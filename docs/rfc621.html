RFC 621

NIC User Directories at SRI-ARC

RFC 621

SRI-ARCのNICユーザーディレクトリー

Abstract

概要

On Friday evening 8-Mar-74, we will delete all those directories at SRI-ARC that belonged to NIC users who were transferred to OFFICE-1.

8-Mar-74（金曜日）の夕方に、OFFICE-1に移行したNICユーザーのものだったSRI-ARC上のディレクトリーをすべて削除します。

Simultaneous1y, there is to be a change at each Network Host such that the Hostname "NIC" will refer to OFFICE-1 (Host 53 octal), not to SRI-ARC. (See RFC# 620, NIC# 21993)

同時に、各ネットワークホストで変更が行われ、ホスト名「NIC」はSRI-ARCではなくOFFICE-1（8進数でホスト53）を指すようになります。（RFC# 620, NIC# 21993を参照）

The effect of these changes is that Network mail sent to NIC users in the form

これらの変更の結果、NICユーザー宛てに次の形式で送られたネットワークメールは、

    "nicusername@NIC"

    "nicusername@NIC"

will be delivered to OFFICE-1, as it should.

本来あるべきとおりOFFICE-1に配送されます。

But if such mail is sent to

しかし、そのようなメールを次の宛先に送った場合、

    "nicusername@SRI-ARC"

    "nicusername@SRI-ARC"

it will not be accepted at SRI-ARC, because the NIC user's username will be no longer be known there.

SRI-ARCではそのNICユーザーのユーザー名がもはや認識されないため、SRI-ARCでは受け付けられません。

PLEASE NOTE THAT IT IS YOUR RESPONSIBILITY TO READ ANY NETWORK MAIL THAT WAS DELIVERED TO YOU AT SRI-ARC PRIOR TO FRIDAY EVENING 8-MARCH. THIS MAIL WILL BE DELETED AT THAT TIME.

3月8日金曜日の夕方より前にSRI-ARCであなた宛てに配送されたネットワークメールは、各自の責任で必ず読んでおいてください。このメールはその時点で削除されます。
