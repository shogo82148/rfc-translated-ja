RFC 309

Data and File Transfer Workshop Announcement

RFC 309

データおよびファイル転送ワークショップの案内

Abstract

概要

MIT will host a workshop on Data and File Transfer, Friday, April 14 and Saturday, April 15, 1972. People have expressed an interest in revising the existing ARPANET Data and File Transfer Protocols (RFC # 264 and RFC # 265), to make them more suitable to fulfill the now better understood ARPANET requirements.

MITは、1972年4月14日（金）と4月15日（土）に、データおよびファイル転送に関するワークショップを開催します。 既存のARPANETのデータ転送プロトコルおよびファイル転送プロトコル（RFC # 264およびRFC # 265）を改訂し、現在ではよりよく理解されるようになったARPANETの要件を満たすのにより適したものにすることに、関心が寄せられています。

The objective of this workshop is to arrive at a unified convention for ARPANET data and file transfer. It is important that we adequately consider the needs of TIP users, DATACOMPUTER users, remote job entry users, and the major ARPANET service systems.

このワークショップの目的は、ARPANETのデータおよびファイル転送について統一された規約にたどり着くことです。 TIPのユーザー、DATACOMPUTERのユーザー、リモートジョブエントリーのユーザー、そしてARPANETの主要なサービスシステムのニーズを十分に考慮することが重要です。

In addition to the current members of the data and file transfer protocol committee, I have invited a number of interested parties to talk and participate in this workshop. On the first day's agenda is a list of speakers who have agreed to discuss their respective interests in data and file transfer. If your interests have not been represented and you would like to give a presentation or discuss a specific area, please contact me (617-864-6900 Ext. 1428).

データおよびファイル転送プロトコル委員会の現在のメンバーに加えて、関心をお持ちの何人かの方々を、このワークショップでの講演と参加にお招きしています。 初日の議事次第には、データおよびファイル転送に関するそれぞれの関心事について話すことを承諾してくださった講演者の一覧があります。 あなたの関心事が取り上げられておらず、発表をしたい、または特定の分野について議論したいという場合は、私（617-864-6900内線1428）までご連絡ください。

Participants are encouraged to have written position papers ready at the time of this meeting. If possible, these papers should be distributed as NWG/RFCs or informal notes to workshop invitees, prior to the workshop.

参加者は、この会合の時点で、文書にまとめた意見書（position paper）を用意しておくことが推奨されます。 可能であれば、これらの文書はワークショップの前に、NWG/RFCとして、またはワークショップの招待者への非公式なメモとして配布すべきです。

As this meeting is intended to be an intensive workshop, with the second half devoted to a detailed specification of protocol, it will be necessary to limit attendance. The attendance to this meeting is by invitation only. A list of invitees is attached. If you have not been invited, and would like to attend the workshop, please contact me.

この会合は集中的なワークショップとし、後半はプロトコルの詳細な仕様策定にあてることを予定しているため、出席者を制限する必要があります。 この会合への出席は招待者のみに限ります。 招待者の一覧を添付します。 招待されていないがワークショップへの出席を希望する場合は、私までご連絡ください。

Hotel reservations may be made at Random House, operated by MIT's Real Estate office ($5.00 to $7.00/night), by contacting either me or Sue Pitkin (617-864-6900 Ext. 1450) before March 31st. If you would prefer other hotel accomodations instead, a convenient hotel is the Fenway motor Hotel (Tel. 617-492-4777).

ホテルの予約は、MITの不動産事務所が運営するRandom House（1泊5.00ドルから7.00ドル）で、3月31日までに私またはSue Pitkin（617-864-6900内線1450）に連絡することでできます。 ほかのホテルの宿泊施設をご希望の場合は、Fenway motor Hotel（電話617-492-4777）が便利です。

Please contact either me or Sue Pitkin if you intend to come.

参加される場合は、私またはSue Pitkinまでご連絡ください。

WORKING SESSION ON DATA AND FILE TRANSFER PROTOCOLS

データおよびファイル転送プロトコルに関する作業セッション

Objective is to come up with revised specifications for data and file transfer protocols that fulfill current (existing and anticipated) ARPANET needs. A unified approach is a desirable goal to strive for.

現在の（既存の、および予想される）ARPANETのニーズを満たす、データおよびファイル転送プロトコルの改訂仕様をまとめることが目的です。 統一的なアプローチを目指すことが望ましい目標です。

Continuation of Friday's discussion of data and file transfer protocols, incorporating specific ideas and changes in the existing protocols.

データおよびファイル転送プロトコルに関する金曜日の議論の続きで、既存のプロトコルに対する具体的なアイデアと変更を取り込みます。

Possible formation of a sub-committee whose task is to write the revised specificaitons for DTP and FTP.

DTPとFTPの改訂仕様を書くことを任務とする小委員会を結成する可能性があります。

Tentative List of Items for Discussion

暫定的な議題の一覧

Data Transfer Protocol (DTP)

データ転送プロトコル（DTP）

  • DTP vs TELNET. Concept of extended TELNET, or allowing use of ASCII in DTP.
  • Error Control and recovery in DTP (use of error checks, restart, etc.)
  • Modes available -- handshake, only one mode, or use of default.
  • Information separator, Aborts, and the Use of Close (NCP-CLS) to Separate Information.
  • Use of DTP with TIPs
  • Use of DTP with DATACOMPUTER
  • DTP対TELNET。 拡張TELNETの概念、またはDTPでのASCIIの使用を認めること。
  • DTPにおけるエラー制御と回復（エラーチェック、再開などの使用）
  • 利用可能なモード -- ハンドシェイク、モードを1つだけにする、またはデフォルトの使用。
  • 情報の区切り、中断（Abort）、および情報を区切るためのClose（NCP-CLS）の使用。
  • TIPでのDTPの使用
  • DATACOMPUTERでのDTPの使用

File Transfer Protocol (FTP)

ファイル転送プロトコル（FTP）

  • Use of ICP, inter-mixing data and control, transferring files to third connections (possibly to different sites)
  • The command language ASCII or codes
  • Handling of data types and physical storage.
  • Handling of descriptors and logical structure
  • Error control and error recovery
  • Use of FTP with TIPs
  • Use of FTP with DATACOMPUTER
  • Uniform Pathnames and the ARPANET virtual file system.
  • ICPの使用、データと制御の混在、第三のコネクションへの（おそらく別のサイトへの）ファイルの転送
  • コマンド言語はASCIIか、コードか
  • データ型と物理的な格納の扱い。
  • 記述子と論理構造の扱い
  • エラー制御とエラー回復
  • TIPでのFTPの使用
  • DATACOMPUTERでのFTPの使用
  • 統一的なパス名とARPANETの仮想ファイルシステム。
