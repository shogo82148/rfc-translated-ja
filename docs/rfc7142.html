RFC 7142

Reclassification of RFC 1142 to Historic

RFC 7142

RFC 1142の歴史的（Historic）ステータスへの再分類

Abstract

概要

This memo reclassifies RFC 1142, "OSI IS-IS Intra-domain Routing Protocol", to Historic status. This memo also obsoletes RFC 1142.

このメモは、RFC 1142「OSI IS-IS Intra-domain Routing Protocol」を歴史的（Historic）ステータスに再分類します。また、このメモはRFC 1142を廃止します。

1. Introduction

1. はじめに

IS-IS is the "OSI Intermediate system to Intermediate system intra-domain routeing information exchange protocol for use in conjunction with the protocol for providing the connectionless-mode Network Service (ISO 8473)", otherwise known as ISO/IEC 10589. It has been extended for use with IP by RFC 1195 [RFC1195] and subsequently enhanced by many other RFCs.

IS-ISは「OSI Intermediate system to Intermediate system intra-domain routeing information exchange protocol for use in conjunction with the protocol for providing the connectionless-mode Network Service (ISO 8473)」であり、ISO/IEC 10589としても知られています。IS-ISはRFC 1195[RFC1195]によってIPで使用できるように拡張され、その後、他の多くのRFCによって機能が強化されてきました。

RFC 1142 [RFC1142] was a republication of ISO DP 10589 originally provided as a service to the Internet community. However, ISO DP 10589 was an ISO "Draft Proposal", which differed in a considerable number of significant respects from the final standardized version published as ISO/IEC 10589 [ISO10589-First-Edition], and subsequently revised as ISO/IEC 10589 Second Edition [ISO10589-Second-Edition]. It has been an ongoing source of confusion when RFC 1142 has been unwittingly quoted or referenced in place of ISO/IEC 10589 itself.

RFC 1142[RFC1142]は、ISO DP 10589を再発行したもので、もともとはインターネットコミュニティーへのサービスとして提供されました。しかし、ISO DP 10589はISOの「ドラフト提案（Draft Proposal）」であり、ISO/IEC 10589[ISO10589-First-Edition]として発行され、その後ISO/IEC 10589第2版[ISO10589-Second-Edition]として改訂された最終的な標準版とは、かなり多くの重要な点で異なっていました。ISO/IEC 10589そのものの代わりにRFC 1142がうっかり引用・参照されることは、これまで絶えず混乱の原因となってきました。

All references to IS-IS should be to the latest edition of the IS-IS standard (currently ISO/IEC 10589:2002, Second Edition), and RFC 1142 is only of historic interest.

IS-ISへの参照はすべて、IS-IS標準の最新版（現在はISO/IEC 10589:2002第2版）に対して行うべきであり、RFC 1142は歴史的な関心の対象でしかありません。

This memo explains why RFC 1142, "OSI IS-IS Intra-domain Routing Protocol", is reclassified to Historic status. This memo also obsoletes RFC 1142.

このメモでは、RFC 1142「OSI IS-IS Intra-domain Routing Protocol」を歴史的（Historic）ステータスに再分類する理由を説明します。また、このメモはRFC 1142を廃止します。

2. Security Considerations

2. セキュリティーに関する考慮事項

Reclassifying RFC 1142 has no security considerations.

RFC 1142の再分類には、セキュリティーに関する考慮事項はありません。
