RFC 1797

Class A Subnet Experiment

RFC 1797

クラスAサブネットの実験

Status of This Memo

このメモのステータス

This document defines an Experimental Protocol for the Internet community. This does not specify an Internet standard of any kind. Discussion and suggestions for improvement are requested. Distribution of this memo is unlimited.

この文書は、インターネットコミュニティーのための実験的プロトコル（Experimental Protocol）を定義します。これは、いかなる種類のインターネット標準も規定するものではありません。改善のための議論と提案を求めます。このメモの配布は無制限です。

Discussion

議論

There appears to be some interest in experimenting with subnetting the class A addresses.

クラスAアドレスのサブネット化を実験することに、ある程度の関心が寄せられているようです。

There is some evidence that not all the routing software in use will deal correctly with subnetted class A addresses. It also appears that actual use of subnetted class A addresses may be necessary in the not too distant future. It is suggested that conducting an experiment now to identify and fix any software that does not properly handle subnetted class A addresses would be useful and important.

使用されているルーティングソフトウェアのすべてが、サブネット化されたクラスAアドレスを正しく扱えるわけではないという証拠がいくつかあります。また、サブネット化されたクラスAアドレスを、それほど遠くない将来に実際に使用する必要が生じる可能性もあるようです。サブネット化されたクラスAアドレスを適切に扱えないソフトウェアを特定して修正するための実験を今のうちに行うことは、有用かつ重要だと考えられます。

To further this experiment the IANA will temporarily designate the class A network number 39 to be used in the following way:

この実験を進めるために、IANAはクラスAのネットワーク番号39を一時的に指定し、次のように使用します。

The high order octet of the 4-octet IPv4 address is the class A network number 39. There are two cases for low order 24 bits.

4オクテットのIPv4アドレスの上位オクテットは、クラスAのネットワーク番号39です。下位24ビットには2つの場合があります。

Case 1:

In the first case, the high order bit of these 24 bits is zero and the next 15 bits are the low order 15 bits of a previously assigned Autonomous System number (AS), as registered by a network registry and listed in the RWhois database system.

Using the AS number in this way allows the experiment to get underway quickly in that it automatically allocates some addresses to each service provider and does not require a registration step.

One concern is that this might cause a run on AS numbers, since by getting an AS number you automatically get some address space. This concern should be offset by the fact that the amount of address space one gets under this plan is the same as one class C network number (and it should be easier to get a single class C allocated than to get an AS number allocated), and that this is a limited time experiment so that these addresses will be temporary.

The low order octet of the 4-octet IPv4 address is for local use. It is expected that an address of this form will be used to identify a specific publicly accessible Internet host.

                +--------+-+-------+--------+--------+
                |   39   |0| low 15 bits AS | local  |
                +--------+-+-------+--------+--------+
Case 2:

In the second case, the high order bit of these 24 bits is one, and the remaining 23 bits are assigned by the IANA (currently reserved for future use).

                +--------+-+-------+--------+--------+
                |   39   |1| variable prefix + local |
                +--------+-+-------+--------+--------+

The general intent is to find a way to assign to experimenters prefixes of differing lengths so that a variety of experiments can be conducted with the prefix/local-address boundary at different points.

場合1：

1つ目の場合では、この24ビットの最上位ビットは0で、続く15ビットは、ネットワークレジストリーによって登録されてRWhoisデータベースシステムに掲載されている、割り当て済みの自律システム番号（AS：Autonomous System number）の下位15ビットです。

このようにAS番号を使用すると、各サービスプロバイダーにいくつかのアドレスが自動的に割り当てられ、登録の手順も必要ないため、実験を素早く始められます。

懸念の1つは、AS番号を取得すれば自動的にアドレス空間が手に入るため、AS番号の取得が殺到するかもしれないことです。この懸念は、この計画で得られるアドレス空間の量がクラスCのネットワーク番号1つ分と同じであること（そして、AS番号の割り当てを受けるよりも、クラスC 1つの割り当てを受けるほうが簡単なはずであること）、また、これは期間限定の実験であり、これらのアドレスは一時的なものであることによって相殺されるはずです。

4オクテットのIPv4アドレスの下位オクテットは、ローカルで使用するためのものです。この形式のアドレスは、公開されアクセス可能な特定のインターネットホストを識別するために使われることを想定しています。

                +--------+-+-------+--------+--------+
                |   39   |0| low 15 bits AS | local  |
                +--------+-+-------+--------+--------+
場合2：

2つ目の場合では、この24ビットの最上位ビットは1で、残りの23ビットはIANAによって割り当てられます（現在は将来の使用のために予約されています）。

                +--------+-+-------+--------+--------+
                |   39   |1| variable prefix + local |
                +--------+-+-------+--------+--------+

全体的な意図は、実験者に異なる長さのプレフィックスを割り当てる方法を見つけ、プレフィックスとローカルアドレスの境界をさまざまな位置にしてさまざまな実験を行えるようにすることです。

It is not intended that either of these address allocation schemes is the model for how subnetted class A addresses will be actually allocated in the future.

これらのアドレス割り当て方式のどちらも、将来サブネット化されたクラスAアドレスが実際にどのように割り当てられるかのモデルとなることを意図したものではありません。

It is expected, to make the experiment interesting, that some providers will use these addresses for servers supplying popular material via the Web or FTP.

実験を興味深いものにするため、一部のプロバイダーが、WebやFTPを通じて人気のある素材を提供するサーバーにこれらのアドレスを使用することを期待しています。

For example, if the service provider registered to use AS 690 wished to use this style of address to provide access to a server of popular information on local host 7, the address would be:

たとえば、AS 690を使用するよう登録されたサービスプロバイダーが、この形式のアドレスを使用して、ローカルホスト7上にある人気のある情報のサーバーへのアクセスを提供したい場合、アドレスは次のようになります。

                +--------+--------+--------+--------+
                |   39   |    2   |   178  |    7   |
                +--------+--------+--------+--------+

                +--------+--------+--------+--------+
                |   39   |    2   |   178  |    7   |
                +--------+--------+--------+--------+

The support for DNS name and address resolution should be provided. For example, if Alternet wanted to put up a database of interesting information using the hostname "Interesting.Alter.Net" using the address 39.2.189.7, they would need to put the name to address mapping in their name server using the A record

DNSの名前とアドレスの解決をサポートすべきです。たとえば、Alternetがアドレス39.2.189.7でホスト名「Interesting.Alter.Net」を使用して興味深い情報のデータベースを立ち上げたい場合、Aレコードを使用して、名前からアドレスへのマッピングを自身のネームサーバーに登録する必要があります。

        Interesting.Alter.Net. IN A 39.2.189.7

        Interesting.Alter.Net. IN A 39.2.189.7

Similarly, the address to name PTR record should be supported

同様に、アドレスから名前へのPTRレコードもサポートすべきです。

        7.189.2.39.IN-ADDR.ARPA. PTR Interesting.Alter.Net.

        7.189.2.39.IN-ADDR.ARPA. PTR Interesting.Alter.Net.

which means that the 189.2.39 branch of the IN-ADDR tree would be delegated to Alternet for the purposes of this experiment.

これは、この実験の目的のために、IN-ADDRツリーの189.2.39の枝がAlternetに委任されることを意味します。

To support this, the 39.IN-ADDR.ARPA branch is delegated to the IANA to be managed at ISI. The nameserver for this branch is IN-ADDR.EP.NET (39.17.199.10). Participants in this experiment should contact the administrator of this nameserver to have their portion of the address space further delegated. The administrator for this server can be reached at <aexpreg@isi.edu>.

これをサポートするため、39.IN-ADDR.ARPAの枝は、ISIで管理するためにIANAに委任されます。この枝のネームサーバーはIN-ADDR.EP.NET（39.17.199.10）です。この実験の参加者は、このネームサーバーの管理者に連絡して、自分の担当するアドレス空間をさらに委任してもらってください。このサーバーの管理者には<aexpreg@isi.edu>で連絡できます。

Another aspect of the testing that should be performed is to have providers interchange addresses to test the portability of subnetted class A addresses. It is not intended that this would be the model for actual use.

実施すべきテストの別の側面として、プロバイダー間でアドレスを交換して、サブネット化されたクラスAアドレスのポータビリティーをテストすることがあります。これが実際の使用のモデルとなることは意図していません。

For example, if AS 690 and AS 1800 want to try out routing holes in each others' allocations within their AS, that should be encouraged. That is, suppose AS 690 handed some address of their addresses to AS 1800, and vice-versa. This type of testing will be necessary to see if the addresses can be made portable in larger sub-A allocations.

たとえば、AS 690とAS 1800が、各自のAS内で互いの割り当ての中にルーティングの穴を開けることを試したい場合、それは奨励されるべきです。つまり、AS 690が自身のアドレスの一部をAS 1800に渡し、その逆も行う場合を考えます。この種のテストは、より大きなサブAの割り当てにおいてアドレスをポータブルにできるかどうかを確かめるために必要です。

This is experiment will be of limited duration and these addresses may be reassigned to other uses when the experiment is over.

この実験は期間限定であり、実験が終了したらこれらのアドレスはほかの用途に再割り当てされる場合があります。

This experiment will begin on 1-May-95.

この実験は1995年5月1日に開始します。

The current date for the termination of this experiment is 1-Dec-95.

この実験の現時点での終了日は1995年12月1日です。
