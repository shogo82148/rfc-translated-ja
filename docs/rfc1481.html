RFC 1481

IAB Recommendation for an Intermediate Strategy to Address the Issue of Scaling

RFC 1481

スケーリングの問題に対処するための暫定戦略に関するIABの推奨事項

Status of This Memo

このメモのステータス

This memo provides information for the Internet community. It does not specify an Internet standard. Distribution of this memo is unlimited.

このメモは、インターネットコミュニティーに情報を提供するものです。インターネット標準を規定するものではありません。このメモの配布は無制限です。

Recommendation

推奨事項

Classless Inter-Domain Routing (CIDR) proposes strategies for address assignment of the existing IP address space with a view to conserve the address space and stem the explosive growth of routing tables in default-route-free routers run by transit routing domain providers [1]. CIDR is proposed as an immediate term strategy to extend the life of the current 32 bit IP address space. This strategy presumes that a suitable long term solution is being addressed within the Internet technical community.

クラスレスドメイン間ルーティング（Classless Inter-Domain Routing、CIDR）は、アドレス空間を節約し、トランジットルーティングドメインのプロバイダーが運用するデフォルトルートを持たないルーターにおけるルーティングテーブルの爆発的な増大を食い止めることを目的として、既存のIPアドレス空間のアドレス割り当ての戦略を提案しています[1]。CIDRは、現在の32ビットのIPアドレス空間の寿命を延ばすための当面の戦略として提案されています。この戦略は、適切な長期的解決策にインターネット技術コミュニティーの中で取り組んでいることを前提としています。

The basic components of the CIDR plan are: management of the allocation of Internet address space and provision of a mechanism for aggregation of routing information. The IP community has published several RFCs and Internet-Drafts which describe the architecture for IP address assignment and routing protocols which will promote the deployment of CIDR. These documents have led to changes in the way network address are allocated and have prompted enhancements to the inter-domain and intra-domain routing protocols.

CIDRの計画の基本的な構成要素は、インターネットアドレス空間の割り当ての管理と、ルーティング情報を集約する仕組みの提供です。IPコミュニティーは、CIDRの導入を促進する、IPアドレス割り当てのアーキテクチャーとルーティングプロトコルを記述したRFCとインターネットドラフトをいくつか公開しています。これらの文書によって、ネットワークアドレスの割り当て方法が変わり、ドメイン間とドメイン内のルーティングプロトコルの改良が促されました。

With the CIDR prompted changes in the management of the allocation of the Internet address space, allocation of blocks of Class C numbers leads to an explosion of the routing tables. So, it is important that the techniques for aggregating information in the routing protocols keep pace with the change in the allocation of IP numbers.

CIDRによって促されたインターネットアドレス空間の割り当ての管理の変更に伴い、クラスCの番号をブロックで割り当てることは、ルーティングテーブルの爆発につながります。そのため、ルーティングプロトコルで情報を集約する技術が、IP番号の割り当ての変化に遅れずについていくことが重要です。

The IAB endorses the CIDR architecture and its implementation. In addition, the IAB supports the actions taken by the IANA and InterNIC, the router vendors, and the network operators to implement CIDR to address the scaling problem that we are facing with the growth of the Internet.

IABは、CIDRのアーキテクチャーとその実装を承認します。さらにIABは、インターネットの成長に伴って私たちが直面しているスケーリングの問題に対処するため、IANAとInterNIC、ルーターベンダー、ネットワーク運用者がCIDRを実装するために行っている活動を支持します。
