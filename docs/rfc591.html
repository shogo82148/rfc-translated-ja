RFC 591

Addition to the Very Distant Host Specification

RFC 591

Very Distant Host仕様への追加

Abstract

概要

It has been brought to my attention that the following sentence should be added to the Very Distant Host specification in Appendix F of BBN report 1822, Specifications for the Interconnection of a Host and an IMP, to the paragraph beginning on page F-5 and ending on page F-7:

BBNレポート1822「Specifications for the Interconnection of a Host and an IMP」の付録FにあるVery Distant Host仕様について、F-5ページで始まりF-7ページで終わる段落に次の文を追加すべきだという指摘を受けました。

"Null packets do not use a channel (nor a channel number) when sent and are not acknowledged when received."

「ヌルパケットは、送信時にはチャネル（およびチャネル番号）を使用せず、受信時には確認応答されない。」

Please file this RFC with your copy of BBN report 1822 until 1822 is next updated.

1822が次に更新されるまで、このRFCをお手元のBBNレポート1822と一緒に綴じておいてください。

DCW/nlg

DCW/nlg
