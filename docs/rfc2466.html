RFC 2466

Management Information Base for IP Version 6: ICMPv6 Group

RFC 2466

IPバージョン6のための管理情報ベース：ICMPv6グループ

Abstract

概要

This document is one in the series of documents that define various MIB object groups for IPv6. Specifically, the ICMPv6 group is defined in this document.

この文書は、IPv6のためのさまざまなMIBオブジェクトグループを定義する一連の文書の1つです。具体的には、この文書ではICMPv6グループを定義します。

This memo defines a portion of the Management Information Base (MIB) for use with network management protocols in the IPv6-based internets.

このメモは、IPv6ベースのインターネットでネットワーク管理プロトコルとともに使用するための管理情報ベース（MIB）の一部を定義します。

This document specifies a MIB module in a manner that is both compliant to the SNMPv2 SMI, and semantically identical to the peer SNMPv1 definitions.

この文書は、SNMPv2のSMIに準拠し、かつ対応するSNMPv1の定義と意味的に同一となる方法でMIBモジュールを規定します。

1. The SNMPv2 Network Management Framework

1. SNMPv2のネットワーク管理フレームワーク

The SNMPv2 Network Management Framework presently consists of three major components. They are:

SNMPv2のネットワーク管理フレームワークは、現在、3つの主要な構成要素からなります。それらは次のとおりです。

  • the SMI, described in RFC 1902 [1] - the mechanisms used for describing and naming objects for the purpose of management.
  • the MIB-II, described in RFC 1213/STD 17 [3] - the core set of managed objects for the Internet suite of protocols.
  • RFC 1157/STD 15 [4] and RFC 1905 [5] which define two versions of the protocol used for network access to managed objects.
  • RFC 1902[1]で説明されているSMI。管理の目的でオブジェクトを記述し、名前を付けるために使用される仕組みです。
  • RFC 1213/STD 17[3]で説明されているMIB-II。インターネットのプロトコル群のための管理対象オブジェクトの中核となる集合です。
  • RFC 1157/STD 15[4]とRFC 1905[5]。管理対象オブジェクトへのネットワークアクセスに使用されるプロトコルの2つのバージョンを定義しています。

The Framework permits new objects to be defined for the purpose of experimentation and evaluation.

このフレームワークでは、実験と評価の目的で新しいオブジェクトを定義することができます。

1.1. Object Definitions

1.1. オブジェクトの定義

Managed objects are accessed via a virtual information store, termed the Management Information Base or MIB. Objects in the MIB are defined using the subset of Abstract Syntax Notation One (ASN.1) defined in the SMI. In particular, each object type is named by an OBJECT IDENTIFIER, an administratively assigned name. The object type together with an object instance serves to uniquely identify a specific instantiation of the object. For human convenience, we often use a textual string, termed the descriptor, to refer to the object type.

管理対象オブジェクトには、管理情報ベース（MIB）と呼ばれる仮想的な情報ストアを介してアクセスします。MIB内のオブジェクトは、SMIで定義された抽象構文記法1（ASN.1）のサブセットを使用して定義されます。特に、各オブジェクト型には、管理上割り当てられた名前であるOBJECT IDENTIFIERによって名前が付けられます。オブジェクト型とオブジェクトインスタンスを組み合わせることで、オブジェクトの特定のインスタンス化を一意に識別します。人間の便宜のために、オブジェクト型を参照するのに、記述子と呼ばれるテキストの文字列をよく使用します。

2. Overview

2. 概要

This document is the one in the series of documents that define various MIB object groups for IPv6. These groups are the basic unit of conformance: if the semantics of a group is applicable to an implementation, then it must implement all objects in that group. For example, an implementation must implement the TCP group if and only if it implements the TCP over IPv6 protocol. At minimum, implementations must implement the IPv6 General group [9] as well as the ICMPv6 group defined in this document.

この文書は、IPv6のためのさまざまなMIBオブジェクトグループを定義する一連の文書の1つです。これらのグループは適合性の基本単位です。グループの意味が実装に適用可能な場合、その実装はそのグループのすべてのオブジェクトを実装する必要があります。たとえば、実装は、IPv6上のTCPのプロトコルを実装する場合に限り、TCPグループを実装する必要があります。実装は、少なくとも、IPv6一般グループ[9]と、この文書で定義されたICMPv6グループを実装する必要があります。

This document defines the ICMPv6 group of the IPv6 MIB.

この文書は、IPv6のMIBのICMPv6グループを定義します。

6. Security Considerations

6. セキュリティーに関する考慮事項

Certain management information defined in this MIB may be considered sensitive in some network environments.

このMIBで定義された管理情報の一部は、一部のネットワーク環境では機密性が高いとみなされる場合があります。

Therefore, authentication of received SNMP requests and controlled access to management information should be employed in such environments.

したがって、そのような環境では、受信したSNMPの要求の認証と、管理情報へのアクセス制御を採用すべきです。
