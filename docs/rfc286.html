RFC 286

Network Library Information System

RFC 286

ネットワーク図書館情報システム

Abstract

概要

Georgetown University is designing a Learning Resource Center (LRC), part of which may consist of a system to enable computer query (hopefully on-line) of G.U.'s Library holdings. The ARPA community might be of assistance in either of two ways:

Georgetown Universityでは、Learning Resource Center（LRC）を設計しています。その一部として、G.U.の図書館の蔵書をコンピューターで（できればオンラインで）照会できるようにするシステムを設けるかもしれません。ARPAコミュニティーには、次の2つのいずれかの方法でご協力いただけるかもしれません。

  1. One or more organizations may have a Library Retrieval System that they would like to share with Georgetown.
  2. Since there probably are needs for such a system at most organizations, and since it would be highly beneficial for one organization to be able to query other library holdings as well, and subsequently arrange for inter-library loans, the ARPA community might undertake to design a Network Library Information System.
  1. Georgetownと共有してもよいと考える図書館検索システム（Library Retrieval System）を、1つ以上の組織が持っているかもしれません。
  2. このようなシステムはおそらくほとんどの組織で必要とされており、また、ある組織がほかの図書館の蔵書も照会でき、その後に図書館間の貸し出しを手配できれば非常に有益であることから、ARPAコミュニティーがネットワーク図書館情報システム（Network Library Information System）の設計に取り組むことが考えられます。

If sufficient interest in such a system exists, a working group could be set up to establish the necessary protocols and iron out details of the system.

このようなシステムに十分な関心が寄せられれば、必要なプロトコルを確立し、システムの詳細を詰めるためのワーキンググループを設けることができるでしょう。

It is probable that the NIC could provide valuable inputs to such an undertaking and perhaps would serve as a focal point for the system design and operation.

NICは、このような取り組みに貴重な情報を提供でき、おそらくシステムの設計と運用の中心的な役割を果たすことになるでしょう。

Please contact me if either:

次のいずれかに当てはまる場合は、私までご連絡ください。

  1. You have, or know of a Library Retrieval System that can be shared with Georgetown University,
  2. Your organization is interested in participating in a Network Library Retrieval System, or
  3. You are interested in participating in designing such a system.
  1. Georgetown Universityと共有できる図書館検索システムを持っている、または知っている
  2. あなたの組織がネットワーク図書館検索システム（Network Library Retrieval System）への参加に関心がある
  3. あなたがこのようなシステムの設計への参加に関心がある
