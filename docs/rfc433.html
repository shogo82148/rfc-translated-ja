RFC 433

Socket Number List

RFC 433

ソケット番号一覧

Abstract

概要

The czar of socket numbers [Jon Postel] has established the following assignments for socket numbers used for public functions. Note that a socket number is a 40 bit quantity, the first 8 bits being the host specification, the next 24 bits being site specific, and the last 8 bits being user specified - these last 8 bits are called the AEN [it stands for, cleverly enough, Another Eightbit Number].

ソケット番号の管理責任者（czar）［Jon Postel］は、公共の機能に使用するソケット番号について、次の割り当てを定めました。ソケット番号は40ビットの量であり、最初の8ビットがホストの指定、次の24ビットがサイト固有、最後の8ビットがユーザー指定であることに注意してください。この最後の8ビットはAENと呼ばれます［これは、なかなか気の利いたことに、Another Eightbit Number（もう1つの8ビットの番号）の略です］。

For the assignments here the value in the host field ranges across all hosts (unless otherwise specified), the value in the 24 bit field is zero, and the AEN is indicated here.

ここでの割り当てでは、ホストフィールドの値は（特に指定がない限り）すべてのホストにわたり、24ビットのフィールドの値は0で、AENをここに示します。

General Assignments:

一般的な割り当て：

Sockets Assignment
0 - 63 Network Wide Standard Functions
64 - 127 Host Specific Functions
128 - 239 Reserved for Future Use
240 - 255 Any Experimental Function

ソケット 割り当て
0 - 63 ネットワーク全体の標準機能
64 - 127 ホスト固有の機能
128 - 239 将来の使用のために予約
240 - 255 任意の実験的機能
