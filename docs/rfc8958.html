RFC 8958

Updated Registration Rules for URI.ARPA

RFC 8958

URI.ARPAの更新された登録規則

Abstract

概要

This document updates RFC 3405 by removing references to the IETF tree from the procedures for requesting that a URI scheme be inserted into the URI.ARPA zone.

この文書は、URIスキームをURI.ARPAゾーンに挿入するよう要求する手順からIETFツリーへの言及を削除することで、RFC 3405を更新します。

1. Introduction

1. はじめに

Part Five of the Dynamic Delegation Discovery System (DDDS) [RFC3405] describes the registration procedures for assignments in URI.ARPA. The document requires that registrations be in the "IETF tree" of URI registrations. The use of URI scheme name trees was defined in [RFC2717] but discontinued by [RFC4395] and its successors. Since the use of trees was discontinued, there is no way in the current process set out in [RFC7595] to meet the requirement to register within that tree.

動的委任発見システム（Dynamic Delegation Discovery System、DDDS）のパート5 [RFC3405] は、URI.ARPAにおける割り当ての登録手順を記述しています。 この文書は、登録がURI登録の「IETFツリー」にあることを要求しています。 URIスキーム名のツリーの使用は[RFC2717]で定義されましたが、 [RFC4395]とその後継文書によって廃止されました。 ツリーの使用が廃止されたため、[RFC7595]に定められた現在のプロセスでは、そのツリー内に登録するという要件を満たす方法がありません。

1.1. Requirements Language

1.1. 要件言語

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in BCP 14 [RFC2119] [RFC8174] when, and only when, they appear in all capitals, as shown here.

この文書のキーワード 「しなければなりません（MUST）」、「してはなりません（MUST NOT）」、「要求されています（REQUIRED）」、「することになります（SHALL）」、「することはありません（SHALL NOT）」、「すべきです（SHOULD）」、「すべきではありません（SHOULD NOT）」、「推奨されます（RECOMMENDED）」、「推奨されません（NOT RECOMMENDED）」、 「してもよいです（MAY）」、「選択できます（OPTIONAL）」は、 ここに示すようにすべて大文字で現れる場合に限り、BCP 14 [RFC2119] [RFC8174] で述べられているとおりに解釈されます。

2. Updated Requirements

2. 更新された要件

This document removes the normative requirement from [RFC3405] for registrations in URI.ARPA to be from the IETF URI tree.

この文書は、URI.ARPAへの登録がIETF URIツリーからのものでなければならないという[RFC3405]の規範的要件を削除します。

All registrations in URI.ARPA MUST now be for schemes that are permanent registrations, as described in BCP 35.

URI.ARPAへのすべての登録は、今後は、BCP 35に記述されているとおり、恒久的な登録であるスキームのためのものでなければなりません（MUST）。

3. IANA Considerations

3. IANAに関する考慮事項

This entire document is updated instructions to IANA.

この文書全体が、IANAへの更新された指示です。

4. Security Considerations

4. セキュリティーに関する考慮事項

This update does not change the security considerations in [RFC3405].

この更新は、[RFC3405]のセキュリティーに関する考慮事項を変更しません。
