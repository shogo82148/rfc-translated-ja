RFC 476

IMP/TIP Memory Retrofit Schedule (Revision 2)

RFC 476

IMP/TIPのメモリー増設スケジュール（改訂2）

Abstract

概要

This revision contains two types of changes to RFC #447. First, the retrofits to Utah, Belvoir, NOAA, USC, Stanford, ISI, Case, and CCA have been completed and are therefore removed from the schedule. Second, the retrofits to UCSB, ETAC, Aberdeen, and Rome have been rescheduled.

この改訂には、RFC #447に対する2種類の変更が含まれています。1つ目に、Utah、Belvoir、NOAA、USC、Stanford、ISI、Case、CCAの増設は完了したため、スケジュールから削除しました。2つ目に、UCSB、ETAC、Aberdeen、Romeの増設の日程を変更しました。

The revised text of RFC #447 follows:

以下は、RFC #447の改訂版の本文です。

During the first several months of 1973 we will be retrofitting each IMP and TIP with additional core memory. At the end of the retrofit program, the memory sizes of the various machines will be as follows:

1973年の最初の数か月の間に、私たちは各IMPとTIPにコアメモリーを増設します。増設計画が終わると、各機種のメモリーサイズは次のようになります。

  • IMP (516 or 316) - 16K words
  • TIP - 28K words
  • TIP with Magnetic Tape Option - 32K words
  • IMP（516または316）- 16Kワード
  • TIP - 28Kワード
  • 磁気テープオプション付きのTIP - 32Kワード

In addition, the expansion of the TIP core memory will necessitate enlarging the TIP to two cabinets.

また、TIPのコアメモリーを増やすため、TIPを2キャビネットに拡大する必要があります。

Listed below is the schedule for the remaining retrofits. We have arranged this schedule to coincide with the usual monthly Preventive Maintenance at each site so as to minimize user inconvenience, but the work required will frequently require the machines to be down longer than normal. I will issue additional RFC's updating this schedule as necessary.

残りの増設のスケジュールを以下に示します。ユーザーの不便を最小限に抑えるため、このスケジュールは各サイトで毎月行われる通常の予防保守に合わせてありますが、必要な作業のために、マシンの停止時間が通常より長くなることがよくあります。必要に応じて、このスケジュールを更新するRFCを追加で発行します。
