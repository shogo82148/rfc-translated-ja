RFC 179

Link Number Assignments

RFC 179

リンク番号の割り当て

Abstract

概要

Today Steve Crocker asked me to announce that from now on link numbers 2-71 (decimal), inclusive, are to be valid for use in connections. Accordingly, the Host-Host Protocol Document, which I am currently writing, will contain the following "declarative specification".

本日、Steve Crockerから、今後はリンク番号2～71（10進数、両端を含む）をコネクションに使用してよいことにすると告知するよう頼まれました。これに従い、私が現在執筆しているHost-Host Protocol Documentには、次の「宣言的な仕様」を記載する予定です。

Links are assigned as follows:

リンクは次のように割り当てます。

Table 1
Link Number Assignment
0 Control link
2-71 Available for connections
1, 72-190 Reserved-not for current use
191 To be used only for measurement work under the direction of the Network Measurement Center at UCLA
192-255 Available for private experimental use
表1
リンク番号 割り当て
0 制御リンク
2-71 コネクションに使用可能
1, 72-190 予約済み（現在は使用しない）
191 UCLAのNetwork Measurement Centerの指示のもとで行う測定作業にのみ使用
192-255 私的な実験用に使用可能
