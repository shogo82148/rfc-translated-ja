Assigned Network Numbers

RFC 717

割り当て済みのネットワーク番号

Abstract

概要

This note specifies the numbers assigned to identify networks for use in the inter-network protocol experiments. Additional Numbers are assigned by Jon Postel [POSTEL@ISIC or (415) 326-6200 x3718].

このノートでは、インターネットワークプロトコルの実験で使うネットワークを識別するために割り当てられた番号を示します。追加の番号はJon Postel [POSTEL@ISIC or (415) 326-6200 x3718]が割り当てます。

This field selects the appropriate gateway processing and is used to dispatch the packet to the appropriate protocol module in the destination. The following values are defined for this field:

        0 -- Escape; protocol is specified by a subsequent field
        1 -- TCP
        2 -- Secure TCP
        3-16 -- Not allocated
