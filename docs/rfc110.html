RFC 110

Conventions for Using an IBM 2741 Terminal as a User Console for Access to Network Server Hosts

RFC 110

ネットワークのサーバーホストにアクセスするためのユーザーコンソールとしてIBM 2741端末を使用する規約

Abstract

概要

TO: NIC
FROM: Joel M. Winnet (LL)
SUBJECT: Conventions for Using an IBM 2741 Terminal as a User Console for Access to Network Server Hosts

宛先：NIC
差出人：Joel M. Winnet（LL）
件名：ネットワークのサーバーホストにアクセスするためのユーザーコンソールとしてIBM 2741端末を使用する規約

An IBM terminal can be used to key in 92 different codes. These include 88 graphics plus the 4 controls SP, BS, HT, and NL. Each of these have defined ASCII codes except the cent graphic ([1]) and the New Line Control (NL). When the NL character is keyed, the program receiving the keyboard input can translate this signal into the appropriate line end signal for the host which is being used. That is, to a NL, CR, or LF code whichever is appropriate. There are 7 other ASCII graphic characters ( {, }, [, ], ^, \, `) and 31 other ASCII controls which cannot be keyed on a 2741 terminal. A convention must be established so that all 128 ASCII codes can be keyed from a 2741 terminal. This requires that one character be chosen as an escape (or prefix) character which,a together with following characters, can be converted into any desired ASCII code. In addition to this escape character, there are three other functions which are usually indicated by the typing of a single character key. These are:

IBM端末では、92種類のコードをキー入力できます。その内訳は、88個の図形文字と、SP、BS、HT、NLの4つの制御文字です。セント記号（[1]）と改行制御（New Line Control、NL）を除き、これらにはそれぞれASCIIコードが定義されています。NL文字がキー入力されると、キーボード入力を受け取るプログラムは、この信号を、使用しているホストに適した行末信号に変換できます。つまり、NL、CR、LFのうち適切なコードに変換します。2741端末でキー入力できないASCII図形文字がほかに7つ（{、}、[、]、^、\、`）、ASCII制御文字がほかに31個あります。128個のASCIIコードすべてを2741端末からキー入力できるようにするための規約を定めなければなりません。そのためには、1つの文字をエスケープ（またはプレフィックス）文字として選び、その文字と後続の文字を組み合わせて、任意のASCIIコードに変換できるようにする必要があります。このエスケープ文字に加えて、通常は単一の文字キーの入力で指示する機能がほかに3つあります。それは次のとおりです。

  1. character delete -- to cause this character and the preceding character in the input line to be deleted.
  2. line delete -- to cause this character and all previous characters in the current input line to be deleted.
  3. logical line end -- to cause all characters keyed after the last logical line end character or last NL character up to this character to be considered as one logical line with this character being treated as if the NL key were entered. Characters following the logical line end character up to another logical line end character or a NL character are used for form another input line.
  1. 文字削除 -- この文字と、入力行でその直前にある文字を削除させます。
  2. 行削除 -- この文字と、現在の入力行でそれより前にあるすべての文字を削除させます。
  3. 論理行末 -- 最後の論理行末文字または最後のNL文字の後からこの文字までにキー入力されたすべての文字を1つの論理行とみなし、この文字をNLキーが入力されたかのように扱わせます。論理行末文字に続き、次の論理行末文字またはNL文字までの文字は、別の入力行を形成するのに使われます。

Since characters keyed are normally sent to the Server Host, a method must be defined to allow characters keyed to be interpreted by the user program. A system escape character can be used for this purpose. On character at a time systems, the characters keyed between two system escape characters can be interpreted by the user program. On line at a time systems, characters keyed after the system escape character and up to and including a NL character can be interpreted by the user program. Lines interpreted by the user program are not sent to the Server Host.

キー入力された文字は通常はサーバーホストに送られるので、キー入力された文字をユーザープログラムに解釈させる方法を定めなければなりません。この目的にはシステムエスケープ文字を使えます。1文字ずつ処理するシステムでは、2つのシステムエスケープ文字の間でキー入力された文字をユーザープログラムが解釈できます。1行ずつ処理するシステムでは、システムエスケープ文字の後からNL文字まで（NL文字を含む）にキー入力された文字をユーザープログラムが解釈できます。ユーザープログラムが解釈した行はサーバーホストには送られません。

For those host systems which require use of the INS or INR network control commands, a method must be defined for causing these commands to be sent. These can be sent on a command to the user program either after keying the system escape character or through the use of the 'attention' button on a 2741 terminal. This choice will depend on the characteristics of the terminal user's operating system.

INSまたはINRのネットワーク制御コマンドを使う必要があるホストシステムのために、これらのコマンドを送らせる方法を定めなければなりません。これらのコマンドは、システムエスケープ文字をキー入力した後に、または2741端末の「attention」ボタンを使って、ユーザープログラムへのコマンドによって送ることができます。どちらにするかは、端末ユーザーのオペレーティングシステムの特性によって決まります。

Other commands to the user program might be to:

ユーザープログラムに対するその他のコマンドとしては、次のようなものが考えられます。

  1. suppress typeout of received messages
  2. restore typeout of received messages
  3. direct received message to a disk file
  4. direct keyed input to a disk file
  5. abort the user program
  1. 受信したメッセージのタイプアウト（印字出力）を抑止する
  2. 受信したメッセージのタイプアウトを再開する
  3. 受信したメッセージをディスクファイルに出力する
  4. キー入力をディスクファイルに出力する
  5. ユーザープログラムを中断する

The following characters are recommended for the special functions listed above:

上記の特殊機能には、次の文字を推奨します。

  1. character escape $NOT [1]
  2. system escape |
  3. character delete @
  4. line delete $CENT [1]
  5. logical linend #
  1. 文字エスケープ $NOT [1]
  2. システムエスケープ |
  3. 文字削除 @
  4. 行削除 $CENT [1]
  5. 論理行末 #

For the 7 ASCII graphics not on a 2741 terminal, the following character escape and graphic pairs are recommended:

2741端末にない7つのASCII図形文字については、次の文字エスケープと図形文字の組を推奨します。

      $NOT <           to translate to         [
      $NOT >           to translate to         ]
      $NOT (           to translate to         {
      $NOT )           to translate to         }
      $NOT "           to translate to         ^
      $NOT /           to translate to         \
      $NOT '           to translate to         `

特殊機能の文字そのものをキー入力できるように、次の文字エスケープと図形文字の組を推奨します。

      $NOT -           to translate to        $NOT
      $NOT :           to translate to         |
      $NOT ,           to translate to         @
      $NOT .           to translate to        $CENT

制御文字SP、BS、HTは、文字エスケープ文字を使って指定することも、2741端末の該当するキーを直接入力して指定することもできることに注意してください。
