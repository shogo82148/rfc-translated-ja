RFC 268

Graphics Facilities Information

RFC 268

グラフィックス設備に関する情報

Abstract

概要

It was suggested at the recent network graphics meeting (@ SAIL 21-23 November) that it would be a good idea to include in the Resources Notebook information about the graphics facilities at each site. To further this proposal, I request that the Technical Liaison (or other knowledgeable person) at each site send me a description of their graphics facilities for inclusion in the Resources Notebook.

最近のネットワークグラフィックス会議（11月21〜23日、SAILにて）で、各サイトのグラフィックス設備に関する情報をResources Notebookに含めるとよいのではないか、という提案がありました。この提案を進めるため、各サイトの技術連絡担当者（Technical Liaison）（またはほかの詳しい人）に、Resources Notebookに掲載するためのグラフィックス設備の説明を私宛てに送っていただくようお願いします。

[It is not intended that this replace any other mechanism for updating Resource Notebook entries and the information collected will be submitted to the normal editorial procedures.]

[これは、Resource Notebookの項目を更新するほかの仕組みを置き換えることを意図したものではありません。また、集めた情報は通常の編集手続きにかけられます。]
