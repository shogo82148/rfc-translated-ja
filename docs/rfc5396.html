RFC 5396

Textual Representation of Autonomous System (AS) Numbers

RFC 5396

自律システム（AS）番号のテキスト表現

Abstract

概要

A textual representation for Autonomous System (AS) numbers is defined as the decimal value of the AS number. This textual representation is to be used by all documents, systems, and user interfaces referring to AS numbers.

自律システム（AS）番号のテキスト表現は、AS番号の10進数の値として定義されます。このテキスト表現は、AS番号に言及するすべての文書、システム、ユーザーインターフェイスで使用するものとします。

1. Introduction

1. はじめに

A textual representation for Autonomous System (AS) numbers is defined as the decimal value of the AS number. This textual representation is to be used by all documents, systems, and user interfaces referring to AS numbers.

自律システム（AS）番号のテキスト表現は、AS番号の10進数の値として定義されます。このテキスト表現は、AS番号に言及するすべての文書、システム、ユーザーインターフェイスで使用するものとします。

This document notes a number of potential representation formats and proposes the adoption of a decimal value notation for AS numbers, or "asplain" according to the representation taxonomy described here.

この文書は、考えられるいくつかの表現形式に触れ、AS番号の表記として10進数の値による表記、つまりここで説明する表現の分類における「asplain」を採用することを提案します。

2. Taxonomy of Representation Formats

2. 表現形式の分類

A taxonomy of representation for AS numbers is as follows:

AS番号の表現の分類は次のとおりです。

asplain
refers to a syntax scheme of representing all AS numbers using decimal integer notation. Using asplain notation, an AS number of value 65526 would be represented as the string "65526" and an AS number of value 65546 would be represented as the string "65546".
asdot+
refers to a syntax scheme of representing all AS numbers using a notation of two integer values joined by a period character: <high order 16-bit value in decimal>.<low order 16-bit value in decimal>. Using asdot+ notation, an AS number of value 65526 would be represented as the string "0.65526" and an AS number of value 65546 would be represented as the string "1.10".
asdot
refers to a syntax scheme of representing AS number values less than 65536 using asplain notation and representing AS number values equal to or greater than 65536 using asdot+ notation. Using asdot notation, an AS number of value 65526 would be represented as the string "65526" and an AS number of value 65546 would be represented as the string "1.10".
asplain
すべてのAS番号を10進整数の表記で表す構文の方式を指します。asplain表記では、値が65526のAS番号は文字列「65526」で表され、値が65546のAS番号は文字列「65546」で表されます。
asdot+
すべてのAS番号を、2つの整数値をピリオド文字で連結した表記、つまり<上位16ビットの値の10進数>.<下位16ビットの値の10進数>で表す構文の方式を指します。asdot+表記では、値が65526のAS番号は文字列「0.65526」で表され、値が65546のAS番号は文字列「1.10」で表されます。
asdot
65536未満のAS番号の値をasplain表記で表し、65536以上のAS番号の値をasdot+表記で表す構文の方式を指します。asdot表記では、値が65526のAS番号は文字列「65526」で表され、値が65546のAS番号は文字列「1.10」で表されます。

3. Representation of AS Number Values

3. AS番号の値の表現

To avoid confusion, a single textual notation is useful for documentation, configuration systems, reports, and external tools and information repositories. The decimal value representation, or "asplain" is proposed as the textual notation to use for AS numbers.

混乱を避けるためには、文書、設定システム、レポート、外部のツールや情報リポジトリーで単一のテキスト表記を使うことが有用です。AS番号に使うテキスト表記として、10進数の値による表現、つまり「asplain」を提案します。

The "asplain" representation represents the number as its decimal value, without any field delimiter, corresponding to the lack of any internal structure required by the use of AS numbers in the inter-domain routing context.

「asplain」表現は、番号をその10進数の値として、フィールドの区切り文字なしで表します。これは、ドメイン間ルーティングの文脈でAS番号を使用する際に、内部構造がまったく必要とされないことに対応しています。

4. IANA Considerations

4. IANAに関する考慮事項

IANA Registries should use decimal representation ("asplain") for AS numbers.

IANAレジストリーは、AS番号に10進数の表現（「asplain」）を使用すべきです。

5. Security Considerations

5. セキュリティーに関する考慮事項

This document does not refer to matters associated with security of routing systems.

この文書は、ルーティングシステムのセキュリティーに関する事柄には言及しません。
