RFC 311

New Console Attachments to the UCSB Host

RFC 311

UCSBホストへの新しいコンソールの接続

The MLC/360M

MLC/360M

The UCSB 360-75 is equipped with an interface unit that allows attachment of any type of I/O device to the Multiplexor Channel and for that device to be operated by program control as though it were a standard IBM Control Unit. The interface, referred to as the Multi-Line Controller/360M (MLC/360M), operates on the Multiplexor Channel and provides 32 independently addressed I/O connections that are grouped into 16 pairs to accommodate full- duplex I/O operation. Each input group has a 16-bit input buffer plus related synchronizing and control logic to make it a stand-alone control unit on the 360 channel. Similarly, each output group has a 32-bit buffer plus logic. Attachment is achieved by connection through a data-set type connector and I/O signal levels conform to EIA standards (RS-232 Spec.).

UCSBの360-75には、あらゆる種類のI/O装置をマルチプレクサーチャネル（Multiplexor Channel）に接続し、その装置を標準のIBM制御装置（Control Unit）であるかのようにプログラム制御で操作できるようにするインターフェイス装置が備わっています。マルチラインコントローラー/360M（Multi-Line Controller/360M、MLC/360M）と呼ばれるこのインターフェイスは、マルチプレクサーチャネル上で動作し、独立にアドレス指定される32個のI/O接続を提供します。これらは全二重のI/O操作に対応するために16組のペアにまとめられています。各入力グループは、16ビットの入力バッファーと、関連する同期・制御ロジックを持ち、360のチャネル上の独立した制御装置となっています。同様に、各出力グループは32ビットのバッファーとロジックを持っています。接続はデータセット型のコネクターを介して行い、I/O信号レベルはEIA規格（RS-232仕様）に準拠しています。

Both the I/O group hardware and the supporting software for the MLC/360M are readily modified to produce any variations required for attachment and operation of non-standard devices.

MLC/360MのI/Oグループのハードウェアとサポートソフトウェアはどちらも、非標準の装置の接続と操作に必要なあらゆる変更を加えるために簡単に改造できます。

Since our primary support was for 201B data-sets at 2400 baud, we first implemented the 16 I/O group pairs to accommodate this type of modem in our time-shared user environment. The I/O groups have now been variously modified to support a wide range of applications, from 300 baud acoustic coupled use to 9600 baud for multi-station classroom operation.

当方の主なサポート対象は2400ボーの201Bデータセットだったので、まず16組のI/Oグループのペアを、タイムシェアリングのユーザー環境でこの種類のモデムに対応するように実装しました。現在では、I/Oグループはさまざまに改造され、300ボーの音響カプラーでの利用から、複数端末の教室での9600ボーの運用まで、幅広い用途をサポートしています。

New Consoles

新しいコンソール

In addition to our standard attachments, which are mostly Culler-Fried graphic display consoles and educational classrooms using such consoles, we have a Tektronix 4002A and an NIH General Purpose Graphics Terminal (GPGT).

当方の標準の接続装置は、主にCuller-Friedのグラフィックディスプレイコンソールと、そうしたコンソールを使う教育用の教室ですが、これに加えて、Tektronix 4002AとNIH汎用グラフィック端末（General Purpose Graphics Terminal、GPGT）があります。

The Tektronix terminal can now be operated on the ARPANET and will provide our users with upper and lower case ASCII for easier operation with other sites. A report on this console's capability will be forthcoming.

Tektronixの端末は現在ARPANET上で操作でき、当方のユーザーに大文字と小文字のASCIIを提供するので、他のサイトとの操作が容易になります。このコンソールの機能についての報告は近く出す予定です。

The GPGT was developed by the University of IOWA for use in Bio-Medical applications. The unit is a delay-line refreshed video display with graphic capability and is the only dynamic type display in use on our host computer at present. We are evaluating its performance in our On-Line System environment. Since a user at this terminal is also able to reach into the network, we will have some future comments on its operation for interested persons.

GPGTは、IOWA大学が生物医学（Bio-Medical）の用途のために開発したものです。この装置は、グラフィック機能を持つ、遅延線でリフレッシュするビデオディスプレイで、現在当方のホストコンピューターで使われている唯一のダイナミック型ディスプレイです。当方では、オンラインシステム（On-Line System）の環境でその性能を評価しています。この端末のユーザーはネットワークにもアクセスできるので、関心のある方のために、その操作について今後なんらかの所見をお伝えする予定です。
