RFC 1926

An Experimental Encapsulation of IP Datagrams on Top of ATM

RFC 1926

ATM上でのIPデータグラムの実験的カプセル化

Abstract

概要

This RFC describes a method of encapsulating IP datagrams on top of Acoustical Transmission Media (ATM). This is a non-recommended standard. Distribution of this memo is unnecessary.

このRFCは、音響伝送媒体（Acoustical Transmission Media: ATM）上でIPデータグラムをカプセル化する方法について説明します。これは非推奨の標準です。このメモの配布は不要です。

Status of This Memo

このメモのステータス

This memo provides information for the Internet community. This memo does not specify an Internet standard of any kind. Distribution of this memo is unlimited.

このメモは、インターネットコミュニティーに情報を提供するものです。いかなる種類のインターネット標準も規定するものではありません。このメモの配布は無制限です。

Overview

概要

The modern laptop computer of today often contains the hardware needed to perform wireless communications by using Acoustical Transmission Media, i.e. sound waves. Until this moment there has been no standard on how to run IP on such media. This document is an attempt to fill this silence.

今日の最新のラップトップコンピューターには、音響伝送媒体（Acoustical Transmission Media）、すなわち音波を用いて無線通信を行うために必要なハードウェアが搭載されていることがよくあります。これまで、このような媒体上でIPを動かす方法についての標準はありませんでした。この文書は、この沈黙を埋める試みです。

Frame transmission

フレームの送信

The IP datagram is divided into four-bit chunks, in network beep order, and converted to characters according to the table below. A single "b" character is prepended as a frame start signal, the characters are then transmitted in ordinary morse code by modulating a steady tone on and off. The frequency of this tone is also known as the Acoustical Signature (AS number) of the sender.

IPデータグラムは、ネットワークビープ順（network beep order）で4ビットの塊に分割され、下の表に従って文字に変換されます。フレーム開始の合図として「b」という文字を1つ先頭に付け、その後、一定の音をオンオフ変調することで、各文字を通常のモールス符号で送信します。この音の周波数は、送信者の音響シグネチャー（Acoustical Signature: AS番号）とも呼ばれます。

     Bits    Character       Bits    Character

     0000    "i"             1000    "u"
     0001    "t"             1001    "m"
     0010    "s"             1010    "v"
     0011    "a"             1011    "f"
     0100    "n"             1100    "w"
     0101    "h"             1101    "l"
     0110    "d"             1110    "k"
     0111    "r"             1111    "g"

     Bits    Character       Bits    Character

     0000    "i"             1000    "u"
     0001    "t"             1001    "m"
     0010    "s"             1010    "v"
     0011    "a"             1011    "f"
     0100    "n"             1100    "w"
     0101    "h"             1101    "l"
     0110    "d"             1110    "k"
     0111    "r"             1111    "g"

To allow more than one Local Acoustical Network (LAN) to coexist the use of different AS numbers for different LANs is suggested. This document proposes seven standard AS numbers to be used, see the table below for details.

複数のローカル音響ネットワーク（Local Acoustical Network: LAN）が共存できるように、LANごとに異なるAS番号を使うことを提案します。この文書では、標準のAS番号として7つを使うことを提案します。詳細は下の表を参照してください。

     Name   Frequency

     "a"     440 Hz
     "b"     494 Hz
     "c"     523 Hz
     "d"     587 Hz
     "e"     659 Hz
     "f"     698 Hz
     "g"     784 Hz

     Name   Frequency

     "a"     440 Hz
     "b"     494 Hz
     "c"     523 Hz
     "d"     587 Hz
     "e"     659 Hz
     "f"     698 Hz
     "g"     784 Hz

It is assumed that for normal operation AS number "a", 440 Hz will be used.

通常の運用では、AS番号「a」、つまり440 Hzが使われることを想定しています。

上記の処理を単純に逆の順序で行います。
