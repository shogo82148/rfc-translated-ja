The following documents are draft standards of the MIT X Consortium. To become standards, further "proof of concept" is required, in the form of working implementations. The specifications may be subject to incompatible changes if implementation efforts uncover significant problems.

次の文書は、MIT X Consortiumのドラフト標準です。標準になるには、動作する実装という形で、さらなる「概念実証（proof of concept）」が必要です。実装作業で重大な問題が見つかった場合、これらの仕様には互換性のない変更が加えられることがあります。

Status of This Memo

このメモのステータス

This FYI RFC provides pointers to the published standards of the MIT X Consortium. This memo provides information for the Internet community. It does not specify any Internet standard. Distribution of this memo is unlimited.

このFYI RFCは、MIT X Consortiumが公開している標準の所在を示すものです。このメモは、インターネットコミュニティーに情報を提供するものです。インターネット標準を規定するものではありません。このメモの配布は無制限です。
