RFC 1558

A String Representation of LDAP Search Filters

RFC 1558

LDAP検索フィルターの文字列表現

Abstract

概要

The Lightweight Directory Access Protocol (LDAP) [1] defines a network representation of a search filter transmitted to an LDAP server. Some applications may find it useful to have a common way of representing these search filters in a human-readable form. This document defines a human-readable string format for representing LDAP search filters.

Lightweight Directory Access Protocol（LDAP）[1]は、LDAPサーバーに送信される検索フィルターのネットワーク表現を定義しています。アプリケーションによっては、これらの検索フィルターを人間が読める形式で表現する共通の方法があると便利な場合があります。この文書は、LDAP検索フィルターを表現するための、人間が読める文字列形式を定義します。

Status of this Memo

このメモのステータス

This memo provides information for the Internet community. This memo does not specify an Internet standard of any kind. Distribution of this memo is unlimited.

このメモは、インターネットコミュニティーに情報を提供するものです。このメモは、いかなる種類のインターネット標準も規定するものではありません。このメモの配布は無制限です。

1. LDAP Search Filter Definition

1. LDAP検索フィルターの定義

An LDAP search filter is defined in [1] as follows:

LDAP検索フィルターは、[1]で次のように定義されています。

  Filter ::= CHOICE {
          and                [0] SET OF Filter,
          or                 [1] SET OF Filter,
          not                [2] Filter,
          equalityMatch      [3] AttributeValueAssertion,
          substrings         [4] SubstringFilter,
          greaterOrEqual     [5] AttributeValueAssertion,
          lessOrEqual        [6] AttributeValueAssertion,
          present            [7] AttributeType,
          approxMatch        [8] AttributeValueAssertion
  }

  SubstringFilter ::= SEQUENCE {
          type    AttributeType,
          SEQUENCE OF CHOICE {
                  initial        [0] LDAPString,
                  any            [1] LDAPString,
                  final          [2] LDAPString
          }
  }

  AttributeValueAssertion ::= SEQUENCE
          attributeType   AttributeType,
          attributeValue  AttributeValue
  }

  AttributeType ::= LDAPString

  AttributeValue ::= OCTET STRING

  LDAPString ::= OCTET STRING

  Filter ::= CHOICE {
          and                [0] SET OF Filter,
          or                 [1] SET OF Filter,
          not                [2] Filter,
          equalityMatch      [3] AttributeValueAssertion,
          substrings         [4] SubstringFilter,
          greaterOrEqual     [5] AttributeValueAssertion,
          lessOrEqual        [6] AttributeValueAssertion,
          present            [7] AttributeType,
          approxMatch        [8] AttributeValueAssertion
  }

  SubstringFilter ::= SEQUENCE {
          type    AttributeType,
          SEQUENCE OF CHOICE {
                  initial        [0] LDAPString,
                  any            [1] LDAPString,
                  final          [2] LDAPString
          }
  }

  AttributeValueAssertion ::= SEQUENCE
          attributeType   AttributeType,
          attributeValue  AttributeValue
  }

  AttributeType ::= LDAPString

  AttributeValue ::= OCTET STRING

  LDAPString ::= OCTET STRING

where the LDAPString above is limited to the IA5 character set. The AttributeType is a string representation of the attribute object identifier in dotted OID format (e.g., "2.5.4.10"), or the shorter string name of the attribute (e.g., "organizationName", or "o"). The AttributeValue OCTET STRING has the form defined in [2]. The Filter is encoded for transmission over a network using the Basic Encoding Rules defined in [3], with simplifications described in [1].

ここで、上記のLDAPStringはIA5文字セットに限定されます。AttributeTypeは、ドット区切りのOID形式による属性のオブジェクト識別子の文字列表現（例：「2.5.4.10」）か、属性のより短い文字列名（例：「organizationName」や「o」）です。AttributeValueのOCTET STRINGは、[2]で定義された形式をとります。Filterは、[1]で説明されている簡略化を加えたうえで、[3]で定義されたBasic Encoding Rulesを使って、ネットワーク上で送信するために符号化されます。

2. String Search Filter Definition

2. 文字列による検索フィルターの定義

The string representation of an LDAP search filter is defined by the following BNF. It uses a prefix format.

LDAP検索フィルターの文字列表現は、次のBNFで定義されます。この表現は前置（prefix）形式を使用します。

  <filter> ::= '(' <filtercomp> ')'
  <filtercomp> ::= <and> | <or> | <not> | <item>
  <and> ::= '&' <filterlist>
  <or> ::= '|' <filterlist>
  <not> ::= '!' <filter>
  <filterlist> ::= <filter> | <filter> <filterlist>
  <item> ::= <simple> | <present> | <substring>
  <simple> ::= <attr> <filtertype> <value>
  <filtertype> ::= <equal> | <approx> | <greater> | <less>
  <equal> ::= '='
  <approx> ::= '~='
  <greater> ::= '>='
  <less> ::= '<='
  <present> ::= <attr> '=*'
  <substring> ::= <attr> '=' <initial> <any> <final>
  <initial> ::= NULL | <value>
  <any> ::= '*' <starval>
  <starval> ::= NULL | <value> '*' <starval>
  <final> ::= NULL | <value>

  <filter> ::= '(' <filtercomp> ')'
  <filtercomp> ::= <and> | <or> | <not> | <item>
  <and> ::= '&' <filterlist>
  <or> ::= '|' <filterlist>
  <not> ::= '!' <filter>
  <filterlist> ::= <filter> | <filter> <filterlist>
  <item> ::= <simple> | <present> | <substring>
  <simple> ::= <attr> <filtertype> <value>
  <filtertype> ::= <equal> | <approx> | <greater> | <less>
  <equal> ::= '='
  <approx> ::= '~='
  <greater> ::= '>='
  <less> ::= '<='
  <present> ::= <attr> '=*'
  <substring> ::= <attr> '=' <initial> <any> <final>
  <initial> ::= NULL | <value>
  <any> ::= '*' <starval>
  <starval> ::= NULL | <value> '*' <starval>
  <final> ::= NULL | <value>

<attr> is a string representing an AttributeType, and has the format defined in [1]. <value> is a string representing an AttributeValue, or part of one, and has the form defined in [2]. If a <value> must contain one of the characters '*' or '(' or ')', these characters should be escaped by preceding them with the backslash '\' character.

<attr>はAttributeTypeを表す文字列で、[1]で定義された形式をとります。<value>はAttributeValueまたはその一部を表す文字列で、[2]で定義された形式をとります。<value>に文字'*'、'('、')'のいずれかを含める必要がある場合は、これらの文字の前にバックスラッシュ文字'\'を置いてエスケープすべきです。

3. Examples

3. 例

This section gives a few examples of search filters written using this notation.

このセクションでは、この表記を使って書いた検索フィルターの例をいくつか示します。

  (cn=Babs Jensen)
  (!(cn=Tim Howes))
  (&(objectClass=Person)(|(sn=Jensen)(cn=Babs J*)))
  (o=univ*of*mich*)

  (cn=Babs Jensen)
  (!(cn=Tim Howes))
  (&(objectClass=Person)(|(sn=Jensen)(cn=Babs J*)))
  (o=univ*of*mich*)
