RFC 401

Conversion of NGP-0 Coordinates to Device Specific Coordinates

RFC 401

NGP-0座標からデバイス固有の座標への変換

Abstract

概要

Conversion of NGP-0 coordinates to floating point PDP-10 coordinates was discussed in RFC #387. In general, however, it is undesirable to convert NGP coordinates to floating point coordinates because real devices require integer addressing. To this end, a means is described to convert NGP coordi- nates to integer coordinates in the range zero to M, where M is the maximum address of the device screen on a machine using 2's complement arithmetic. It would not, however, be difficult to modify this algorithm to operate on machines using one's complement or sign-magnitude arithmetic.

NGP-0座標からPDP-10の浮動小数点座標への変換については、RFC #387で議論しました。しかし一般に、実際のデバイスは整数によるアドレス指定を必要とするので、NGP座標を浮動小数点座標に変換するのは望ましくありません。そこで、2の補数演算を使うマシンにおいて、NGP座標を0からMまでの範囲の整数座標に変換する方法を説明します。ここで、Mはデバイスの画面の最大アドレスです。ただし、このアルゴリズムを1の補数演算や符号と絶対値による演算を使うマシンで動作するように変更するのは難しくないでしょう。

First consider the NGP coordinate format:

まず、NGPの座標形式について考えます。

                   +--+-----------+
                   |  |   n       |
                   +--+-----------+
                    s ^  FRACTION
                    i
                    g
                    n

                   +--+-----------+
                   |  |   n       |
                   +--+-----------+
                    s ^  FRACTION
                    i
                    g
                    n

Where the sign occupies the most significant bit of the coordinate followed by bits of numerical information (initial implementation of NGP requires N=15). Negative numbers are represented by 2's complement. Conversion to device coordinates is accomplished by:

ここで、符号は座標の最上位ビットを占め、その後に数値情報のビットが続きます（NGPの初期の実装ではN=15が必要です）。負の数は2の補数で表します。デバイス座標への変換は次の式で行います。

                    D = S * f + S

                    D = S * f + S

Where

ここで、

D
integer device coordinate
S
scaling factor (typically M/2)
f
NGP fractional coordinate
D
整数のデバイス座標
S
スケーリング係数（通常はM/2）
f
NGPの小数座標

Let us rewrite this as:

これを次のように書き直します。

                            n     n
                    D = S*(2 *f)/2 +S

                            n     n
                    D = S*(2 *f)/2 +S

Now factor S into two terms:

次に、Sを2つの項に分解します。

                            I
                    S= Q * 2

                            I
                    S= Q * 2

Where Q is an odd integer and I is an integer.

ここで、Qは奇数の整数、Iは整数です。

When:

このとき、

                             I   n     n
                    D = Q * 2 *(2 *f)/2  +S

                             I-n   n
                      = Q * 2   *(2 *f)  +S

                             I   n     n
                    D = Q * 2 *(2 *f)/2  +S

                             I-n   n
                      = Q * 2   *(2 *f)  +S

The factor (2n*f) is represented in 2's complement form simply by extending the sign bit of f into the upper portion of the computer word, If Q = 1 (as it would be with many devices), it can be ignored. If Q >< 1, we may console ourselves that an integer multiply is faster on most machines than a floating point multiply. In fact, on a PDP-10, this multiply can usually be performed with no access to memory since Q is usually small.

因数(2n*f)は、fの符号ビットをコンピューターのワードの上位部分に拡張するだけで、2の補数形式で表せます。Q = 1の場合（多くのデバイスではそうなるでしょう）、Qは無視できます。Q >< 1の場合でも、ほとんどのマシンでは整数の乗算のほうが浮動小数点の乗算よりも速いことが慰めになるでしょう。実際、PDP-10では、Qは通常小さいので、この乗算はたいていメモリーにアクセスせずに実行できます。

We are now left with the 2I-n factor. This can be accomplished with an arithmetic shift left by (I-n) or an arithmetic shift right by (n-I) as is appropriate. The offset factor, S, may now be added using an integer add.

残るのは2I-nの因数です。これは、必要に応じて(I-n)だけ算術左シフトするか、(n-I)だけ算術右シフトすることで実現できます。あとは、オフセット係数Sを整数の加算で加えればよいのです。

The procedure for converting NGP coordinates to integer device coordinates is then:

したがって、NGP座標を整数のデバイス座標に変換する手順は次のとおりです。

  1. move coordinate to a register and extend sign
  2. integer multiply by Q (if necessary)
  3. arithmetic shift left by (I-n)
  4. integer add S
  1. 座標をレジスターに移し、符号を拡張する
  2. Qを整数で乗算する（必要な場合）
  3. (I-n)だけ算術左シフトする
  4. Sを整数で加算する

This procedure would generally be much faster than:

この手順は、一般に次の手順よりもはるかに速いでしょう。

  1. move coordinate to register and extend sign
  2. float fractional coordinate
  3. floating point multiply
  4. floating point add
  5. conversion to fixed point
  1. 座標をレジスターに移し、符号を拡張する
  2. 小数座標を浮動小数点数に変換する
  3. 浮動小数点の乗算を行う
  4. 浮動小数点の加算を行う
  5. 固定小数点数に変換する
