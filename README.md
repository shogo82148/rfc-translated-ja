# rfc-translated-ja
Japanese translated RFC documents

## ライセンス

このリポジトリには、ライセンスの異なる 3 種類の内容が含まれています。

- **日本語訳**（`src/ja/rfc*.xml` と、`docs/` 以下の HTML の日本語部分）: Copyright (c) ICHINOSE Shogo。[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/deed.ja) でライセンスします。
- **RFC の原文**（`src/rfcs/`、`src/en/`、`src/patches/` と、`docs/` 以下の HTML の英語部分）: 著作権は各文書に記載された著作権者（IETF Trust、Internet Society、または著者）に帰属し、各文書のライセンス条件（[IETF Trust Legal Provisions](https://trustee.ietf.org/documents/trust-legal-provisions/) など）が適用されます。日本語訳はこの条件にもとづいて公開しています。
- **それ以外**（`scripts/` などのツール類）: [MIT License](LICENSE) です。

日本語訳は非公式なもので、正式な文書は英語の原文です。
