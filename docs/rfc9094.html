A YANG Data Model for Wavelength Switched Optical Networks (WSONs)

RFC 9094

波長スイッチ光ネットワーク（WSON）のためのYANGデータモデル

Abstract

概要

This document provides a YANG data model for the routing and wavelength assignment (RWA) TE topology in Wavelength Switched Optical Networks (WSONs). The YANG data model defined in this document conforms to the Network Management Datastore Architecture (NMDA).

この文書は、波長スイッチ光ネットワーク（Wavelength Switched Optical Network: WSON）におけるルーティングと波長割り当て（Routing and Wavelength Assignment: RWA）のTEトポロジーのためのYANGデータモデルを提供します。この文書で定義するYANGデータモデルは、ネットワーク管理データストアアーキテクチャー（NMDA）に準拠しています。

1. Introduction

1. はじめに

This document provides a YANG data model for the routing and wavelength assignment (RWA) Traffic Engineering (TE) topology in transparent Wavelength Switched Optical Networks (WSONs). The YANG data model described in this document is a WSON technology-specific YANG data model based on the information model developed in [RFC7446] and the two encoding documents ([RFC7581] and [RFC7579]) that developed protocol-independent encodings based on [RFC7446].

この文書は、透過的な波長スイッチ光ネットワーク（WSON）におけるルーティングと波長割り当て（RWA）のトラフィックエンジニアリング（TE）トポロジーのためのYANGデータモデルを提供します。この文書で説明するYANGデータモデルは、WSON技術固有のYANGデータモデルであり、[RFC7446]で策定された情報モデルと、[RFC7446]に基づいてプロトコル非依存のエンコーディングを策定した2つのエンコーディング文書（[RFC7581]と[RFC7579]）に基づいています。

[ITU-Tg6982] defines amplified multichannel dense wavelength division multiplexing applications with single-channel optical interfaces. The YANG data model defined in this document refers to the standard application mode defined in [ITU-Tg6982].

[ITU-Tg6982]は、シングルチャネル光インターフェイスを備えた、増幅されたマルチチャネル高密度波長分割多重のアプリケーションを定義しています。この文書で定義するYANGデータモデルは、[ITU-Tg6982]で定義された標準アプリケーションモードを参照します。

Neither impairment-aware optical networks nor flexi-grid are in scope for this document. Refer to [OPT-IMPAIR-AWARE-YANG] for the impairment-aware optical network topology model and [FLEXI-GRID-YANG] for the flexi-grid optical network topology model.

伝送劣化（impairment）を考慮した光ネットワークも、フレキシグリッド（flexi-grid）も、この文書の範囲外です。伝送劣化を考慮した光ネットワークのトポロジーモデルについては[OPT-IMPAIR-AWARE-YANG]を、フレキシグリッド光ネットワークのトポロジーモデルについては[FLEXI-GRID-YANG]を参照してください。

Additionally, neither transponder models nor resource block models (e.g., 3R) are in scope for this document.

さらに、トランスポンダーのモデルも、リソースブロックのモデル（たとえば、3R）も、この文書の範囲外です。

This document defines one YANG module: "ietf-wson-topology" (Section 3). This document augments the generic TE topology specification [RFC8795].

この文書は、1つのYANGモジュール「ietf-wson-topology」（Section 3）を定義します。この文書は、汎用的なTEトポロジーの仕様[RFC8795]を拡張（augment）します。

There are multiple applications for the YANG data model defined in this document. For example, nodes within the network can use the data model to capture their understanding of the overall WSON topology and expose it to a controller. A controller can further propagate the topology to other controllers. The YANG data model is used by NETCONF [RFC6020] [RFC8341] or a RESTCONF [RFC8040] protocol. The YANG data model defined in this document conforms to the Network Management Datastore Architecture [RFC8342].

この文書で定義するYANGデータモデルには、複数の用途があります。たとえば、ネットワーク内のノードは、このデータモデルを使用して、WSONトポロジー全体についての自身の理解を取得し、それをコントローラーに公開できます。コントローラーは、さらにそのトポロジーを他のコントローラーに伝播できます。このYANGデータモデルは、NETCONF[RFC6020] [RFC8341]またはRESTCONF[RFC8040]のプロトコルで使用されます。この文書で定義するYANGデータモデルは、ネットワーク管理データストアアーキテクチャー[RFC8342]に準拠しています。

4. Security Considerations

4. セキュリティーに関する考慮事項

The YANG module specified in this document defines a schema for data that is designed to be accessed via network management protocols such as NETCONF [RFC6241] or RESTCONF [RFC8040]. The lowest NETCONF layer is the secure transport layer, and the mandatory-to-implement secure transport is Secure Shell (SSH) [RFC6242]. The lowest RESTCONF layer is HTTPS, and the mandatory-to-implement secure transport is TLS [RFC8446].

この文書で規定するYANGモジュールは、NETCONF[RFC6241]やRESTCONF[RFC8040]などのネットワーク管理プロトコルを介してアクセスされるように設計されたデータのスキーマを定義します。NETCONFの最下層はセキュアなトランスポート層であり、実装必須のセキュアなトランスポートはSecure Shell（SSH）[RFC6242]です。RESTCONFの最下層はHTTPSであり、実装必須のセキュアなトランスポートはTLS[RFC8446]です。

The NETCONF protocol over Secure Shell (SSH) specification [RFC6242] describes a method for invoking and running NETCONF within a Secure Shell (SSH) session as an SSH subsystem. The NETCONF access control model [RFC8341] provides the means to restrict access for particular NETCONF or RESTCONF users to a preconfigured subset of all available NETCONF or RESTCONF protocol operations and content.

NETCONF over Secure Shell（SSH）の仕様[RFC6242]は、Secure Shell（SSH）セッション内でSSHサブシステムとしてNETCONFを起動して実行する方法を説明しています。ネットワーク設定アクセス制御モデル[RFC8341]は、特定のNETCONFまたはRESTCONFのユーザーのアクセスを、利用可能なすべてのNETCONFまたはRESTCONFのプロトコル操作とコンテンツのうち、事前に設定されたサブセットに制限する手段を提供します。

There are a number of data nodes defined in this YANG module that are writable/creatable/deletable (i.e., config true, which is the default). These data nodes may be considered sensitive or vulnerable in some network environments. Write operations (e.g., edit-config) to these data nodes without proper protection can have a negative effect on network operations. Considerations in Section 8 of [RFC8795] are also applicable to the module defined in this document.

このYANGモジュールには、書き込み可能/作成可能/削除可能な（つまり、デフォルトである「config true」の）データノードが多数定義されています。これらのデータノードは、一部のネットワーク環境では機密性が高い、または脆弱であるとみなされる場合があります。適切な保護なしにこれらのデータノードへの書き込み操作（たとえば、edit-config）を行うと、ネットワークの運用に悪影響を及ぼす可能性があります。[RFC8795]のSection 8の考慮事項は、この文書で定義するモジュールにも適用されます。

Some of the readable data nodes in this YANG module may be considered sensitive or vulnerable in some network environments. It is thus important to control read access (e.g., via get, get-config, or notification) to these data nodes. Considerations in Section 8 of [RFC8795] are also applicable to the module defined in this document.

このYANGモジュール内の読み取り可能なデータノードの一部は、一部のネットワーク環境では機密性が高い、または脆弱であるとみなされる場合があります。したがって、これらのデータノードへの読み取りアクセス（たとえば、get、get-config、または通知を介したもの）を制御することが重要です。[RFC8795]のSection 8の考慮事項は、この文書で定義するモジュールにも適用されます。

Finally, the YANG module described in this document augments the "ietf-network" YANG module [RFC8345] and the "ietf-te-topology" YANG module [RFC8795] by adding data nodes. The security considerations for the subtrees described in those RFCs apply equally to the new data nodes that this module adds.

最後に、この文書で説明するYANGモジュールは、データノードを追加することによって、「ietf-network」YANGモジュール[RFC8345]と「ietf-te-topology」YANGモジュール[RFC8795]を拡張（augment）します。それらのRFCで説明されているサブツリーに関するセキュリティーに関する考慮事項は、このモジュールが追加する新しいデータノードにも同様に適用されます。
