RFC 127

Comments on RFC 123

RFC 127

RFC 123へのコメント

Abstract

概要

The following is my interpretation of the exchange between NCP's which would be necessary to carry out the Initial Connection Protocol of RFC 123.

以下は、RFC 123の初期接続プロトコル（Initial Connection Protocol）を実行するために必要となるNCP間のやり取りについての、私の解釈です。

     Server NCP                                User NCP
     ----------                                --------

     Listen for Connection on L                RTS, U, L, l
     STR, L, U, 32                                         A

     Send 32 bits of data
     in 1 message on link l
                           A
     (value is S)                              Receive 32 bits of data
                                               from link l (value is S)
                                                          A

     CLS, L, U                                 CLS, U, L

     STR, S+1, U, B                            STR, U+1, S, B
                   s                                         u

     RTS, S, U+1, l                            RTS, U, S+1, l
                   B                                         c

     wait for connection                       wait for connection

     ALL, l , m , b                            ALL, l , m , b
           B   B   B                                 c   c   c

     data sent on link l                       data sent on link l
                        c                                         B

     data received on link l                   data received on link l
                            B                                         c

     Server NCP                                User NCP
     ----------                                --------

     Listen for Connection on L                RTS, U, L, l
     STR, L, U, 32                                         A

     Send 32 bits of data
     in 1 message on link l
                           A
     (value is S)                              Receive 32 bits of data
                                               from link l (value is S)
                                                          A

     CLS, L, U                                 CLS, U, L

     STR, S+1, U, B                            STR, U+1, S, B
                   s                                         u

     RTS, S, U+1, l                            RTS, U, S+1, l
                   B                                         c

     wait for connection                       wait for connection

     ALL, l , m , b                            ALL, l , m , b
           B   B   B                                 c   c   c

     data sent on link l                       data sent on link l
                        c                                         B

     data received on link l                   data received on link l
                            B                                         c

lA, lB, and lc are links, mB and mc are message allocations, bB and bc are bit allocations, and all other symbols are as defined in RFC 123.

lA、lB、lcはリンク、mBとmcはメッセージ割り当て、bBとbcはビット割り当てで、その他の記号はすべてRFC 123での定義どおりです。
