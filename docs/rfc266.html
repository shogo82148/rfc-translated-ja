RFC 266

Network host status

RFC 266

ネットワークホストの状態

Abstract

概要

This RFC reports on the status of most.Network Hosts from October 26 to November 5. (Massachusetts celebrated Armistice day on Monday, October 25.) During these two weeks the general status of these hosts remained as it had been previously.

このRFCでは、10月26日から11月5日までの、ほとんどのネットワークホストの状態を報告します（マサチューセッツ州では、10月25日の月曜日に休戦記念日を祝いました）。この2週間、これらのホストの全般的な状態は、以前と変わりませんでした。

where

ここで、

D=
Dead (Destination Host either dead or inaccessible [due to network partitioning or local IMP failure] from the BBN Terminal IMP.)
R=
Refused (Destination Host returned a CLS to the initial RFC.)
T=
Timed out (Destination Host did not respond in any way to the initial RFC, although not dead.)
H=
1/2 Open (Destination Host opened a connection but then either immediately closed it, or did not respond any further.)
O=
Open (Destination Host opened a connection and was accessible to users.)
D=
Dead（停止。宛先ホストが停止しているか、BBNの端末IMPから［ネットワークの分断やローカルのIMPの障害のため］アクセスできない）
R=
Refused（拒否。宛先ホストが最初のRFC（接続要求）に対してCLSを返した）
T=
Timed out（タイムアウト。宛先ホストは停止していないが、最初のRFCにまったく応答しなかった）
H=
1/2 Open（半開。宛先ホストはコネクションを開いたが、その後すぐに閉じたか、それ以上応答しなかった）
O=
Open（開。宛先ホストがコネクションを開き、ユーザーがアクセスできた）

* The UCLA IBM-360/91 currently has Remote Job Service (NETRJS), but has not implemented a full server Telnet System. The BBN Terminal IMP is not equipped to test NETRJS; however, we are assuming that receipt of the UCLA explanatory message indicates that NETRJS is also functioning.

* UCLAのIBM-360/91は現在、リモートジョブサービス（Remote Job Service、NETRJS）を備えていますが、完全なサーバーTelnetシステムは実装していません。BBNの端末IMPはNETRJSをテストする設備を備えていません。ただし、UCLAの説明メッセージを受信できたことは、NETRJSも機能していることを示すものと見なしています。
