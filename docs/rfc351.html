(Graphics)Information form for the ARPANET Graphics Resources Notebook:

RFC 351

(Graphics) ARPANET Graphics Resources Notebookのための情報フォーム：

Abstract

概要

Attached is a questionnaire about the state of graphics resources at your site. As per the last Graphics Protocol Committee meeting, we are attempting to compile such information for an ARPANET Graphics Resources Notebook.

各サイトのグラフィックス資源の状況に関するアンケートを添付します。前回のGraphics Protocol Committeeの会議で決まったとおり、私たちはARPANET Graphics Resources Notebookのために、このような情報をまとめようとしています。

Please complete the form and return it as soon as possible, preferably as a NIC Journal entry (making it easier for us to manipulate the information) to Dave Crocker (Nic Ident: DHC). Mailing address:

フォームに記入し、できるだけ早くDave Crocker（NIC ident：DHC）宛てに返送してください。できればNIC Journalのエントリーとして送ってください（そのほうが私たちが情報を扱いやすくなります）。郵送先：
