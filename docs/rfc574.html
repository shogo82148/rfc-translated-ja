RFC 574

Announcement of a Mail Facility at UCSB

RFC 574

UCSBにおけるメール機能のお知らせ

Abstract

概要

There now exists a server program at UCSB, resident under socket 3, which supports that subset of the File Transfer Protocol necessary for mail delivery. Only the MAIL and BYE commands are implemented at this time.

現在UCSBには、ソケット3で待ち受けるサーバープログラムがあり、ファイル転送プロトコル（File Transfer Protocol）のうちメール配送に必要なサブセットをサポートしています。現時点で実装されているのは、MAILコマンドとBYEコマンドだけです。

Mail may be sent to an individual at UCSB by specifying his local user name in the MAIL command. The following is a list of those individuals currently defined as valid recipients of Network mail, each with their respective user name: Ed Faeh (FAEH), Jim Guyton (GUYTON), Mark Krilanovich (KRILANOV), Curtis Mosso (MOSSO), John Pickens (PICKENS), and Ron Stoughton (STOUGHTN). In addition, any general comments or complaints about UCSB services may be sent to user name GRIPE.

UCSBの個人にメールを送るには、MAILコマンドでその人のローカルユーザー名を指定します。現在ネットワークメールの有効な受信者として定義されている個人と、それぞれのユーザー名は次のとおりです：Ed Faeh（FAEH）、Jim Guyton（GUYTON）、Mark Krilanovich（KRILANOV）、Curtis Mosso（MOSSO）、John Pickens（PICKENS）、Ron Stoughton（STOUGHTN）。また、UCSBのサービスに関する一般的なご意見や苦情は、ユーザー名GRIPEに送ってください。
