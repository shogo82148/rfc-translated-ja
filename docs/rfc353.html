Network host status

RFC 353

ネットワークホストの状態

Abstract

概要

This RFC reports on the status of most Network Hosts from May 22 to June 2.

このRFCでは、5月22日から6月2日までの、ほとんどのネットワークホストの状態を報告します。

No testing was done on Memorial Day, which Massachusetts celebrated on May 29. No testing was done on May 31 and June 1 due to an attempt to install the new IMP system.

マサチューセッツ州で5月29日に祝われた戦没将兵追悼記念日（Memorial Day）には、テストを行いませんでした。5月31日と6月1日は、新しいIMPシステムの導入を試みたため、テストを行いませんでした。

Three new terminal IMPs were installed during this interval. On June 1, Terminal IMP #155 was installed at Fort Belvoir in Fairfax, Virginia; on June 3, Terminal IMP #154 was installed at SAAC (Seismic Array Analysis Center) in Alexandria, Virginia; and on June 5, Terminal IMP #153 was installed at NOAA (National Oceanic Analysis Agency) in Boulder, Colorado.

この期間に、3台の新しい端末IMPが設置されました。6月1日には端末IMP #155がバージニア州フェアファックスのフォートベルボア（Fort Belvoir）に、6月3日には端末IMP #154がバージニア州アレクサンドリアのSAAC（Seismic Array Analysis Center）に、6月5日には端末IMP #153がコロラド州ボルダーのNOAA（National Oceanic Analysis Agency）に設置されました。

Several Hosts are currently excluded from the daily testing. These Hosts fall into two categories:

現在、いくつかのホストは日々のテストの対象から外れています。これらのホストは次の2つの種類に分けられます。

1) Hosts which are not expected to be functioning on the Network as servers (available for use from other sites) on a regular basis for at least two weeks. The only Host in this category is the PDP-10 at Case (Network address 13).

1）少なくとも2週間は、ネットワーク上でサーバーとして（ほかのサイトから利用できる状態で）定常的に機能する見込みのないホスト。この種類に該当するホストは、CaseのPDP-10（ネットワークアドレス13）だけです。

2) Hosts which are currently intended to be users only. Included here are the Terminal IMPs, which are presently in the Network (AMES, MITRE, NBS, ETAC, USC, GWC, NOAA, SAAC, BELVOIR, and BBN*). This category also includes the Network Control Center computer (Network address 5) which is used solely for gathering statistics from the Network. Finally, included among these Hosts are the following:

2）現在、ユーザーとしてのみ使うことを想定しているホスト。これには、現在ネットワークに接続されている端末IMP（AMES、MITRE、NBS、ETAC、USC、GWC、NOAA、SAAC、BELVOIR、BBN*）が含まれます。この種類には、ネットワークから統計情報を収集するためだけに使われるネットワークコントロールセンター（Network Control Center）のコンピューター（ネットワークアドレス5）も含まれます。最後に、これらのホストには次のものも含まれます。

where

ここで、

D =
Dead (Destination Host either dead or inaccessible [due to network partitioning or local IMP failure] from the BBN Terminal IMP.)
F =
Full (Destination Host opened a connection, informed user that all Network ports were in use, and immediately closed the connection.)
H =
1/2 Open (Destination Host opened a connection but then either immediately closed it, or did not respond any further.)
O =
Open (Destination opened a connection and was accessible to us.
R =
Refused (Destination Host returned a CLS to the initial RFC.)
T =
Timed out (Destination Host did not complete the ICP and open a connection within 60 seconds.)
D =
Dead（停止。宛先ホストが停止しているか、BBNの端末IMPから［ネットワークの分断やローカルのIMPの障害のため］アクセスできない）
F =
Full（満杯。宛先ホストはコネクションを開き、ネットワークのポートがすべて使用中であることをユーザーに通知して、すぐにコネクションを閉じた）
H =
1/2 Open（半開。宛先ホストはコネクションを開いたが、その後すぐに閉じたか、それ以上応答しなかった）
O =
Open（開。宛先がコネクションを開き、私たちがアクセスできた）
R =
Refused（拒否。宛先ホストが最初のRFC（接続要求）に対してCLSを返した）
T =
Timed out（タイムアウト。宛先ホストが60秒以内にICPを完了してコネクションを開かなかった）
