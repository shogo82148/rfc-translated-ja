RFC 629

Scenario for using the Network Journal

RFC 629

Network Journalを使うためのシナリオ

Abstract

概要

Network users may send mail to individuals and to groups, input as messages or entire files, through the Network Journal, using SNDMSG or their site's mail system. The mail is converted at NIC into NLS files, Journalized, and sent to specified recipients. Short messages may be received as messages, longer ones as citations to files which may be retrieved immediately, and also later, by using FTP. Mail sent to NIC with a "/" in the user-name field invokes the Net Journal.

ネットワークユーザーは、SNDMSGまたは自サイトのメールシステムを使い、Network Journalを通じて個人やグループにメールを送ることができます。メールは、メッセージとして入力することも、ファイル全体として入力することもできます。メールはNICでNLSファイルに変換され、Journalに登録（Journalized）されて、指定された受信者に送られます。短いメッセージはメッセージとして受け取ることができ、長いものはファイルへの引用（citation）として受け取ります。そのファイルは、FTPを使ってすぐに取り出すことも、後から取り出すこともできます。ユーザー名フィールドに「/」を含めてNICに送ったメールは、Net Journalを呼び出します。

SENDING THE MESSAGE OR FILE BY TELEX SNDMSG

TELEX SNDMSGによるメッセージやファイルの送信

Construct user field with slash and NIC idents:

スラッシュとNIC識別子（ident）を使って、ユーザーフィールドを組み立てます。

      [Users:] sender ident/addressee ident(s)@NIC

      [Users:] sender ident/addressee ident(s)@NIC

e.g. "JEW/DHC MAP@NIC". To send to a group, use group ident, e.g. "JEW/NLG@NIC". To combine Journal SNDMSG with SNDMSG to others, add others' Network addresses after commas, e.g. "JEW/DHC@NIC,PRATT@ISI". See ARPANET Directory for NIC idents and Network addresses.

例：「JEW/DHC MAP@NIC」。グループに送るには、グループの識別子を使います（例：「JEW/NLG@NIC」）。JournalへのSNDMSGとほかの人へのSNDMSGを組み合わせるには、カンマの後にほかの人のネットワークアドレスを追加します（例：「JEW/DHC@NIC,PRATT@ISI」）。NIC識別子とネットワークアドレスについては、ARPANET Directoryを参照してください。

   [@] SNDMSG <CR>
   [Type ? for help]
   [Users:] JEW/NGG <SP> DHC@NIC, PRATT@ISI <CR>
   [Subject:] Title of Message <CR>
   [Message (? for help):] Text of message ...

   [@] SNDMSG <CR>
   [Type ? for help]
   [Users:] JEW/NGG <SP> DHC@NIC, PRATT@ISI <CR>
   [Subject:] Title of Message <CR>
   [Message (? for help):] Text of message ...

Note: ^B allows insertion of a sequential file as the message or at any point in the test of the message:

注：^Bを使うと、シーケンシャルファイルを、メッセージとして、またはメッセージのテキスト中の任意の位置に挿入できます。

      ^B [(Insert file:)] <directory>file <ALT> [ext ...EOF)]
   <^Z>
   [jew/ngg dhc@nic -- ok]   (or [ -- queued -- timed-out])
   [pratt@isi -- ok]

      ^B [(Insert file:)] <directory>file <ALT> [ext ...EOF)]
   <^Z>
   [jew/ngg dhc@nic -- ok]   (or [ -- queued -- timed-out])
   [pratt@isi -- ok]

When using SNDMSG through TELNET, change TELNET escape character, to ^Q for example, allowing ^Z to be used for end-of-message.

TELNET経由でSNDMSGを使う場合は、TELNETのエスケープ文字をたとえば^Qに変更して、^Zをメッセージの終わりを示すために使えるようにしてください。

RETRIEVING THE FILE FROM NETWORK JOURNAL

Network Journalからのファイルの取り出し

Substitute the citation received, for example "<GJOURNAL>21695", for "<journal>number" and supply a filename in the following:

次の手順で、「<journal>number」を受け取った引用（たとえば「<GJOURNAL>21695」）に置き換え、ファイル名を指定します。

   [@] FTP <CR>
   [HOST FTP User process x.xx.x]
   [*] CONN <SP> NIC <CR>
   [   Connection opened]
   [*< OFFICE-1 FTP Server x.xx.x - at DAY DATE TIME]
   [*] LOG <SP> ANONYMOUS <SP> NIC <CR>
   [*] GET <SP> <journal>number.NLS;xnls <CR>
   [   to local file] filename <CR> [New file] <CR>
   [<  IMAGE retrieve of <journal>number.NLS; started]
   [<  transfer completed]
   [*] DISC <CR>
   [*] QUIT <CR>

   [@] COP <ALT> [<File list>] file <ALT> [<TO>] LPT: <CR> [OK] <CR>

   [@] FTP <CR>
   [HOST FTP User process x.xx.x]
   [*] CONN <SP> NIC <CR>
   [   Connection opened]
   [*< OFFICE-1 FTP Server x.xx.x - at DAY DATE TIME]
   [*] LOG <SP> ANONYMOUS <SP> NIC <CR>
   [*] GET <SP> <journal>number.NLS;xnls <CR>
   [   to local file] filename <CR> [New file] <CR>
   [<  IMAGE retrieve of <journal>number.NLS; started]
   [<  transfer completed]
   [*] DISC <CR>
   [*] QUIT <CR>

   [@] COP <ALT> [<File list>] file <ALT> [<TO>] LPT: <CR> [OK] <CR>

SENDING A MESSAGE BY TELNET, FTP, OR OTHER MAIL SYSTEM

TELNET、FTP、またはその他のメールシステムによるメッセージの送信

TENEXユーザーによるTELNET：

      [@] TELNET <CR>
      [User Telnet x.x DATE ...]
      [#] NIC <SP> FTP <CR> [is complete.#]
      [300 OFFICE-1 FTP Server x.xx.x - at DAY DATE TIME]
      MAIL <SP> JEW/RWW <SP> DHC <CR>   (pause)
      [350 Type mail, ended by a line with only a "."]
      Re: Title of Message <CR>
      First line of message <CR>
      second line of message <CR>   ...etc.
       . <CR>   (pause)

      <^Z>

      [#] QUIT <CR>

Using Other Mail Systems:

その他のメールシステムの使用：

It is not possible to give a generalized scenario for use with all local mail systems.

すべてのローカルメールシステムで使える汎用的なシナリオを示すことはできません。

The general procedure, to be applied to the local mail system, is to supply:

ローカルメールシステムに適用する一般的な手順は、次のものを指定することです。

"NIC" as the host name, and

ホスト名として「NIC」、および

Sender's NIC ident / Addressee's NIC ident as user name

ユーザー名として「送信者のNIC識別子 / 宛先のNIC識別子」

See RFC543, NIC 17777, for more detail on Network Journal.

Network Journalの詳細については、RFC543（NIC 17777）を参照してください。
