RFC 688

Tentative Schedule for the New TELNET Implementation for the TIP

RFC 688

TIPにおける新しいTELNETの実装の暫定スケジュール

Abstract

概要

Implementation of the New TELNET Protocol has now become the top priority item on the TIP development queue. Because what is done in the TIP potentially affects what is done at a number of hosts, below we give the implementation schedule to which we hope to adhere.

新しいTELNETプロトコル（New TELNET Protocol）の実装は、今やTIPの開発キューの最優先項目になりました。TIPで行うことは多くのホストで行うことに影響する可能性があるため、以下に、私たちが守りたいと考えている実装スケジュールを示します。

  • July 18, 1975 -- Done with the basic design. A version of the TIP which has a general version of the option negotiator, but refuses all options, operational.
  • Mid-September, 1975 -- Design of the options done. A version of the TIP which includes any modifications that are necessary to support the options operational.
  • Mid-November -- Operational version of the TIP with the basic set of options implemented (Binary Transmission, Echo, Suppress Go-Ahead, Timing Mark, RCTE).
  • End of 1975 -- Any problems with hosts worked out, any necessary revisions done, and a solid version of the TIP up and running the TELNET Protocol with options.
  • 1975年7月18日 -- 基本設計を完了。すべてのオプションを拒否するものの、汎用版のオプションネゴシエーターを備えたTIPのバージョンが稼働。
  • 1975年9月中旬 -- オプションの設計を完了。オプションのサポートに必要な修正をすべて含むTIPのバージョンが稼働。
  • 11月中旬 -- 基本的なオプション群（Binary Transmission、Echo、Suppress Go-Ahead、Timing Mark、RCTE）を実装したTIPの稼働版。
  • 1975年末 -- ホストとの問題をすべて解決し、必要な改訂をすべて完了して、オプション付きのTELNETプロトコルを実行する安定版のTIPが稼働。
