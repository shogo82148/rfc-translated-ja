RFC 620

Request for monitor host table updates

RFC 620

モニターのホストテーブル更新の依頼

Abstract

概要

The ARC/NIC group has successfully been running OFFICE-1 for several weeks now. Our NIC users have been transferred to that site, and are receiving all their computation from TYMSHARE. In conjunction with this change, we would like all sites to change their monitor HOST tables, effective Friday, March 8, 1974.

ARC/NICグループは、ここ数週間、OFFICE-1の運用に成功しています。NICのユーザーはそのサイトに移行しており、すべての計算処理をTYMSHAREから受けています。この変更に伴い、すべてのサイトにおいて、1974年3月8日（金）から有効となるように、モニターのHOSTテーブルを変更していただきたいと考えています。

The net change we wish to accomplish is the following:

実現したい変更の内容は次のとおりです。

  1. Site 53 (octal) is OFFICE-1
  2. Site 2 is SRI-ARC
  3. The nickname for site 2 is ARC (not NIC)
  4. The nickname for site 53 is NIC
  1. サイト53（8進数）はOFFICE-1です
  2. サイト2はSRI-ARCです
  3. サイト2のニックネームはARCです（NICではありません）
  4. サイト53のニックネームはNICです

Please note that now that NIC services are available from OFFICE-1, they rather than SRI-ARC should be accessed over the network as "NIC".

NICのサービスがOFFICE-1から提供されるようになったため、ネットワーク経由で「NIC」としてアクセスする先は、SRI-ARCではなくOFFICE-1になりますので、ご注意ください。

To effect this change, each TENEX site's monitor host table should be updated in the following manner. The actual host name section should contain the following entries (they may already be present).

この変更を反映するには、各TENEXサイトのモニターのホストテーブルを次のように更新する必要があります。実際のホスト名のセクションには、次のエントリーを含めてください（すでに存在している場合もあります）。

CC.(2,SR1-ARC,USER!SERVER!TENEX)
CC.(253,TYMSHARE-TIP,USER!TIP)
CC.(53,OFFICE-1,USER!SERVER!TENEX)

CC.(2,SR1-ARC,USER!SERVER!TENEX)
CC.(253,TYMSHARE-TIP,USER!TIP)
CC.(53,OFFICE-1,USER!SERVER!TENEX)

Further, the NICKNAME table should contain the following entries. The entry for NIC should be changed to refer to site 53 (octal), and a new entry for ARC should be added. Specifically, they are:

さらに、NICKNAMEテーブルには次のエントリーを含めてください。NICのエントリーはサイト53（8進数）を参照するように変更し、ARCのエントリーを新たに追加します。具体的には次のとおりです。

CC.(2,ARC,NICKNAME!SERVER!USER!TENEX)

CC.(53,NIC,NICKNAME!SERVER!USER!TENEX)

CC.(2,ARC,NICKNAME!SERVER!USER!TENEX)

CC.(53,NIC,NICKNAME!SERVER!USER!TENEX)

Other Network sites, not running TENEX, should make these changes in a manner consistent with their operating system.

TENEXを実行していないその他のネットワークサイトは、それぞれのオペレーティングシステムに合った方法でこれらの変更を行ってください。

As mentioned above, these changes are effective on March 8. We will inform all our users to use the nickname NiC in reference to OFFICE-1 as of this date. Thank you for your co-operation.

前述のとおり、これらの変更は3月8日から有効になります。この日から、OFFICE-1を指すにはニックネームNiCを使うよう、当方のすべてのユーザーに周知します。ご協力に感謝します。
