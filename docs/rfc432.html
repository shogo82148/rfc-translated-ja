RFC 432

Network Logical Map

RFC 432

ネットワーク論理マップ

Abstract

概要

Attached is the logical map of the network as of December 30, 1972. The ovals indicate the host computers that we think are connected to each IMP, with the double oval implying an interface. If there are any errors in the map or if your status vis-a-vis connected hosts, is going to change within the next few months, please contact:

1972年12月30日時点のネットワークの論理マップを添付します。楕円は、各IMPに接続されていると私たちが考えているホストコンピューターを示し、二重の楕円はインターフェイスがあることを示します。マップに誤りがある場合や、接続されているホストに関する状況が今後数か月以内に変わる予定の場合は、次の連絡先までご連絡ください。

Cambridge, Ma. 02138
