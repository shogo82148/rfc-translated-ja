RFC 659

Announcing Addtional Telnet Options

RFC 659

追加のTelnetオプションのお知らせ

Abstract

概要

This is to announce the set of Telnet Options defined in Request For Comments 651 through 658 (NIC 31154 through 31161) are part of the official Telnet Options and should be added to the Protocol Notebook.

Request For Comments 651から658（NIC 31154から31161）で定義された一連のTelnetオプションが公式のTelnetオプションの一部となり、Protocol Notebookに追加されるべきであることをお知らせします。

RFC 651 is a revision of the Status Option to utilize the subcommand feature and reduce the number of bits required to convey the status information. This revised Status Option replaces the previous Status Option.

RFC 651は、サブコマンド機能を利用し、状態情報を伝えるのに必要なビット数を減らすように、Status Optionを改訂したものです。この改訂版のStatus Optionは、以前のStatus Optionを置き換えます。

The other RFCs (652 through 658) are new Options for controlling the behavior of the format effector characters Carriage Return, Horizontal Tab, Form Feed, Vertical Tab, and Line Feed.

ほかのRFC（652から658）は、書式制御文字（format effector）であるCarriage Return、Horizontal Tab、Form Feed、Vertical Tab、Line Feedの動作を制御するための新しいオプションです。

Your attention is also called to RFC 645 (NIC 30899) "Network Standard Data Specification Syntax" which was prepared some time ago but has not received wide circulation.

また、RFC 645（NIC 30899）「Network Standard Data Specification Syntax」にも注目してください。この文書はしばらく前に作成されましたが、広くは配布されていません。

Unfortunately the Network Information Center can not provide hardcopy documents. Currently the author is responsible for distribution of RFCs.

あいにく、Network Information Centerはハードコピーの文書を提供できません。現在は、著者がRFCの配布を担当しています。
