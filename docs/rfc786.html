RFC 786

Mail Transfer Protocol: ISI TOPS20 MTP-NIMAIL interface

RFC 786

メール転送プロトコル：ISI TOPS20のMTP-NIMAILインターフェイス

INTRODUCTION

はじめに

This document defines the ISI TOPS20s interface between the Mail Transfer Protocol (MTP) and the Network Independent Mail Protocol (NIMAIL) in terms of the files which implement it. The internal structure and name of each file is described below.

この文書では、メール転送プロトコル（Mail Transfer Protocol、MTP）とネットワーク非依存メールプロトコル（Network Independent Mail Protocol、NIMAIL）の間のISI TOPS20のインターフェイスを、それを実装するファイルの観点から定義します。各ファイルの内部構造と名前を以下に説明します。

For a complete understanding of the MTP protocol as well as the terms used within this document, see RFC 780 "Mail Transfer Protocol", RFC 784 "ISI TOPS20 Implementation", and RFC 785 "ISI TOPS20 File Defintitions". The NIMAIL is documented in IEN 169, "A Simple NIFTP-Based Mail System".

MTPプロトコルとこの文書で使われる用語を完全に理解するには、RFC 780「Mail Transfer Protocol」、RFC 784「ISI TOPS20 Implementation」、RFC 785「ISI TOPS20 File Defintitions」を参照してください。NIMAILについては、IEN 169「A Simple NIFTP-Based Mail System」に記載されています。

DESCRIPTION

説明

  1. NIMAIL to MTP

    NIMAIL will present mail for processing by MTP using the files specified in RFC 785.

  2. MTP to NIMAIL

    MTP will present mail for processing by NIMAIL in files of the following form:

       address <CR><LF>
   address <CR><LF>
   address <CR><LF>
   <CR><LF>
   Via: USC-ISIE; date-time <CR><LF>
   header
    .
    .
    .
   <CR><LF>
   body
    .
    .
    .

    Where each address is of the form:

          user%host%host%host@host

    And each address in the same file has the same "@host" part.

    The date-time will be in the default TOPS20 ODTIM format "dd-mmm-yy hh:mm:ss" (24 hour time).

    The files will named "arbitrary.NIMAIL.-1", where "arbitrary" will be somesort of date-time encoding for human uses. The NIMAIL will not care in the least what the "arbitrary" part is. These files will be placed into the NIMAIL directory on ISIE.

  1. NIMAILからMTPへ

    NIMAILは、RFC 785で規定されたファイルを使って、MTPが処理するメールを渡します。

  2. MTPからNIMAILへ

    MTPは、NIMAILが処理するメールを、次の形式のファイルで渡します。

       address <CR><LF>
   address <CR><LF>
   address <CR><LF>
   <CR><LF>
   Via: USC-ISIE; date-time <CR><LF>
   header
    .
    .
    .
   <CR><LF>
   body
    .
    .
    .

    ここで、各addressは次の形式です。

          user%host%host%host@host

    また、同じファイル内の各addressは同じ「@host」部分を持ちます。

    date-timeは、TOPS20のODTIMのデフォルト形式「dd-mmm-yy hh:mm:ss」（24時間制）になります。

    ファイルの名前は「arbitrary.NIMAIL.-1」になります。ここで「arbitrary」は、人が使うための何らかの日時のエンコーディングです。NIMAILは「arbitrary」部分が何であってもまったく気にしません。これらのファイルはISIE上のNIMAILディレクトリーに置かれます。

DISCUSSION

議論

The NIMAIL and MTP will each perform a transformation of the address information to create the appropriate input for the other system.

NIMAILとMTPはそれぞれ、アドレス情報を変換して、相手のシステムに適した入力を作成します。

NIMAIL to MTP

The mail that arrives at NIMAIL with the information

   joe%hostx%hosty%hostz@isie

will be presented to MTP with the information

   FROM: <NIMAIL@ISIE>
   TO: <@hostz,@hosty,joe@hostx>
MTP to NIMAIL

The mail that arrives at MTP with the information

   FROM: <sam@SRI-NIC>
   TO: <@ISIE,@hostz,@hosty,joe@hostx>

will be presented to NIMAIL with the information

   joe%hostx%hosty@hostz

   Via: ISIE
NIMAILからMTPへ

次の情報を持ってNIMAILに届いたメールは、

   joe%hostx%hosty%hostz@isie

次の情報を持ってMTPに渡されます。

   FROM: <NIMAIL@ISIE>
   TO: <@hostz,@hosty,joe@hostx>
MTPからNIMAILへ

次の情報を持ってMTPに届いたメールは、

   FROM: <sam@SRI-NIC>
   TO: <@ISIE,@hostz,@hosty,joe@hostx>

次の情報を持ってNIMAILに渡されます。

   joe%hostx%hosty@hostz

   Via: ISIE
