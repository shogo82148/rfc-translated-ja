RFC 4569

Internet Assigned Numbers Authority (IANA) Registration of the Message Media Feature Tag

RFC 4569

messageメディアフィーチャータグのIANA（Internet Assigned Numbers Authority）への登録

Abstract

概要

This document registers with the IANA a new media feature tag associated with the 'message' media type. This media feature tag indicates that a particular device supports 'message' as a streaming media type. Media feature tags can be used to route calls to devices that support certain features.

この文書は、'message'メディアタイプに関連する新しいメディアフィーチャータグ（media feature tag）をIANAに登録します。このメディアフィーチャータグは、特定のデバイスがストリーミングメディアタイプとして'message'をサポートしていることを示します。メディアフィーチャータグは、特定の機能をサポートするデバイスに呼（call）をルーティングするために使用できます。

1. Introduction

1. はじめに

The Session Description Protocol (SDP) specification [5] defines a number of media types. RFC 3840 [4] registers with the IANA media feature tags associated with all those media types except for the 'message' media type. This document registers a new media feature tag that is associated with the 'message' media type.

セッション記述プロトコル（SDP: Session Description Protocol）の仕様[5]は、多数のメディアタイプを定義しています。RFC 3840 [4]は、それらのメディアタイプのうち'message'メディアタイプを除くすべてに関連するメディアフィーチャータグをIANAに登録しています。この文書は、'message'メディアタイプに関連する新しいメディアフィーチャータグを登録します。

The reason why the 'message' media feature tag was not registered by RFC 3840 was that when RFC 3840 was published, the SDP specification was RFC 2327 [1]. RFC 3840 defined media feature tags for all the media types defined by RFC 2327. However, RFC 2327 did not define the 'message' media type. This media type was defined by the revised SDP specification [5], which was published after RFC 3840.

'message'メディアフィーチャータグがRFC 3840で登録されなかった理由は、RFC 3840が公開された時点でのSDPの仕様がRFC 2327 [1]だったからです。RFC 3840は、RFC 2327で定義されたすべてのメディアタイプについてメディアフィーチャータグを定義しました。しかし、RFC 2327は'message'メディアタイプを定義していませんでした。このメディアタイプは、RFC 3840より後に公開された改訂版のSDP仕様[5]で定義されました。

2. セキュリティーに関する考慮事項

RFC 3840 [4]のセクション11.1で、メディアフィーチャータグの使用に関連するセキュリティー上の考慮事項を論じています。

3. IANA Considerations

3. IANAに関する考慮事項

This specification registers a new media feature tag in the SIP [3] tree per the procedures defined in RFC 2506 [2] and RFC 3840 [4].

この仕様は、RFC 2506 [2]とRFC 3840 [4]で定義された手順にしたがって、SIP [3]ツリーに新しいメディアフィーチャータグを登録します。

Media feature tag name:
sip.message
ASN.1 Identifier:
21
Summary of the media feature indicated by this tag:
This feature tag indicates that the device supports message as a streaming media type.
Values appropriate for use with this feature tag:
Boolean.
The feature tag is intended primarily for use in the following applications, protocols, services, or negotiation mechanisms:
This feature tag is most useful in a communications application for describing the capabilities of a device, such as a phone or PDA.
Examples of typical use:
Routing a call to a phone that can support session-based instant messaging.
Related standards or documents:
RFC 4569.
Security Considerations:
Security considerations for this media feature tag are discussed in Section 11.1 of RFC 3840.
メディアフィーチャータグ名:
sip.message
ASN.1識別子:
21
このタグが示すメディア機能の概要:
このフィーチャータグは、そのデバイスがストリーミングメディアタイプとしてmessageをサポートしていることを示します。
このフィーチャータグで使用するのに適した値:
ブール値（Boolean）。
このフィーチャータグが主に使用されることを意図しているアプリケーション、プロトコル、サービス、またはネゴシエーションメカニズム:
このフィーチャータグは、電話機やPDAなどのデバイスの機能を記述する通信アプリケーションで最も役立ちます。
典型的な使用例:
セッションベースのインスタントメッセージングをサポートできる電話機への呼のルーティング。
関連する標準または文書:
RFC 4569。
セキュリティーに関する考慮事項:
このメディアフィーチャータグに関するセキュリティー上の考慮事項は、RFC 3840のセクション11.1で論じられています。
