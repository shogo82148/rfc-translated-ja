RFC 7892

IANA Allocation Procedures for the GMPLS OTN Signal Type Registry

RFC 7892

GMPLS OTN Signal Typeレジストリーに対するIANAの割り当て手続き

Abstract

概要

IANA defined the "OTN Signal Type" subregistry of the "Generalized Multi-Protocol Label Switching (GMPLS) Signaling Parameters" registry in RFC 7139. This document updates the "OTN Signal Type" subregistry to allow registration via Specification Required.

IANAは、RFC 7139で「Generalized Multi-Protocol Label Switching (GMPLS) Signaling Parameters」レジストリーの「OTN Signal Type」サブレジストリーを定義しました。この文書は、Specification Requiredによる登録を許可するように「OTN Signal Type」サブレジストリーを更新します。

1. Introduction

1. はじめに

IANA maintains "OTN Signal Type" subregistry of the "Generalized Multi-Protocol Label Switching (GMPLS) Signaling Parameters" registry for OTN signal types (as defined in [RFC4328] and updated by [RFC7139]). This subregistry is defined to use only the Standards Action registration policy as defined by [RFC5226]. This document updates [RFC7139] to allow the "OTN Signal Type" subregistry to also use the Specification Required policy as defined in [RFC5226].

IANAは、OTNシグナルタイプ（[RFC4328]で定義され、[RFC7139]で更新されたもの）のために、「Generalized Multi-Protocol Label Switching (GMPLS) Signaling Parameters」レジストリーの「OTN Signal Type」サブレジストリーを保守しています。このサブレジストリーは、[RFC5226]で定義されているStandards Actionの登録ポリシーだけを使用するように定義されています。この文書は、「OTN Signal Type」サブレジストリーが[RFC5226]で定義されているSpecification Requiredのポリシーも使用できるように、[RFC7139]を更新します。

2. Security Considerations

2. セキュリティーに関する考慮事項

This document does not introduce any new security considerations to the existing GMPLS signaling protocols. Refer to [RFC7139] for further details of the specific security measures. Additionally, [RFC5920] provides an overview of security vulnerabilities and protection mechanisms for the GMPLS control plane.

この文書は、既存のGMPLSシグナリングプロトコルに新しいセキュリティー上の考慮事項を導入しません。具体的なセキュリティー対策の詳細については、[RFC7139]を参照してください。さらに、[RFC5920]は、GMPLSコントロールプレーンのセキュリティー上の脆弱性と保護の仕組みの概要を示しています。

3. IANA Considerations

3. IANAに関する考慮事項

IANA maintains the "OTN Signal Type" subregistry of the "Generalized Multi-Protocol Label Switching (GMPLS) Signaling Parameters" registry. The registry currently is defined to use the Standards Action registration policy as defined by [RFC5226].

IANAは、「Generalized Multi-Protocol Label Switching (GMPLS) Signaling Parameters」レジストリーの「OTN Signal Type」サブレジストリーを保守しています。このレジストリーは現在、[RFC5226]で定義されているStandards Actionの登録ポリシーを使用するように定義されています。

Per this document, IANA has updated the registration policies for the "OTN Signal Type" subregistry to be "Standards Action" for Standards Track documents and "Specification Required" for other documents.

この文書に従い、IANAは「OTN Signal Type」サブレジストリーの登録ポリシーを、標準化過程の文書に対しては「Standards Action」、その他の文書に対しては「Specification Required」となるように更新しました。
