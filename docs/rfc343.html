RFC 343

IMP System Change Notification

RFC 343

IMPシステムの変更の通知

Abstract

概要

As most of you probably know, our attempt to release IMPSYS 2600 on May 15 (as discussed in RFC #331) was unsuccessful. Briefly, the primary reasons for failure (all operational rather than programming bugs) were:

ご存じの方が多いと思いますが、（RFC #331で述べたとおり）5月15日にIMPSYS 2600をリリースしようとした試みは失敗に終わりました。手短に言うと、失敗の主な理由（いずれもプログラミングのバグではなく運用上の問題です）は次のとおりです。

  1. The network appears to have grown too large for us to successfully coordinate operator intervention at all sites.
  2. An unanticipated aspect of the gradual release of the new system was the "poisoning" of IMP's running the new system by adjacent IMP's running the old system, and vice versa. Working around this problem made the dissemination of the new system take much longer than anticipated.
  1. ネットワークの規模が大きくなりすぎて、すべてのサイトでのオペレーターの介入をうまく調整できなくなったようです。
  2. 新しいシステムを段階的にリリースする際の予期しなかった側面として、新しいシステムを実行しているIMPが、古いシステムを実行している隣接IMPによって「汚染」され、その逆も起こりました。この問題を回避するために、新しいシステムの配布に予想よりはるかに長い時間がかかりました。

We believe we see solutions to both of these problems and are now ready to schedule the next attempt(s) to release IMPSYS 2600. We hereby request all sites to cooperate with this effort in the following ways.

私たちは、これらの問題の両方について解決策が見えたと考えており、IMPSYS 2600をリリースする次の試みの予定を立てる準備ができています。ここに、すべてのサイトに次の方法でこの取り組みに協力していただくようお願いします。

  1. All sites with Model 516 IMP's have been contacted by telephone and asked to set the switches on their IMP's as follows:

    HALT INH
    off
    W.D.T.
    off
    AUTO RSTRT
    on
    MEMORY PRTCT
    off

    Please be sure that your switches remain set at these positions until further notice.

  2. No site should attempt to use the IMP's "Trace" routine during the day(s) of the attempted system release.
  3. Terminal IMP's may be turned off for significant portions of the day(s) of the attempted system release. Please be patient with any inconvenience which this causes.

  4. We hope to accomplish release of IMPSYS 2600 on the next attempt. Nevertheless, we are not omniscient and may again be thwarted by difficulties. Accordingly, we are scheduling the next attempt for Wednesday, May 31, and subsequently every Tuesday (June 6, 13, 20, ...) until the release is successfully accomplished. We will arrange the release process so that site operator coverage is not required; nevertheless we hope that the normal site operator coverage is available in case unanticipated problems develop. Release of the new system will begin early in the day (approximately 7 a.m. EDT). We again suggest that sites do not schedule production work over the network during the release attempt(s). We will notify each site by phone after the release has been successfully completed.

    Finally, we apologize in advance for any inconvenience caused by the contortions required to release this new system, and thank all of the site operations' staffs who worked with us on May 15 for their cooperation.

    AAM/jm

  1. Model 516のIMPを持つすべてのサイトには、電話で連絡して、IMPのスイッチを次のように設定するよう依頼しました。

    HALT INH
    オフ
    W.D.T.
    オフ
    AUTO RSTRT
    オン
    MEMORY PRTCT
    オフ

    追って通知するまで、スイッチをこの位置に設定したままにしておいてください。

  2. システムのリリースを試みる日には、どのサイトもIMPの「Trace」ルーチンを使おうとしないでください。
  3. システムのリリースを試みる日には、Terminal IMPがかなりの時間にわたって停止されることがあります。これによってご不便をおかけしますが、ご容赦ください。

  4. 次の試みでIMPSYS 2600のリリースを達成したいと考えています。とはいえ、私たちは全知ではないので、再び困難に阻まれるかもしれません。そこで、次の試みを5月31日の水曜日に予定し、以降はリリースが成功するまで毎週火曜日（6月6日、13日、20日、…）に行います。サイトのオペレーターの対応が必要とならないようにリリースの手順を手配しますが、予期しない問題が発生した場合に備えて、通常どおりサイトのオペレーターが対応できることを希望します。新しいシステムのリリースは、朝早く（東部夏時間の午前7時ごろ）に始めます。リリースを試みている間は、ネットワーク越しの本番作業を予定しないよう、改めてサイトの皆さんにお勧めします。リリースが無事に完了したら、各サイトに電話でお知らせします。

    最後に、この新しいシステムをリリースするために必要な無理な手順によってご不便をおかけすることを前もってお詫びするとともに、5月15日に私たちと一緒に作業していただいたすべてのサイトの運用スタッフの皆さんのご協力に感謝します。

    AAM/jm
