RFC 126

Ames Graphics Facilities at Ames Research Center

RFC 126

Ames Research CenterのAmesグラフィックス設備

Abstract

概要

This note is intended as a response to an RFC which suggested that nodes describe their graphics environment. The following graphics facilites are now at Ames for the IBM 360/67 TSS:

このノートは、各ノードが自身のグラフィックス環境について説明するよう提案したRFCへの回答として書いたものです。現在Amesには、IBM 360/67 TSS用に次のグラフィックス設備があります：

  1. An SC 4020 off line microfilm system.
  2. Calcomp plotters.
  3. ARDS storage tube CRTs.
  4. IMLAC PDS-1 refresh CRTs.
  5. One IBM 2250 CRT.
  1. SC 4020オフラインマイクロフィルムシステム。
  2. Calcompプロッター。
  3. ARDS蓄積管CRT。
  4. IMLAC PDS-1リフレッシュ型CRT。
  5. IBM 2250 CRT 1台。

Devices which will be in use in the near future are:

近い将来に使われる予定の装置は次のとおりです：

  1. An Evans and Sutherland LDS-2 system.
  2. Hazeltine alphanumeric CRTs.
  1. Evans and Sutherland LDS-2システム。
  2. Hazeltine英数字CRT。

Because of the diverse nature of the devices and the varying software support provided by the manafacturers, work has been undertaken to provide a device independent package. This package is currently being implemented. The basic entity is a device independent intermediate language which describes the picture to be displayed. When a device is selected, the intermediate language is converted to specific device orders.

装置の性質が多様で、製造元が提供するソフトウェアサポートもまちまちであるため、装置に依存しないパッケージを提供する作業に着手しました。このパッケージは現在実装中です。基本となるのは、表示する図形を記述する、装置に依存しない中間言語です。装置が選択されると、中間言語はその装置固有の命令に変換されます。

Other features include the definition and storage of subpictures for later construction of more complex pictures. An interface has been specified so that graphic data sets can be transmitted to other installations on the TSS network.

ほかにも、後でより複雑な図形を組み立てるための部分図形を定義・保存する機能などがあります。グラフィックスのデータセットをTSSネットワーク上のほかの施設へ送信できるよう、インターフェイスも規定しました。

A note to those who plan to use the ILLIAC IV when it becomes a functioning node at Ames. I would like information concerning the graphics environment at your sites and any thoughts you have on how you will be using graphics with the ILLIAC IV.

ILLIAC IVがAmesで稼働するノードになったときにそれを使う予定の方々へのお願いです。皆さんのサイトのグラフィックス環境に関する情報と、ILLIAC IVでグラフィックスをどのように使うかについてのお考えをお寄せください。
