RFC 9672

Transferring Opportunistic Wireless Encryption to the IEEE 802.11 Working Group

RFC 9672

Opportunistic Wireless Encryption の IEEE 802.11 ワーキンググループへの移管

Abstract

概要

RFC 8110 describes Opportunistic Wireless Encryption (OWE), a mode that allows unauthenticated clients to connect to a network using encrypted traffic. This document transfers the ongoing maintenance and further development of the protocol to the IEEE 802.11 Working Group.

RFC 8110 は、認証されていないクライアントが暗号化されたトラフィックを使ってネットワークに接続できるモードである Opportunistic Wireless Encryption（OWE）を記述しています。 この文書は、このプロトコルの継続的な保守とさらなる開発を IEEE 802.11 ワーキンググループに移管します。

This document updates RFC 8110 by noting that future work on the protocol described therein will occur in the IEEE 802.11 Working Group.

この文書は、RFC 8110 に記述されているプロトコルに関する今後の作業が IEEE 802.11 ワーキンググループで行われることを示すことにより、RFC 8110 を更新します。

1. Introduction

1. はじめに

Opportunistic Wireless Encryption (OWE) [RFC8110] is a mode of opportunistic security [RFC7435] for IEEE Std 802.11 that provides encryption of the wireless medium without authentication.

Opportunistic Wireless Encryption（OWE）[RFC8110] は、IEEE Std 802.11 向けの日和見セキュリティー（opportunistic security）[RFC7435] のモードであり、認証なしで無線媒体の暗号化を提供します。

Since publication, [RFC8110] (also known as "[Wi-Fi_Enhanced_Open]") has been widely implemented and deployed.

公開以来、[RFC8110]（「[Wi-Fi_Enhanced_Open]」としても知られています）は広く実装され、展開されています。

The IEEE 802.11 Working Group [IEEE_802.11] has requested the ability to maintain and develop OWE (see [IEEE_LS]) to ensure that the protocol remains in sync with the IEEE protocols. This document represents concurrence that future work on OWE [RFC8110] will now occur in the IEEE 802.11 Working Group.

IEEE 802.11 ワーキンググループ [IEEE_802.11] は、このプロトコルが IEEE のプロトコルと同期した状態を維持できるように、OWE を保守および開発できるようにすることを要請しました（[IEEE_LS] を参照してください）。 この文書は、OWE [RFC8110] に関する今後の作業が IEEE 802.11 ワーキンググループで行われることに同意するものです。

2. Transfer of Maintenance

2. 保守の移管

This document represents concurrence that future work on OWE [RFC8110] will now occur in the IEEE 802.11 Working Group [IEEE_802.11] to ensure that the protocol remains in sync with the IEEE protocols.

この文書は、このプロトコルが IEEE のプロトコルと同期した状態を維持できるように、OWE [RFC8110] に関する今後の作業が IEEE 802.11 ワーキンググループ [IEEE_802.11] で行われることに同意するものです。

The OWE protocol [RFC8110] will be duplicated by the IEEE 802.11 Working Group [IEEE_802.11] such that the document alone will be enough to implement, maintain, and modify the protocol within the IEEE under its policies and procedures.

OWE プロトコル [RFC8110] は、IEEE 802.11 ワーキンググループ [IEEE_802.11] によって複製され、その文書だけで、IEEE の方針と手順に従って IEEE 内でこのプロトコルを実装、保守、変更できるようになります。

3. Security Considerations

3. セキュリティーに関する考慮事項

This document simply notes that future work on the protocol described in [RFC8110] will now occur in the IEEE. As such, it does not introduce any new security considerations.

この文書は、[RFC8110] に記述されているプロトコルに関する今後の作業が IEEE で行われることを単に示すものです。 したがって、新たなセキュリティーに関する考慮事項は生じません。

4. IANA Considerations

4. IANAに関する考慮事項

This document has no IANA actions.

この文書にはIANAアクションはありません。
