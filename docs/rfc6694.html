RFC 6694

The "about" URI Scheme

RFC 6694

「about」URIスキーム

Abstract

概要

This document describes the "about" URI scheme, which is widely used by Web browsers and some other applications to designate access to their internal resources, such as settings, application information, hidden built-in functionality, and so on.

この文書は、「about」URIスキームについて説明します。このスキームは、Webブラウザーやその他の一部のアプリケーションで、設定、アプリケーション情報、隠れた組み込み機能などの内部リソースへのアクセスを指定するために広く使用されています。

1. Introduction

1. はじめに

This document describes the "about" Uniform Resource Identifier (URI) scheme. The "about" URI scheme is currently widely used by Web browsers to designate access to their internal resources, such as settings, application information, and so-called "Easter eggs" (i.e., a hidden feature or joke in an application).

この文書は、「about」統一資源識別子（Uniform Resource Identifier: URI）スキームについて説明します。「about」URIスキームは現在、Webブラウザーで、設定、アプリケーション情報、いわゆる「イースターエッグ」（すなわち、アプリケーション内の隠し機能やジョーク）などの内部リソースへのアクセスを指定するために広く使用されています。

2. URI Scheme Specification

2. URIスキームの仕様

2.1. URI Scheme Syntax

2.1. URIスキームの構文

The "about" URI syntactically conforms to the <about-uri> rule below, expressed using the Augmented Backus-Naur Form (ABNF) [RFC5234]:

「about」URIは、構文上、拡張バッカス・ナウア記法（Augmented Backus-Naur Form: ABNF）[RFC5234]を使用して表現した次の<about-uri>規則に従います。

  about-uri = "about:" about-token [ about-query ] [ about-fragment ]
  about-token = *pchar
  about-query = "?" query
  about-fragment = "#" fragment
  pchar     = <as specified in RFC 3986, Appendix A>
  query     = <as specified in RFC 3986, Appendix A>
  fragment  = <as specified in RFC 3986, Appendix A>

  about-uri = "about:" about-token [ about-query ] [ about-fragment ]
  about-token = *pchar
  about-query = "?" query
  about-fragment = "#" fragment
  pchar     = <as specified in RFC 3986, Appendix A>
  query     = <as specified in RFC 3986, Appendix A>
  fragment  = <as specified in RFC 3986, Appendix A>

2.2. URI Scheme Semantics

2.2. URIスキームのセマンティクス

The resource that is referenced by a particular "about" URI is denoted by the <about-token> part of the URI. It is not a hierarchical element for a naming authority. The <about-query> part specifies additional information about its handling and/or the information that should be returned by the resource referenced by the URI.

特定の「about」URIが参照するリソースは、そのURIの<about-token>部分によって示されます。これは、命名機関（naming authority）のための階層的な要素ではありません。<about-query>部分は、その処理に関する追加情報、またはURIが参照するリソースが返すべき情報、あるいはその両方を指定します。

It is impossible to specify a binding between all the possible tokens and the semantics of "about" URIs that would contain such tokens. Therefore, the resource referenced by the URI is generally considered to be specific to a Web browser implementation.

考えられるすべてのトークンと、それらのトークンを含む「about」URIのセマンティクスとの対応付けを規定することは不可能です。したがって、URIが参照するリソースは一般に、Webブラウザーの実装に固有のものと考えられています。

2.2.1. Well-Known "about" URIs

2.2.1. よく知られた「about」URI

Some <about-token>s have been reserved, as the behavior of the resource that is referenced is well-known (well-known tokens).

参照されるリソースの動作がよく知られているため、いくつかの<about-token>は予約されています（よく知られたトークン）。

A well-known "about" URI is a URI that has a well-known token as its <about-token> part. It is recommended that such URIs be handled in accordance with the specification referenced in the "about" URI Tokens registry (see Section 5.2).

よく知られた「about」URIとは、<about-token>部分によく知られたトークンを持つURIです。そのようなURIは、「about」URI Tokensレジストリー（セクション5.2を参照）で参照されている仕様に従って処理することが推奨されます。

Well-known "about" URIs are intended to be registered when there is a need to codify the behavior of a particular <about-token>.

よく知られた「about」URIは、特定の<about-token>の動作を成文化する必要がある場合に登録することを意図しています。

2.3. Encoding Considerations

2.3. エンコーディングに関する考慮事項

"about" URIs are subject to encoding rules as defined in RFC 3986 [RFC3986].

「about」URIは、RFC 3986[RFC3986]で定義されているエンコーディング規則に従います。

3. "about:blank"

3. 「about:blank」

This document defines one well-known token: "blank". The "about:blank" URI refers to a resource represented in the browser by a blank page.

この文書は、よく知られたトークンを1つ定義します。それは「blank」です。「about:blank」URIは、ブラウザー内で空白のページとして表現されるリソースを参照します。

4. Security Considerations

4. セキュリティーに関する考慮事項

Security considerations for URIs are discussed in Section 7 of RFC 3986 [RFC3986]. However, most of those provisions do not apply to the "about" URI scheme, as they are mainly scoped to schemes used in the Internet.

URIに関するセキュリティーの考慮事項は、RFC 3986[RFC3986]のセクション7で議論されています。しかし、それらの規定の大部分は主にインターネットで使用されるスキームを対象としているため、「about」URIスキームには当てはまりません。

"about" URIs can sometimes refer to sensitive information, such as user passwords stored in a cache, or parameters that, if changed, could affect a user's data. The application therefore needs to ensure that the user's data is secured and no threats are imposed by "about" URIs.

「about」URIは、キャッシュに保存されたユーザーのパスワードや、変更するとユーザーのデータに影響を与えうるパラメーターなど、機密情報を参照することがあります。したがって、アプリケーションは、ユーザーのデータが保護され、「about」URIによって脅威がもたらされないようにする必要があります。

5.2.1. Registration Procedure

5.2.1. 登録手続き

The registration policy for this registry is "First Come First Served", as described in RFC 5226 [RFC5226]. The registrant of the token should provide the information mentioned in the following registration template:

このレジストリーの登録ポリシーは、RFC 5226[RFC5226]で説明されている「First Come First Served（先着順）」です。トークンの登録者は、次の登録テンプレートに記載された情報を提供する必要があります。

  • Registered token: The desired well-known token to be used in "about" URIs.
  • Intended usage: A short description of how "about" URIs with the registered token are handled, including information about the referenced resource.
  • Contact/change controller: Person (including contact information) authorized to change this registration.
  • Specification: A stable reference to a document that specifies the registered "about" URI. The question of interoperability does not arise. The key motivation is to have a reference to a specification documenting well-known behavior of the "about" URI in Web browsers. As a rule of thumb, if the behavior is common to two or more Web browser implementations, it can be considered well-known. An existing assignment may be duplicated if the registered token is used in more than one Web browser implementation.
  • Registered token: 「about」URIで使用する、希望するよく知られたトークン。
  • Intended usage: 登録したトークンを持つ「about」URIがどのように処理されるかの短い説明。参照されるリソースに関する情報を含みます。
  • Contact/change controller: この登録を変更する権限を持つ人（連絡先情報を含む）。
  • Specification: 登録する「about」URIを規定する文書への安定した参照。相互運用性の問題は生じません。主な動機は、Webブラウザーにおける「about」URIのよく知られた動作を文書化した仕様への参照を持つことです。経験則として、その動作が2つ以上のWebブラウザー実装に共通していれば、よく知られていると見なせます。登録するトークンが2つ以上のWebブラウザー実装で使用されている場合は、既存の割り当てを重複させてもかまいません。
