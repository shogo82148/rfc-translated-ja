RFC 384

Official site idents for organizations in the ARPA Network

RFC 384

ARPAネットワークに参加する組織の公式サイト識別子

Abstract

概要

Idents are given here in two lists, a list in alpha order and a list by Site address.

ここでは、識別子をアルファベット順の一覧とサイトアドレス順の一覧の2つの一覧で示します。

These lists include only those organizations with present or scheduled direct connection to the Network. Scheduled Sites are indicated by "s". Inactive addresses are shown as "i".

これらの一覧には、ネットワークに現在直接接続している組織、または直接接続する予定の組織だけを含めています。接続予定のサイトは「s」で示します。稼働していないアドレスは「i」で示します。
