YANG Groupings for SSH Clients and SSH Servers

RFC 9644

SSHクライアントとSSHサーバーのためのYANGグルーピング

Abstract

概要

This document presents three IETF-defined YANG modules and a script used to create four supporting IANA modules.

この文書は、IETFが定義する3つのYANGモジュールと、それを補助する4つのIANAモジュールの作成に使用するスクリプトを示します。

The three IETF modules are ietf-ssh-common, ietf-ssh-client, and ietf-ssh-server. The "ietf-ssh-client" and "ietf-ssh-server" modules are the primary productions of this work, supporting the configuration and monitoring of Secure Shell (SSH) clients and servers.

3つのIETFモジュールは、ietf-ssh-common、ietf-ssh-client、ietf-ssh-serverです。「ietf-ssh-client」モジュールと「ietf-ssh-server」モジュールがこの成果の主要な生成物であり、Secure Shell（SSH）クライアントとSSHサーバーの設定と監視をサポートします。

The four IANA modules are iana-ssh-encryption-algs, iana-ssh-key-exchange-algs, iana-ssh-mac-algs, and iana-ssh-public-key-algs. These modules each define YANG enumerations providing support for an IANA-maintained algorithm registry.

4つのIANAモジュールは、iana-ssh-encryption-algs、iana-ssh-key-exchange-algs、iana-ssh-mac-algs、iana-ssh-public-key-algsです。これらのモジュールはそれぞれ、IANAが管理するアルゴリズムのレジストリーをサポートするYANG列挙型を定義します。

1. Introduction

1. はじめに

This document presents three IETF-defined YANG modules [RFC7950] and a script used to create four supporting IANA modules.

この文書は、IETFが定義する3つのYANGモジュール[RFC7950]と、それを補助する4つのIANAモジュールの作成に使用するスクリプトを示します。

The three IETF modules are ietf-ssh-common (Section 2), ietf-ssh-client (Section 3), and ietf-ssh-server (Section 4). The "ietf-ssh-client" and "ietf-ssh-server" modules are the primary productions of this work, supporting the configuration and monitoring of SSH clients and servers.

3つのIETFモジュールは、ietf-ssh-common（Section 2）、ietf-ssh-client（Section 3）、ietf-ssh-server（Section 4）です。「ietf-ssh-client」モジュールと「ietf-ssh-server」モジュールがこの成果の主要な生成物であり、SSHクライアントとSSHサーバーの設定と監視をサポートします。

The groupings defined in this document are expected to be used in conjunction with the groupings defined in an underlying transport-level module, such as the groupings defined in [RFC9643]. The transport-level data model enables the configuration of transport-level values, such as a remote address, a remote port, a local address, and a local port.

この文書で定義するグルーピングは、[RFC9643]で定義されているグルーピングのような、下位のトランスポートレベルのモジュールで定義されたグルーピングと組み合わせて使用されることを想定しています。トランスポートレベルのデータモデルにより、リモートアドレス、リモートポート、ローカルアドレス、ローカルポートなどのトランスポートレベルの値を設定できます。

The four IANA modules are: iana-ssh-encryption-algs, iana-ssh-key-exchange-algs, iana-ssh-mac-algs, and iana-ssh-public-key-algs. These modules each define YANG enumerations providing support for an IANA-maintained algorithm registry.

4つのIANAモジュールは、iana-ssh-encryption-algs、iana-ssh-key-exchange-algs、iana-ssh-mac-algs、iana-ssh-public-key-algsです。これらのモジュールはそれぞれ、IANAが管理するアルゴリズムのレジストリーをサポートするYANG列挙型を定義します。

This document assumes that the four IANA modules exist and presents a script in Appendix A that IANA may use to generate those YANG modules. This document does not publish the initial versions of these four modules. IANA publishes these modules.

この文書は、4つのIANAモジュールが存在することを前提としており、IANAがそれらのYANGモジュールを生成するために使用できるスクリプトをAppendix Aで示します。この文書は、これら4つのモジュールの初版を公開しません。これらのモジュールはIANAが公開します。

1.1. Regarding the Three IETF Modules

1.1. 3つのIETFモジュールについて

The three IETF modules define features and groupings to model "generic" SSH clients and SSH servers, where "generic" should be interpreted as "least common denominator" rather than "complete." Support for the basic SSH protocol [RFC4252] [RFC4253] [RFC4254] is afforded by these modules, leaving configuration of advanced features (e.g., multiple channels) to augmentations made by consuming modules.

3つのIETFモジュールは、「汎用的な」SSHクライアントとSSHサーバーをモデル化するための機能（feature）とグルーピングを定義します。ここでの「汎用的な」は、「完全な」ではなく「最小公分母」と解釈すべきです。これらのモジュールは基本的なSSHプロトコル[RFC4252] [RFC4253] [RFC4254]をサポートし、高度な機能（たとえば、複数のチャネル）の設定は、これらのモジュールを利用するモジュールによる拡張（augment）に委ねます。

It is intended that the YANG groupings will be used by applications needing to configure SSH client and server protocol stacks. For instance, these groupings are used to help define the data models in [NETCONF-CLIENT-SERVER], for clients and servers using the Network Configuration Protocol (NETCONF) over SSH [RFC6242].

これらのYANGグルーピングは、SSHクライアントとSSHサーバーのプロトコルスタックを設定する必要があるアプリケーションによって使用されることを意図しています。たとえば、これらのグルーピングは、SSH上のネットワーク設定プロトコル（Network Configuration Protocol: NETCONF）[RFC6242]を使用するクライアントとサーバーのための[NETCONF-CLIENT-SERVER]のデータモデルを定義するのに使用されています。

The "ietf-ssh-client" and "ietf-ssh-server" YANG modules each define one grouping, which is focused on just SSH-specific configuration, and specifically avoid any transport-level configuration, such as what ports to listen on or connect to. This affords applications the opportunity to define their own strategy for how the underlying TCP connection is established. For instance, applications supporting NETCONF Call Home [RFC8071] could use the "ssh-server-grouping" grouping for the SSH parts it provides while adding data nodes for the TCP-level call-home configuration.

「ietf-ssh-client」YANGモジュールと「ietf-ssh-server」YANGモジュールはそれぞれ1つのグルーピングを定義します。このグルーピングはSSH固有の設定だけに焦点を当てており、どのポートで待ち受けるか、どのポートに接続するかといったトランスポートレベルの設定は意図的に避けています。これにより、アプリケーションは下位のTCPコネクションを確立する方法について独自の方針を定義できます。たとえば、NETCONF Call Home [RFC8071]をサポートするアプリケーションは、自らが提供するSSHの部分には"ssh-server-grouping"グルーピングを使用しつつ、TCPレベルのコールホームの設定のためのデータノードを追加できます。

The modules defined in this document optionally support [RFC6187], which describes enabling host keys and public keys based on X.509v3 certificates.

この文書で定義するモジュールは、X.509v3証明書に基づくホスト鍵と公開鍵を有効にする方法を記述した[RFC6187]をオプションでサポートします。

2. The "ietf-ssh-common" Module

2. 「ietf-ssh-common」モジュール

The SSH common model presented in this section is common to both SSH clients and SSH servers. The "transport-params-grouping" grouping can be used to configure the list of SSH transport algorithms permitted by the SSH client or SSH server. The lists of permitted algorithms are in decreasing order of usage preference. The algorithm that appears first in the client list that also appears in the server list is the one that is used for the SSH transport layer connection. The ability to restrict the algorithms allowed is provided in this grouping for SSH clients and SSH servers that are capable of doing so and may serve to make SSH clients and SSH servers compliant with security policies.

このセクションで示すSSH共通モデルは、SSHクライアントとSSHサーバーの両方に共通です。"transport-params-grouping"グルーピングは、SSHクライアントまたはSSHサーバーが許可するSSHトランスポートアルゴリズムのリストを設定するために使用できます。許可されるアルゴリズムのリストは、使用の優先度が高い順に並べます。クライアントのリストで最初に現れ、かつサーバーのリストにも現れるアルゴリズムが、SSHトランスポート層コネクションに使用されるアルゴリズムです。許可するアルゴリズムを制限する機能は、それが可能なSSHクライアントとSSHサーバーのためにこのグルーピングで提供されており、SSHクライアントとSSHサーバーをセキュリティーポリシーに準拠させるのに役立つ場合があります。

  • "client-identity"ノードは、"username"と認証方式を設定します。各認証方式は、Section 3.1.1で定義されている"feature"ステートメントによって有効になります。
  • "server-authentication"ノードは、SSHサーバーを認証するためのトラストアンカーを設定します。各選択肢は"feature"ステートメントによって有効になります。
  • "transport-params"ノードは、機能によって有効にする必要があり、この設定によって確立されるSSHセッションのパラメーターを設定します。
  • "keepalives"ノードは、機能によって有効にする必要があり、SSHサーバーの生存確認のための"presence"コンテナーを設定します。生存確認はSSHプロトコル層で行われます。

  • 参照されているグルーピングステートメントについて：

    • "inline-or-keystore-asymmetric-key-grouping"グルーピングについては、[RFC9642]のSection 2.1.3.4で説明しています。
    • "inline-or-keystore-end-entity-cert-with-key-grouping"グルーピングについては、[RFC9642]のSection 2.1.3.6で説明しています。
    • "inline-or-truststore-public-keys-grouping"グルーピングについては、[RFC9641]のSection 2.1.3.4で説明しています。
    • "inline-or-truststore-certs-grouping"グルーピングについては、[RFC9641]のSection 2.1.3.3で説明しています。
    • "transport-params-grouping"グルーピングについては、この文書のSection 2.1.2.1で説明しています。

3.1.3. Protocol-Accessible Nodes

3.1.3. プロトコルからアクセス可能なノード

The "ietf-ssh-client" module defines only "grouping" statements that are used by other modules to instantiate protocol-accessible nodes. Thus, this module, when implemented, does not itself define any protocol-accessible nodes.

「ietf-ssh-client」モジュールは、他のモジュールがプロトコルからアクセス可能なノードをインスタンス化するために使用する"grouping"ステートメントのみを定義します。したがって、このモジュールは、実装されたとしても、それ自体ではプロトコルからアクセス可能なノードを定義しません。

5. Security Considerations

The three IETF YANG modules in this document define groupings and will not be deployed as standalone modules. Their security implications may be context-dependent based on their use in other modules. The designers of modules that import these groupings must conduct their own analysis of the security considerations.

この文書の3つのIETF YANGモジュールはグルーピングを定義するものであり、単独のモジュールとして展開されることはありません。これらのセキュリティー上の影響は、他のモジュールでの使用に基づいて、文脈に依存する場合があります。これらのグルーピングをインポートするモジュールの設計者は、セキュリティーに関する考慮事項について独自の分析を行わなければなりません。

def create_module_body(module, f):

    # Fetch the current CSV file from IANA
    r = requests.get(module["csv_url"])
    assert(r.status_code == 200)

    # Ascertain the first CSV column's name
    with StringIO(r.text) as csv_file:
        csv_reader = csv.reader(csv_file)
        for row in csv_reader:
            first_colname = row[0]
            break

    # Parse each CSV line
    with StringIO(r.text) as csv_file:
        csv_reader = csv.DictReader(csv_file)
        for row in csv_reader:

            # Extract just the ref
            refs = row["Reference"][1:-1]  # remove the '[' and ']' \
chars
            refs = refs.split("][")

            # There may be more than one ref
            titles = []
            for ref in refs:

                # Ascertain the ref's title
                if ref.startswith("RFC"):

                    # Fetch the current BIBTEX entry
                    bibtex_url="https://datatracker.ietf.org/doc/"+ \
ref.lower() + "/bibtex/"
                    r = requests.get(bibtex_url)
                    assert r.status_code == 200, "Could not GET " + \
bibtex_url

                    # Append to 'titles' value from the "title" line
                    for item in r.text.split("\n"):
                        if "title =" in item:
                            titles.append(re.sub('.*{{(.*)}}.*', r'\\
g<1>', item))
                            break
                    else:
                        raise Exception("RFC title not found")


                    # Insert a space: "RFCXXXX" --> "RFC XXXX"
                    index = refs.index(ref)
                    refs[index] = "RFC " + ref[3:]

                elif ref.startswith("FIPS"):
                    # Special case for FIPS, since no bibtex to fetch
                    if ref == "FIPS 46-3" or ref == "FIPS-46-3":
                        titles.append("Data Encryption Standard (DES\
)")
                    else:
                        raise Exception("FIPS ref not found")

                else:
                    raise Exception("ref not found")

            # Function used below
            def write_enumeration(alg):
                f.write('\n')
                f.write(f'      enum {alg} {{\n')
                if "HISTORIC" in row["Note"]:
                    f.write(f'        status obsolete;\n')
                elif "OK to Implement" in row:
                    if "MUST NOT" in row["OK to Implement"]:
                        f.write(f'        status obsolete;\n')
                    elif "SHOULD NOT" in row["OK to Implement"]:
                        f.write(f'        status deprecated;\n')
                f.write(f'        description\n')
                description = f'          "Enumeration for the \'{al\
g}\' algorithm.'
                if "Section" in row["Note"]:
                    description += " " + row["Note"]
                description += '";'
                description = textwrap.fill(description, width=69, s\
ubsequent_indent="           ")
                f.write(f'{description}\n')
                f.write('        reference\n')
                f.write('          "')
                if row["Reference"] == "":
                    f.write('    Missing in IANA registry.')
                else:
                    ref_len = len(refs)
                    for i in range(ref_len):
                        ref = refs[i]
                        f.write(f'{ref}:\n')
                        title = "             " + titles[i]
                        if i == ref_len - 1:
                            title += '";'
                        title = textwrap.fill(title, width=67, subse\
quent_indent="             ")
                        f.write(f'{title}')
                        if i != ref_len - 1:
                            f.write('\n       ')
                f.write('\n')
                f.write('      }\n')


            # Write one or more "enumeration" statements
            if not row[first_colname].endswith("-*"): # just one enu\
meration
                # Avoid duplicate entries caused by the "ecdh-sha2-*\
" family expansion
                if not row[first_colname].startswith("ecdh-sha2-nist\
p"):
                    write_enumeration(row[first_colname])
            else: # a family of enumerations
                curve_ids = [
                    "nistp256",
                    "nistp384",
                    "nistp521",
                    "1.3.132.0.1",
                    "1.2.840.10045.3.1.1",
                    "1.3.132.0.33",
                    "1.3.132.0.26",
                    "1.3.132.0.27",
                    "1.3.132.0.16",
                    "1.3.132.0.36",
                    "1.3.132.0.37",
                    "1.3.132.0.38",
                ]
                for curve_id in curve_ids:
                    write_enumeration(row[first_colname][:-1] + curv\
e_id)


def create_module_end(module, f):

    # Close out the enumeration, typedef, and module
    f.write("    }\n")
    f.write("    description\n")
    f.write(f'      "An enumeration for SSH {module["spaced_name"]} \
algorithms.";\n')
    f.write("  }\n")
    f.write('\n')
    f.write('}\n')


def create_module(module):

    # Install cache for 8x speedup
    requests_cache.install_cache()

    # Ascertain YANG module's name
    yang_module_name = "iana-ssh-" + module["hyphenated_name"] + "-a\
lgs.yang"

    # Create YANG module file
    with open(yang_module_name, "w") as f:
        create_module_begin(module, f)
        create_module_body(module, f)
        create_module_end(module, f)


def main():
    for module in MODULES:
        create_module(module)


if __name__ == "__main__":
    main()

                description = textwrap.fill(description, width=69, s\
ubsequent_indent="           ")
                f.write(f'{description}\n')
                f.write('        reference\n')
                f.write('          "')
                if row["Reference"] == "":
                    f.write('    Missing in IANA registry.')
                else:
                    ref_len = len(refs)
                    for i in range(ref_len):
                        ref = refs[i]
                        f.write(f'{ref}:\n')
                        title = "             " + titles[i]
                        if i == ref_len - 1:
                            title += '";'
                        title = textwrap.fill(title, width=67, subse\
quent_indent="             ")
                        f.write(f'{title}')
                        if i != ref_len - 1:
                            f.write('\n       ')
                f.write('\n')
                f.write('      }\n')


            # Write one or more "enumeration" statements
            if not row[first_colname].endswith("-*"): # just one enu\
meration
                # Avoid duplicate entries caused by the "ecdh-sha2-*\
" family expansion
                if not row[first_colname].startswith("ecdh-sha2-nist\
p"):
                    write_enumeration(row[first_colname])
            else: # a family of enumerations
                curve_ids = [
                    "nistp256",
                    "nistp384",
                    "nistp521",
                    "1.3.132.0.1",
                    "1.2.840.10045.3.1.1",
                    "1.3.132.0.33",
                    "1.3.132.0.26",
                    "1.3.132.0.27",
                    "1.3.132.0.16",
                    "1.3.132.0.36",
                    "1.3.132.0.37",
                    "1.3.132.0.38",
                ]
                for curve_id in curve_ids:
                    write_enumeration(row[first_colname][:-1] + curv\
e_id)


def create_module_end(module, f):

    # Close out the enumeration, typedef, and module
    f.write("    }\n")
    f.write("    description\n")
    f.write(f'      "An enumeration for SSH {module["spaced_name"]} \
algorithms.";\n')
    f.write("  }\n")
    f.write('\n')
    f.write('}\n')


def create_module(module):

    # Install cache for 8x speedup
    requests_cache.install_cache()

    # Ascertain YANG module's name
    yang_module_name = "iana-ssh-" + module["hyphenated_name"] + "-a\
lgs.yang"

    # Create YANG module file
    with open(yang_module_name, "w") as f:
        create_module_begin(module, f)
        create_module_body(module, f)
        create_module_end(module, f)


def main():
    for module in MODULES:
        create_module(module)


if __name__ == "__main__":
    main()
