RFC 6685

Expert Review for Incident Object Description Exchange Format (IODEF) Extensions in IANA XML Registry

RFC 6685

IANA XMLレジストリーにおけるインシデントオブジェクト記述交換フォーマット（IODEF）拡張のExpert Review

Abstract

概要

This document specifies restrictions on additions to the subset of the IANA XML Namespace and Schema registries, to require Expert Review for extensions to Incident Object Description Exchange Format (IODEF).

この文書は、インシデントオブジェクト記述交換フォーマット（Incident Object Description Exchange Format、IODEF）の拡張にExpert Reviewを求めるために、IANAのXML NamespaceレジストリーとXML Schemaレジストリーの一部への追加に関する制限を規定します。

1. Introduction

1. はじめに

IODEF extensions via class extension through AdditionalData and RecordItem elements, per Section 5.2 of [RFC5070], generally register their namespaces and schemas with the IANA XML Namespace registry at http://www.iana.org/assignments/xml-registry/ns.html and the IANA XML Schema registry at http://www.iana.org/assignments/xml-registry/schema.html, respectively [RFC3688].

[RFC5070]のセクション5.2に従い、AdditionalData要素とRecordItem要素によるクラス拡張を通じて行うIODEFの拡張は、通常、その名前空間とスキーマを、それぞれhttp://www.iana.org/assignments/xml-registry/ns.htmlにあるIANAのXML Namespaceレジストリーと、http://www.iana.org/assignments/xml-registry/schema.htmlにあるIANAのXML Schemaレジストリーに登録します[RFC3688]。

In addition to schema reviews required by IANA, these registry requests should be accompanied by a review by IODEF experts to ensure the specified AdditionalData and/or RecordItem contents are compatible with IODEF and with other existing IODEF extensions. This document specifies that review.

IANAが求めるスキーマのレビューに加えて、これらのレジストリーへの登録要求には、指定されたAdditionalDataやRecordItemの内容がIODEFや既存のほかのIODEF拡張と互換性があることを確認するための、IODEFの専門家によるレビューを伴うべきです。この文書は、そのレビューを規定します。

2. Expert Review of IODEF-Related XML Registry Entries

2. IODEF関連のXMLレジストリーエントリーのExpert Review

Changes to the XML Schema registry for schema names beginning with "urn:ietf:params:xml:schema:iodef" are subject to an additional IODEF Expert Review [RFC5226] for IODEF correctness and appropriateness.

XML Schemaレジストリーのうち、「urn:ietf:params:xml:schema:iodef」で始まるスキーマ名に対する変更は、IODEFとしての正しさと適切さについて、追加のIODEFのExpert Review[RFC5226]の対象となります。

The IODEF expert(s) for these reviews will be designated by the IETF Security Area Directors.

これらのレビューを行うIODEFの専門家は、IETFのセキュリティーエリアのエリアディレクターが指名します。

3. Security Considerations

3. セキュリティーに関する考慮事項

This document has no security considerations.

この文書には、セキュリティーに関する考慮事項はありません。

4. IANA Considerations

4. IANAに関する考慮事項

This document specifies additional expert reviews for IODEF extensions, on the XML Schema registry (http://www.iana.org/assignments/xml-registry/schema.html), in Section 2.

この文書は、セクション2で、XML Schemaレジストリー（http://www.iana.org/assignments/xml-registry/schema.html）におけるIODEF拡張に対する追加の専門家レビューを規定します。
