RFC 6938

Deprecation of BGP Path Attributes: DPA, ADVERTISER, and RCID_PATH / CLUSTER_ID

RFC 6938

BGPパス属性DPA、ADVERTISER、RCID_PATH / CLUSTER_IDの非推奨化

Abstract

概要

This document requests IANA to deprecate the following BGP path attributes: DPA, ADVERTISER, and RCID_PATH / CLUSTER_ID, associated with an abandoned Internet-Draft and a Historic RFC.

この文書は、放棄されたインターネットドラフトと歴史的（Historic）RFCに関連する、DPA、ADVERTISER、RCID_PATH / CLUSTER_IDの各BGPパス属性を非推奨にするよう、IANAに要請します。

1. Introduction

1. はじめに

As of this writing, the BGP Path Attributes registry maintained by IANA contains entries for DPA, ADVERTISER, and RCID_PATH / CLUSTER_ID. The first of these is associated with [BGPDPA], an Internet-Draft that was abandoned in 1996. The latter are associated with [RFC1863], an RFC that was reclassified as Historic by [RFC4223] in 2005. Neither specification is currently in use, nor have they ever been.

この文書の執筆時点で、IANAが管理するBGP Path Attributesレジストリーには、DPA、ADVERTISER、RCID_PATH / CLUSTER_IDのエントリーがあります。最初のものは、1996年に放棄されたインターネットドラフトである[BGPDPA]に関連しています。後の2つは、2005年に[RFC4223]によって歴史的（Historic）に再分類されたRFCである[RFC1863]に関連しています。どちらの仕様も現在使われておらず、これまでに使われたこともありません。

Note that the deprecated CLUSTER_ID is distinct from CLUSTER_LIST [RFC4456]. CLUSTER_LIST is not being deprecated.

非推奨となるCLUSTER_IDは、CLUSTER_LIST[RFC4456]とは別のものであることに注意してください。CLUSTER_LISTは非推奨にはなりません。

2. IANA Considerations

2. IANAに関する考慮事項

Per this document, IANA has marked the BGP Path Attributes registry entries for DPA (Value 11), ADVERTISER (Value 12), and RCID_PATH / CLUSTER_ID (Value 13) as "deprecated".

この文書に従い、IANAは、BGP Path AttributesレジストリーのDPA（値11）、ADVERTISER（値12）、RCID_PATH / CLUSTER_ID（値13）のエントリーを「deprecated」（非推奨）としてマークしました。

3. Security Considerations

3. セキュリティーに関する考慮事項

There are no meaningful security consequences arising from this registry update.

このレジストリーの更新によって生じる、セキュリティー上の意味のある影響はありません。
