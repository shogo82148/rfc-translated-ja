RFC 470

Change in Socket for TIP News Facility

RFC 470

TIPニュース機能のソケットの変更

Abstract

概要

The Socket which supports the TIP News Facility has been changed to socket 367 (Octal) at BBN-TENEX. TIP users should be uneffected by this change since the TIP program has already been changed to ICP to the new socket. Because some user TELNET programs have been implemented a "news" command, the old socket will be maintained until April 15, 1973 to give implementers time to change to the new socket.

TIPニュース機能（TIP News Facility）を提供するソケットは、BBN-TENEXのソケット367（8進）に変更されました。TIPプログラムはすでに新しいソケットへICPするよう変更済みなので、TIPのユーザーはこの変更の影響を受けないはずです。一部のユーザーTELNETプログラムには「news」コマンドが実装されているため、実装者が新しいソケットに切り替える時間を確保できるよう、古いソケットは1973年4月15日まで維持します。
