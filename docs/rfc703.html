RFC 703

July, 1975, Survey of New-Protocol TELNET Servers

RFC 703

1975年7月の新プロトコルTelnetサーバーの調査

Abstract

概要

In the nearly five months since the last report several new server sites have joined the network and there has been some significant progress in New-Protocol implementation. Perhaps the New-Protocol implementation on the TIPs scheduled for the end of the year will encourage further progress in the near future.

前回の報告から5か月近くのあいだに、いくつかの新しいサーバーサイトがネットワークに加わり、新プロトコル（New-Protocol）の実装にも大きな進展がありました。年末に予定されているTIPでの新プロトコルの実装が、近いうちにさらなる進展を促すかもしれません。

There have been numerous changes since the last list (numbers in octal):

前回の一覧から多くの変更がありました（番号は8進数）。

  • SRI-ARC (2) is no longer a server host;
  • MIT-AI (206), MIT-ML (306), LONDON (52), and OFFICE-1 (53) have added New-Protocol servers;
  • LLL-RISOS (25), SDAC-44 (32), and ARPA-DMS (34) have joined the network;
  • SCI-TENEX (55), Rutgers-10 (56), USC-ISIC (364), and SUMEX-AIM (70) have joined the network with New-Protocol servers.
  • SRI-ARC（2）はもはやサーバーホストではありません。
  • MIT-AI（206）、MIT-ML（306）、LONDON（52）、OFFICE-1（53）に新プロトコルサーバーが追加されました。
  • LLL-RISOS（25）、SDAC-44（32）、ARPA-DMS（34）がネットワークに加わりました。
  • SCI-TENEX（55）、Rutgers-10（56）、USC-ISIC（364）、SUMEX-AIM（70）が新プロトコルサーバーとともにネットワークに加わりました。

注記：

*

(2)

(3)

Key:

凡例：

X
No server at this socket
?
Status not ascertained-unable to connect to host
I#
Option # implemented incoming to user (Server says "Will #")
O#
Option # implemented outgoing from user (Server says "Do #")
X
このソケットにサーバーなし
?
状態を確認できず（ホストに接続できない）
I#
ユーザーへの受信方向のオプション#を実装（サーバーが「Will #」と送る）
O#
ユーザーからの送信方向のオプション#を実装（サーバーが「Do #」と送る）

(# is option number in new Protocol, Options in tabulation:

（#は新プロトコルでのオプション番号です。一覧表に出てくるオプションは次のとおりです。

0
Transmit-Binary
1
Echo
3
Suppress-Go-Ahead
6
Timing-Mark)

3

6
