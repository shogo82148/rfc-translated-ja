RFC 280

A Draft Set of Host Names

RFC 280

ホスト名の草案

Abstract

概要

The enclosed list of host names is a draft. The hosts with an * next to them indicated that this is the name they desired. The others are names assigned. If I do not hear from representatives at the hosts to change or correct the names in this list by December 3, I will publish a list which we all can consider official.

同封したホスト名の一覧は草案です。*が付いているホストは、その名前を希望したホストです。それ以外は割り当てた名前です。12月3日までに、この一覧の名前の変更や訂正についてホストの代表者から連絡がなければ、皆で正式なものとみなせる一覧を公開します。
