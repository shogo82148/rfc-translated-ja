The Security Evaluated Standardized Password-Authenticated Key Exchange (SESPAKE) Protocol

RFC 8133

セキュリティー評価済み標準パスワード認証鍵交換（SESPAKE）プロトコル

Abstract

概要

This document describes the Security Evaluated Standardized Password-Authenticated Key Exchange (SESPAKE) protocol. The SESPAKE protocol provides password-authenticated key exchange for usage in systems for protection of sensitive information. The security proofs of the protocol were made for situations involving an active adversary in the channel, including man-in-the-middle (MitM) attacks and attacks based on the impersonation of one of the subjects.

この文書では、セキュリティー評価済み標準パスワード認証鍵交換（Security Evaluated Standardized Password-Authenticated Key Exchange、SESPAKE）プロトコルについて説明します。 SESPAKEプロトコルは、機密情報を保護するシステムで使用するためのパスワード認証鍵交換を提供します。 このプロトコルのセキュリティー証明は、中間者（MitM）攻撃や主体の一方へのなりすましに基づく攻撃を含め、チャネル上に能動的な攻撃者が存在する状況を想定して行われました。

1. Introduction

1. はじめに

This document describes the Security Evaluated Standardized Password-Authenticated Key Exchange (SESPAKE) protocol. The SESPAKE protocol provides password-authenticated key exchange for usage in systems for protection of sensitive information. The protocol is intended to be used to establish keys that are then used to organize a secure channel for protection of sensitive information. The security proofs of the protocol were made for situations involving an active adversary in the channel, including man-in-the-middle (MitM) attacks and attacks based on the impersonation of one of the subjects.

この文書では、セキュリティー評価済み標準パスワード認証鍵交換（Security Evaluated Standardized Password-Authenticated Key Exchange、SESPAKE）プロトコルについて説明します。 SESPAKEプロトコルは、機密情報を保護するシステムで使用するためのパスワード認証鍵交換を提供します。 このプロトコルは、機密情報を保護するための安全なチャネルを構成するのに使う鍵を確立するために使用することを想定しています。 このプロトコルのセキュリティー証明は、中間者（MitM）攻撃や主体の一方へのなりすましに基づく攻撃を含め、チャネル上に能動的な攻撃者が存在する状況を想定して行われました。

4. Protocol Description

4. プロトコルの説明

The main point of the SESPAKE protocol is that parties sharing a weak key (a password) generate a strong common key. An active adversary who has access to a channel is not able to obtain any information that can be used to find a key in offline mode, i.e., without interaction with legitimate participants.

SESPAKEプロトコルの要点は、弱い鍵（パスワード）を共有する当事者が強い共通鍵を生成することです。 チャネルにアクセスできる能動的な攻撃者は、オフラインモードで、すなわち正当な参加者とのやり取りなしに、鍵を見つけるのに使用できるいかなる情報も得ることができません。

The protocol is used by subjects A (client) and B (server) that share some secret parameter that was established in an out-of-band mechanism: a client is a participant who stores a password as a secret parameter, and a server is a participant who stores a password-based computed point of the elliptic curve.

このプロトコルは、帯域外のメカニズムで確立された何らかの秘密パラメーターを共有する主体A（クライアント）とB（サーバー）によって使用されます。 クライアントは秘密パラメーターとしてパスワードを保存する参加者であり、サーバーはパスワードに基づいて計算された楕円曲線上の点を保存する参加者です。

The SESPAKE protocol consists of two steps: the key-agreement step and the key-confirmation step. During the first step (the key-agreement step), the parties exchange keys using Diffie-Hellman with public components masked by an element that depends on the password -- one of the predefined elliptic curve points multiplied by the password-based coefficient. This approach provides an implicit key authentication, which means that after this step, one party is assured that no other party, aside from a specifically identified second party, may gain access to the generated secret key. During the second step (the key-confirmation step), the parties exchange strings that strongly depend on the generated key. After this step, the parties are assured that a legitimate party, and no one else, actually has possession of the secret key.

SESPAKEプロトコルは、鍵合意ステップと鍵確認ステップの2つのステップで構成されます。 最初のステップ（鍵合意ステップ）では、当事者はDiffie-Hellmanを使用して鍵を交換します。このとき、公開成分は、パスワードに依存する要素、すなわち事前に定義された楕円曲線上の点の1つにパスワードに基づく係数を掛けたもので、マスクされます。 この方式は暗黙的な鍵認証を提供します。これは、このステップの後、一方の当事者は、特定された相手方の当事者以外のどの当事者も、生成された秘密鍵にアクセスできないことを確信できることを意味します。 2番目のステップ（鍵確認ステップ）では、当事者は生成された鍵に強く依存する文字列を交換します。 このステップの後、当事者は、正当な当事者が、そしてその当事者だけが、実際に秘密鍵を保持していることを確信できます。

To protect against online guessing attacks, counters that indicate the number of failed connections were introduced in the SESPAKE protocol. There is also a special technique for small-order point processing and a mechanism that provides protection against reflection attacks by using different operations for different sides.

オンライン推測攻撃から保護するために、SESPAKEプロトコルでは、失敗した接続の回数を示すカウンターが導入されました。 また、小さい位数の点を処理するための特別な手法と、側ごとに異なる演算を使用することでリフレクション攻撃から保護するメカニズムもあります。

4.1. Protocol Parameters

4.1. プロトコルパラメーター

Various elliptic curves can be used in the protocol. For each elliptic curve supported by clients, the following values MUST be defined:

このプロトコルでは、さまざまな楕円曲線を使用できます。 クライアントがサポートする各楕円曲線について、次の値を定義しなければなりません（MUST）。

  • the protocol parameters identifier, ID_ALG (which can also define a HASH function, a pseudorandom function (PRF) used in the PBKDF2 function, etc.), which is a byte string of an arbitrary length;
  • the point P, which is a generator point of the subgroup of order q of the curve;
  • the set of distinct curve points {Q_1,Q_2,...,Q_N} of order q, where the total number of points, N, is defined for the protocol instance.
  • プロトコルパラメーター識別子ID_ALG（HASH関数や、PBKDF2関数で使用する疑似ランダム関数（PRF）なども定義できる）。これは任意の長さのバイト文字列です。
  • 点P。これは曲線の位数qの部分群の生成元です。
  • 位数qの相異なる曲線上の点の集合{Q_1,Q_2,...,Q_N}。ここで、点の総数Nはプロトコルのインスタンスごとに定義されます。

The method of generation of the points {Q_1,Q_2,...,Q_N} is described in Section 5.

点{Q_1,Q_2,...,Q_N}の生成方法はセクション5で説明します。

The following protocol parameters are used by subject A:

主体Aは、次のプロトコルパラメーターを使用します。

  1. The secret password value PW, which is a byte string that is uniformly randomly chosen from a subset of cardinality 10^10 or greater of the set B_k, where k >= 6 is the password length.
  2. The list of curve identifiers supported by A.
  3. Sets of points {Q_1,Q_2,...,Q_N}, corresponding to curves supported by A.
  4. The C_1^A counter, which tracks the total number of unsuccessful authentication trials in a row, and a value of CLim_1 that stores the maximum possible number of such events.
  5. The C_2^A counter, which tracks the total number of unsuccessful authentication events during the period of usage of the specific PW, and a value of CLim_2 that stores the maximum possible number of such events.
  6. The C_3^A counter, which tracks the total number of authentication events (successful and unsuccessful) during the period of usage of the specific PW, and a value of CLim_3 that stores the maximum possible number of such events.
  7. The unique identifier, ID_A, of subject A (OPTIONAL), which is a byte string of an arbitrary length.
  1. 秘密のパスワード値PW。これは、集合B_kの濃度10^10以上の部分集合から一様ランダムに選ばれたバイト文字列です。ここで、k >= 6はパスワードの長さです。
  2. Aがサポートする曲線識別子のリスト。
  3. Aがサポートする曲線に対応する点{Q_1,Q_2,...,Q_N}の集合。
  4. 連続した認証試行の失敗の総数を記録するカウンターC_1^Aと、そのような事象の最大許容回数を格納する値CLim_1。
  5. 特定のPWの使用期間中の認証失敗の事象の総数を記録するカウンターC_2^Aと、そのような事象の最大許容回数を格納する値CLim_2。
  6. 特定のPWの使用期間中の認証の事象（成功と失敗の両方）の総数を記録するカウンターC_3^Aと、そのような事象の最大許容回数を格納する値CLim_3。
  7. 主体Aの一意な識別子ID_A（選択できます（OPTIONAL））。これは任意の長さのバイト文字列です。

The following protocol parameters are used by subject B:

主体Bは、次のプロトコルパラメーターを使用します。

  1. The values ind and salt, where ind is in {1,...,N} and salt is in {1,...,2^128-1}.

  2. The point Q_PW, satisfying the following equation:

       Q_PW = int(F(PW, salt, 2000))*Q_ind.

    It is possible that the point Q_PW is not stored and is calculated using PW in the beginning of the protocol. In that case, B has to store PW and points {Q_1,Q_2,...,Q_N}.

  3. The ID_ALG identifier.
  4. The C_1^B counter, which tracks the total number of unsuccessful authentication trials in a row, and a value of CLim_1 that stores the maximum possible number of such events.
  5. The C_2^B counter, which tracks the total number of unsuccessful authentication events during the period of usage of the specific PW, and a value of CLim_2 that stores the maximum possible number of such events.
  6. The C_3^B counter, which tracks the total number of authentication events (successful and unsuccessful) during the period of usage of the specific PW, and a value of CLim_3 that stores the maximum possible number of such events.
  7. The unique identifier, ID_B, of subject B (OPTIONAL), which is a byte string of an arbitrary length.
  1. 値indとsalt。ここで、indは{1,...,N}に属し、saltは{1,...,2^128-1}に属します。

  2. 次の等式を満たす点Q_PW。

       Q_PW = int(F(PW, salt, 2000))*Q_ind.

    点Q_PWを保存せず、プロトコルの開始時にPWを使用して計算することもできます。 その場合、BはPWと点{Q_1,Q_2,...,Q_N}を保存しておく必要があります。

  3. ID_ALG識別子。
  4. 連続した認証試行の失敗の総数を記録するカウンターC_1^Bと、そのような事象の最大許容回数を格納する値CLim_1。
  5. 特定のPWの使用期間中の認証失敗の事象の総数を記録するカウンターC_2^Bと、そのような事象の最大許容回数を格納する値CLim_2。
  6. 特定のPWの使用期間中の認証の事象（成功と失敗の両方）の総数を記録するカウンターC_3^Bと、そのような事象の最大許容回数を格納する値CLim_3。
  7. 主体Bの一意な識別子ID_B（選択できます（OPTIONAL））。これは任意の長さのバイト文字列です。

4.2. Initial Values of the Protocol Counters

4.2. プロトコルのカウンターの初期値

After the setup of a new password value PW, the values of the counters MUST be assigned as follows:

  5. B sends the values of ind, salt, and the ID_ALG identifier to A. B also can OPTIONALLY send the ID_B identifier to A. All subsequent calculations are done by B in the elliptic curve group defined by the ID_ALG identifier.
  6. A sets the curve defined by the received ID_ALG identifier as the used elliptic curve. All subsequent calculations are done by A in this elliptic curve group.
  7. A calculates the point Q_PW^A = int(F(PW, salt, 2000))*Q_ind.

5. Construction of Points {Q_1,...,Q_N}

5. 点{Q_1,...,Q_N}の構成

This section provides an example of a possible algorithm for the generation of each point Q_i in the set {Q_1,...,Q_N} that corresponds to the given elliptic curve E.

このセクションでは、与えられた楕円曲線Eに対応する集合{Q_1,...,Q_N}の各点Q_iを生成するアルゴリズムの一例を示します。

The algorithm is based on choosing points with coordinates with known preimages of a cryptographic hash function H, which is the GOST R 34.11-2012 hash function (see [RFC6986]) with 256-bit output if 2^254 < q < 2^256, and the GOST R 34.11-2012 hash function (see [RFC6986]) with 512-bit output if 2^508 < q < 2^512.

このアルゴリズムは、暗号学的ハッシュ関数Hの原像が既知である座標を持つ点を選ぶことに基づいています。ここで、Hは、2^254 < q < 2^256の場合は256ビット出力のGOST R 34.11-2012ハッシュ関数（[RFC6986]を参照）、2^508 < q < 2^512の場合は512ビット出力のGOST R 34.11-2012ハッシュ関数（[RFC6986]を参照）です。

The algorithm consists of the following steps:

このアルゴリズムは、次のステップで構成されます。

  1. Set i = 1, SEED = 0, s = 4.
  2. Calculate X = int(HASH(BYTES(P) || bytes_s(SEED))) mod p.
  3. Check to see if the value of X^3 + aX + b is a quadratic residue in the field F_p. If it is not, set SEED = SEED + 1 and return to Step 2.
  4. Choose the value of Y = min{r1, r2}, where r1, r2 from {0,1,...,p-1} are such that r1 != r2 and r1^2 = r2^2 = R mod p for R = X^3 + aX + b.
  5. Check to see if the following relations hold for the point Q = (X, Y): Q != O and q*Q = O. If they do, go to Step 6; if not, set SEED = SEED + 1 and return to Step 2.
  6. Set Q_i = Q. If i < N, then set i = i + 1 and go to Step 2; otherwise, finish.
  1. i = 1、SEED = 0、s = 4とします。
  2. X = int(HASH(BYTES(P) || bytes_s(SEED))) mod pを計算します。
  3. X^3 + aX + bの値が体F_pにおける平方剰余であるかどうかを確認します。 平方剰余でない場合、SEED = SEED + 1として、ステップ2に戻ります。
  4. Y = min{r1, r2}の値を選びます。ここで、{0,1,...,p-1}に属するr1、r2は、R = X^3 + aX + bに対してr1 != r2かつr1^2 = r2^2 = R mod pとなるものです。
  5. 点Q = (X, Y)について、次の関係が成り立つかどうかを確認します: Q != Oかつq*Q = O。 成り立つ場合は、ステップ6に進みます。成り立たない場合は、SEED = SEED + 1として、ステップ2に戻ります。
  6. Q_i = Qとします。 i < Nの場合は、i = i + 1として、ステップ2に進みます。それ以外の場合は、終了します。

With the defined algorithm for any elliptic curve E, point sets {Q_1,...,Q_N} are constructed. Constructed points in one set MUST have distinct X-coordinates.

このように定義したアルゴリズムで、任意の楕円曲線Eについて点の集合{Q_1,...,Q_N}を構成します。 1つの集合内の構成された点は、互いに異なるX座標を持たなければなりません（MUST）。

Note: The knowledge of a hash function preimage prevents knowledge of the multiplicity of any point related to generator point P. It is of primary importance, because such knowledge could be used to implement an attack against the protocol with an exhaustive search for the password.

注: ハッシュ関数の原像がわかっていることにより、生成元Pに関する任意の点の倍数を知ることはできなくなります。 これは最も重要な点です。そのような知識は、パスワードの全数探索によってプロトコルを攻撃するのに使われる可能性があるためです。

6. Security Considerations

6. セキュリティーに関する考慮事項

Any cryptographic algorithms -- particularly HASH functions and HMAC functions -- that are used in the SESPAKE protocol MUST be carefully designed and MUST be able to withstand all known types of cryptanalytic attacks.

SESPAKEプロトコルで使用するすべての暗号アルゴリズム（特にHASH関数とHMAC関数）は、慎重に設計されている必要があります（MUST）。また、既知のあらゆる種類の暗号解読攻撃に耐えられる必要があります（MUST）。

It is RECOMMENDED that the HASH function satisfy the following condition:

HASH関数は、次の条件を満たすことが推奨されます（RECOMMENDED）。

  • hashlen <= log_2(q) + 4, where hashlen is the length of the HASH function output.
  • hashlen <= log_2(q) + 4。ここで、hashlenはHASH関数の出力の長さです。

It is RECOMMENDED that the output length of hash functions used in the SESPAKE protocol be greater than or equal to 256 bits.

SESPAKEプロトコルで使用するハッシュ関数の出力長は、256ビット以上であることが推奨されます（RECOMMENDED）。

The points {Q_1,Q_2,...,Q_N} and P MUST be chosen in such a way that they are provably pseudorandom. As a practical matter, this means that the algorithm for generation of each point Q_i in the set {Q_1,...,Q_N} (see Section 5) ensures that the multiplicity of any point under any other point is unknown.

点{Q_1,Q_2,...,Q_N}とPは、証明可能な形で疑似ランダムになるように選択しなければなりません（MUST）。 実際上、これは、集合{Q_1,...,Q_N}の各点Q_iを生成するアルゴリズム（セクション5を参照）によって、任意の点の、他の任意の点に関する倍数が知られていないことが保証されることを意味します。

Using N = 1 is RECOMMENDED.

N = 1を使用することが推奨されます（RECOMMENDED）。

注: この文書で説明するプロトコルについての具体的な攻撃者モデルは、セキュリティー証明を含む[SESPAKE-SECURITY]にあります。

def XGCD(a,b):
  """XGCD(a,b) returns a list of form [g,x,y], where g is GCD(a,b) and
  x,y satisfy the equation g = ax + by."""
  a1=1; b1=0; a2=0; b2=1; aneg=1; bneg=1; swap = False
  if(a < 0):
    a = -a; aneg=-1
  if(b < 0):
    b = -b; bneg=-1
  if(b > a):
    swap = True
    [a,b] = [b,a]
  while (1):
    quot = -(a / b)
    a = a % b
    a1 = a1 + quot*a2; b1 = b1 + quot*b2
    if(a == 0):
      if(swap):
        return [b, b2*bneg, a2*aneg]
      else:
        return [b, a2*aneg, b2*bneg]
    quot = -(b / a)
    b = b % a
    a2 = a2 + quot*a1; b2 = b2 + quot*b1
    if(b == 0):
      if(swap):
        return [a, b1*bneg, a1*aneg]
      else:
        return [a, a1*aneg, b1*bneg]

def getMultByMask( elems, mask ):
  n = len( elems )
  r = 1
  for i in range( n ):

    mask = mask >> 1
  return r

def powF(R, m, p):
  assert R != None
  assert type(m) in (int, long)

  if m == 0:
    assert R != 0
    return 1
  elif m < 0:
    t = invF(R, p)
    return powF(t, (-m), p)
  else:
    i = m.bit_length() - 1
    r = 1
    while i > 0:
      if (m >> i) & 1:
        r = (r * R) % p
      r = (r * r) % p
      i -= 1
    if m & 1:
      r = (r * R) % p
    return r
def add(Px, Py, Qx, Qy, p, a, b):
  if Qx == Qy == None:
    return [Px, Py]

  if Px == Py == None:
    return [Qx, Qy]

  if (Px == Qx) and (Py == negF(Qy, p)):
    return [None, None]

  if (Px == Qx) and (Py == Qy):
    assert Py != 0
    return duplicate(Px, Py, p, a)
  else:
    l = divF( subF( Qy, Py, p ), subF( Qx, Px, p ), p )
    resX = subF( subF( powF( l, 2, p ), Px, p ), Qx, p )
    resY = subF( mulF( l, subF( Px, resX, p ), p ), Py, p )
    return [resX, resY]

def duplicate(Px, Py, p, a):
  if (Px == None) and (Py == None):
    return [None, None]

  if Py == 0:
    return [None, None]

  l = divF(addF(mulF(powF(Px, 2, p), 3, p), a, p), mulF(Py, 2, p), p)
  resX = subF(powF(l, 2, p), mulF(Px, 2, p), p)
  resY = subF(mulF(l, subF(Px, resX, p), p), Py, p)
  return [resX, resY]
def mul(Px, Py, s, p, a, b):
  assert type(s) in (int, long)
  assert Px != None and Py != None

  X = Px
  Y = Py

  i = s.bit_length() - 1
  resX = None
  resY = None
  while i > 0:
    if (s >> i) & 1:
      resX, resY = add(resX, resY, X, Y, p, a, b)
    resX, resY = duplicate(resX, resY, p, a)
    i -= 1
  if s & 1:
    resX, resY = add(resX, resY, X, Y, p, a, b)
  return [resX, resY]

def Ord(Px, Py, m, q, p, a, b):
  assert Px != None and Py != None
  assert (m != None) and (q != None)
  assert mul(Px, Py, m, p, a, b) == [None, None]

  X = Px
  Y = Py
  r = m
  for mask in range(1 << len(q)):
    t = getMultByMask(q, mask)
    Rx, Ry = mul(X, Y, t, p, a, b)
    if (Rx == None) and (Ry == None):
      r = min(r, t)
  return r

  if R == 0:
    assert False
  temp = powF(R, ((p - 1) / 2), p)
  if temp == (p - 1):
    return False
  else:
    assert temp == 1
    return True
def getRandomQuadraticNonresidue(p):
  from random import randint
  r = (randint(2, p - 1)) % p
  while isQuadraticResidue(r, p):
    r = (randint(2, p - 1)) % p
  return r

def ModSqrt( R, p ):
  assert R != None
  assert isQuadraticResidue(R, p)

  if p % 4 == 3:
    res = powF(R, (p + 1) / 4, p)
    if powF(res, 2, p) != R:
      res = None
    return [res, negF(res, p)]
  else:
    ainvF = invF(R, p)

    s = p - 1
    alpha = 0
    while (s % 2) == 0:
      alpha += 1
      s = s / 2

    b = powF(getRandomQuadraticNonresidue(p), s, p)
    r = powF(R, (s + 1) / 2, p)

    bj = 1
    for k in range(0, alpha - 1):  # alpha >= 2 because p % 4 = 1
      d = 2 ** (alpha - k - 2)
      x = powF(mulF(powF(mulF(bj, r, p), 2, p), ainvF, p), d, p)
      if x != 1:
        bj = mulF(bj, powF(b, (2 ** k), p), p)
    res = mulF(bj, r, p)
    return [res, negF(res, p)]
def generateQs( p, pByteSize, a, b, m, q, orderDivisors, Px, Py, N ):

  Qs = []
  S = []
  Hash_src = []
  Hash_res = []
  co_factor = m / q

  seed = 0
  while len( Qs ) != N:
    hashSrc = PxBytes + PyBytes + num2le( seed, 4 )
    if pByteSize == ( 256 / 8 ):
      QxBytes = H256( hashSrc )
    else:
      QxBytes = H512( hashSrc )

    Qx = le2num( QxBytes ) % p

    R = addF( addF( powF(Qx, 3, p ), mulF(Qx, a, p), p), b, p )

    S += [seed]
    Hash_src += [hashSrc]
    Hash_res += [QxBytes]
    seed += 1

  return Qs, S, Hash_src, Hash_res

def XGCD(a,b):
  """XGCD(a,b) returns a list of form [g,x,y], where g is GCD(a,b) and
  x,y satisfy the equation g = ax + by."""
  a1=1; b1=0; a2=0; b2=1; aneg=1; bneg=1; swap = False
  if(a < 0):
    a = -a; aneg=-1
  if(b < 0):
    b = -b; bneg=-1
  if(b > a):
    swap = True
    [a,b] = [b,a]
  while (1):
    quot = -(a / b)
    a = a % b
    a1 = a1 + quot*a2; b1 = b1 + quot*b2
    if(a == 0):
      if(swap):
        return [b, b2*bneg, a2*aneg]
      else:
        return [b, a2*aneg, b2*bneg]
    quot = -(b / a)
    b = b % a
    a2 = a2 + quot*a1; b2 = b2 + quot*b1
    if(b == 0):
      if(swap):
        return [a, b1*bneg, a1*aneg]
      else:
        return [a, a1*aneg, b1*bneg]

  return r

def powF(R, m, p):
  assert R != None
  assert type(m) in (int, long)

  if m == 0:
    assert R != 0
    return 1
  elif m < 0:
    t = invF(R, p)
    return powF(t, (-m), p)
  else:
    i = m.bit_length() - 1
    r = 1
    while i > 0:
      if (m >> i) & 1:
        r = (r * R) % p
      r = (r * r) % p
      i -= 1
    if m & 1:
      r = (r * R) % p
    return r
def add(Px, Py, Qx, Qy, p, a, b):
  if Qx == Qy == None:
    return [Px, Py]

  if Px == Py == None:
    return [Qx, Qy]

  if (Px == Qx) and (Py == negF(Qy, p)):
    return [None, None]

  if (Px == Qx) and (Py == Qy):
    assert Py != 0
    return duplicate(Px, Py, p, a)
  else:
    l = divF( subF( Qy, Py, p ), subF( Qx, Px, p ), p )
    resX = subF( subF( powF( l, 2, p ), Px, p ), Qx, p )
    resY = subF( mulF( l, subF( Px, resX, p ), p ), Py, p )
    return [resX, resY]

def duplicate(Px, Py, p, a):
  if (Px == None) and (Py == None):
    return [None, None]

  if Py == 0:
    return [None, None]

  l = divF(addF(mulF(powF(Px, 2, p), 3, p), a, p), mulF(Py, 2, p), p)
  resX = subF(powF(l, 2, p), mulF(Px, 2, p), p)
  resY = subF(mulF(l, subF(Px, resX, p), p), Py, p)
  return [resX, resY]
def mul(Px, Py, s, p, a, b):
  assert type(s) in (int, long)
  assert Px != None and Py != None

  X = Px
  Y = Py

  i = s.bit_length() - 1
  resX = None
  resY = None
  while i > 0:
    if (s >> i) & 1:
      resX, resY = add(resX, resY, X, Y, p, a, b)
    resX, resY = duplicate(resX, resY, p, a)
    i -= 1
  if s & 1:
    resX, resY = add(resX, resY, X, Y, p, a, b)
  return [resX, resY]

def Ord(Px, Py, m, q, p, a, b):
  assert Px != None and Py != None
  assert (m != None) and (q != None)
  assert mul(Px, Py, m, p, a, b) == [None, None]

  X = Px
  Y = Py
  r = m
  for mask in range(1 << len(q)):
    t = getMultByMask(q, mask)
    Rx, Ry = mul(X, Y, t, p, a, b)
    if (Rx == None) and (Ry == None):
      r = min(r, t)
  return r

def isQuadraticResidue( R, p ):
  if R == 0:
    assert False
  temp = powF(R, ((p - 1) / 2), p)
  if temp == (p - 1):
    return False
  else:
    assert temp == 1
    return True
def getRandomQuadraticNonresidue(p):
  from random import randint
  r = (randint(2, p - 1)) % p
  while isQuadraticResidue(r, p):
    r = (randint(2, p - 1)) % p
  return r

def ModSqrt( R, p ):
  assert R != None
  assert isQuadraticResidue(R, p)

  if p % 4 == 3:
    res = powF(R, (p + 1) / 4, p)
    if powF(res, 2, p) != R:
      res = None
    return [res, negF(res, p)]
  else:
    ainvF = invF(R, p)

    s = p - 1
    alpha = 0
    while (s % 2) == 0:
      alpha += 1
      s = s / 2

    b = powF(getRandomQuadraticNonresidue(p), s, p)
    r = powF(R, (s + 1) / 2, p)

    bj = 1
    for k in range(0, alpha - 1):  # alpha >= 2 because p % 4 = 1
      d = 2 ** (alpha - k - 2)
      x = powF(mulF(powF(mulF(bj, r, p), 2, p), ainvF, p), d, p)
      if x != 1:
        bj = mulF(bj, powF(b, (2 ** k), p), p)
    res = mulF(bj, r, p)
    return [res, negF(res, p)]
def generateQs( p, pByteSize, a, b, m, q, orderDivisors, Px, Py, N ):
  assert pByteSize in ( 256 / 8, 512 / 8 )
  PxBytes = num2le( Px, pByteSize )
  PyBytes = num2le( Py, pByteSize )
  Qs = []
  S = []
  Hash_src = []
  Hash_res = []
  co_factor = m / q

  seed = 0
  while len( Qs ) != N:
    hashSrc = PxBytes + PyBytes + num2le( seed, 4 )
    if pByteSize == ( 256 / 8 ):
      QxBytes = H256( hashSrc )
    else:
      QxBytes = H512( hashSrc )

    Qx = le2num( QxBytes ) % p

    R = addF( addF( powF(Qx, 3, p ), mulF(Qx, a, p), p), b, p )
    if ( R == 0 ) or ( not isQuadraticResidue( R, p ) ):
      seed += 1
      continue

    Qy_sqrt = ModSqrt( R, p )
    Qy = min(Qy_sqrt)
    if co_factor * Ord(Qx, Qy, m, orderDivisors, p, a, b) != m:
      seed += 1
      continue

    Qs += [(Qx, Qy)]
    S += [seed]
    Hash_src += [hashSrc]
    Hash_res += [QxBytes]
    seed += 1

  return Qs, S, Hash_src, Hash_res
