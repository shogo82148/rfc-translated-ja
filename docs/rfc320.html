RFC 320

Workshop on Hard Copy Line Graphics

RFC 320

ハードコピーの線画に関するワークショップ

Abstract

概要

At CMU we have recently interfaced a Xerox Graphic Printer (ex-LDX) to the PDP-10 using a PDP-11 as in intelligent controller for the printer. Specially designed interface and data structures permit the PDP-11 to generate each scan line as needed without having to resort to the brute force generation of the bit image for the whole page.

CMUでは最近、PDP-11をプリンターのインテリジェントなコントローラーとして使い、Xerox Graphic Printer（旧LDX）をPDP-10に接続しました。特別に設計したインターフェイスとデータ構造により、PDP-11は、ページ全体のビットイメージを力ずくで生成することなく、必要に応じて各走査線を生成できます。

The attached pages were produced using this system with the help of a document generation program and a character set design program. This is something personal.

添付のページは、このシステムを使い、文書生成プログラムと文字セット設計プログラムの助けを借りて作成したものです。これは個人的なものです。

XCRIBL SYSTEM COMPUTER SCIENCE DEPARTMENT CARNEGIE-MELLON UNIVERSITY

XCRIBLシステム 計算機科学科 カーネギーメロン大学

What you are now reading is a computer printout produced by the XCRIBL system. Computers printers do not have typefaces like this one nor can they change typefaces. Conventional computer printers cannot print character sets where the center to center distances are not all the same. The machine that printed this document is a facsimile copying machine built by Xerox a number of years ago. The computer science department of Carnegie-Mellon University has designed and constructed the interface to connect it to a minicomputer (PDP-11) which in turn is linked to a large computer, the PDP-10. The equipment has been working since January.

いまあなたが読んでいるのは、XCRIBLシステムで作成したコンピューターの印刷出力です。コンピューターのプリンターには、このような書体はなく、書体を変えることもできません。従来のコンピューターのプリンターでは、文字の中心間の距離がすべて同じではない文字セットは印刷できません。この文書を印刷した機械は、数年前にXeroxが製造したファクシミリ複写機です。カーネギーメロン大学の計算機科学科は、この機械をミニコンピューター（PDP-11）に接続するインターフェイスを設計、製作しました。このミニコンピューターは、さらに大型コンピューターであるPDP-10につながっています。この装置は1月から稼働しています。

The Xerox Graphic Printer (XGP) works in a similar fashion to the Xerox office copiers. Instead of reflecting light off a printed page as in a copier the XGP uses a cathode ray tube similar to old television tubes as a source of light. The image is drawn as a series of dots on the CRT with a resolution of 12 dots per inch. The line of dots is reflected onto a selenium drum which electrostatically attracts a fine black powder to the exposed selenium areas. The powder is transfered to a moving sheet of paper. Finally a fuser melts the powder onto the paper.

Xerox Graphic Printer（XGP）は、Xeroxの事務用複写機と似た仕組みで動作します。複写機のように印刷されたページで光を反射させる代わりに、XGPは光源として、昔のテレビのブラウン管に似た陰極線管（CRT）を使用します。画像は、1インチあたり12ドットの解像度で、CRT上に一連のドットとして描かれます。ドットの列はセレンドラムに反射されます。セレンドラムは、露光したセレンの領域に細かい黒い粉を静電気で引き付けます。その粉は、移動する用紙に転写されます。最後に、定着器が粉を溶かして用紙に定着させます。

To be able to print any character the pattern of dots which will be printed as that character must be entered into the computer along with an indicator of what the pattern represents. To facilitate this a program has been written to design character sets. This program draws a grid on a display terminal. Each box in the grid represents one dot in the final Xerox output. The dots may be set or unset and the character redrawn on the display as frequently as one might desire. Because of the ease with which this may be done it becomes an enjoyable task to design a character set and then be able to change any part of any character.

任意の文字を印刷できるようにするには、その文字として印刷するドットのパターンを、そのパターンが何を表すかを示す情報とともにコンピューターに入力しなければなりません。これを容易にするために、文字セットを設計するプログラムが作成されました。このプログラムは、ディスプレイ端末上に格子を描きます。格子の各マスは、最終的なXeroxの出力の1ドットを表します。ドットはオンにもオフにもでき、文字は好きなだけ何度でもディスプレイ上に描き直すことができます。これが簡単にできるので、文字セットを設計し、どの文字のどの部分でも変更できるようにすることは楽しい作業になります。

The XGP is also capable of drawing lines and gray scale images. The AI group is using the XGP to print pictures of faces and speech spectrograms. The range of possible uses is boundless.

XGPは線や濃淡画像（グレースケール画像）を描くこともできます。AIグループは、XGPを使って顔の写真や音声のスペクトログラムを印刷しています。考えられる用途の範囲は無限です。
