RFC 339

MLTNET - A "Multi-Telnet" Subsystem for Tenex

RFC 339

MLTNET - TENEXのための「マルチTELNET」サブシステム

INTRODUCTION

はじめに

MLTNET is a TELNET-like facility for TENEX which enables a user to control a number of jobs, running on different ARPANET hosts. It multiplexes the user's local console among the remote jobs. MLTNET is useful in applications which require coordinated behavior of several network hosts. In particular, we have found it helpful in debugging programs which make use of the network. The MLTNET program is designed to be easy to use and, while used in remote mode, to be as transparent as possible to the user. It is somewhat less sophisticated than the TENEX user-TELNET program. MLTNET is currently a subsystem on the BBN-TENEX host.

MLTNETは、TENEX用のTELNETに似た機能で、ユーザーが異なるARPANETホスト上で動作する複数のジョブを制御できるようにします。MLTNETは、ユーザーのローカルコンソールをリモートのジョブ間で多重化します。MLTNETは、複数のネットワークホストの協調動作を必要とするアプリケーションで役立ちます。特に、ネットワークを利用するプログラムのデバッグに役立つことがわかっています。MLTNETプログラムは、使いやすく、またリモートモードで使用している間はユーザーにとってできる限り透過的になるように設計されています。TENEXのユーザーTELNETプログラムと比べると、機能はやや簡素です。MLTNETは現在、BBN-TENEXホストのサブシステムとして提供されています。

USING MLTNET

MLTNETの使い方

MLTNET operates in two modes:

MLTNETは2つのモードで動作します。

  1. Local Mode Operation:

    When in local mode MLTNET interprets input types by the user as commands to it. Commands consist of a mnemonic command name followed by zero or more parameters. Included in the commands recognized by MLTNET are ones which enable the user to associate a name of his choice with a connection to an ARPANET site, to establish a connection with a named site, to list the network status as seen from the user's TENEX etc.

  2. Remote Mode Operation

    When operating in remote mode MLTNET makes the user's console appear to be directly connected to a remote site. It transmits input typed by the user to the remote site and prints output recieved from the remote site. Output received from a remote site while the user is in local mode or is interacting with another remote site is buffered for the user by MLTNET.

    MLTNET has been designed to be transparent to the user while operating in remote mode. In particular, when in remote mode it transmits user-types ^C (CONTROL-C, the TENEX "attention" character) and ^T (CONTROL-T, the TENEX "time used query" character) to the remote site. When in local mode ^C and ^T have their usual TENEX effect.

    Occasinally a user may find it necessary to modify the characteristics of a connection to a particular remote site. For example, he may want to have MLTNET echo typed input as it is transmitted. Or, he may be using a remote host which requires both upper and lower case characters from a local terminal which has only upper case; in such a case he would want MLTNET to transmit upper and lower case as appropriate. In remote mode operation MLTNET recognizes "!" as an escape character and interprets the character following it as a command to change the characterristics of the connection currently in use. Commands recognized by MLTNET in remote mode are summerized in the next section. To have MLTNET transmit "!" to the remote site the user types "!!".

  1. ローカルモードの動作：

    ローカルモードでは、MLTNETはユーザーの入力を自分へのコマンドとして解釈します。コマンドは、覚えやすいコマンド名と、それに続く0個以上のパラメーターで構成されます。MLTNETが認識するコマンドには、ユーザーが選んだ名前をARPANETサイトへの接続に関連付けるもの、名前を付けたサイトとの接続を確立するもの、ユーザーのTENEXから見たネットワークの状態を一覧表示するものなどがあります。

  2. リモートモードの動作

    リモートモードで動作しているとき、MLTNETはユーザーのコンソールがリモートサイトに直接接続されているかのように見せます。MLTNETは、ユーザーが入力したものをリモートサイトに送信し、リモートサイトから受信した出力を表示します。ユーザーがローカルモードにいる間や、別のリモートサイトとやり取りしている間にリモートサイトから受信した出力は、MLTNETがユーザーのためにバッファリングします。

    MLTNETは、リモートモードで動作している間はユーザーにとって透過的であるように設計されています。特に、リモートモードでは、ユーザーが入力した^C（CONTROL-C、TENEXの「アテンション」文字）と^T（CONTROL-T、TENEXの「使用時間の問い合わせ」文字）をリモートサイトに送信します。ローカルモードでは、^Cと^Tは通常のTENEXでの効果を持ちます。

    ユーザーは、特定のリモートサイトへの接続の特性を変更する必要に迫られることがあります。たとえば、入力した文字を送信と同時にMLTNETにエコーさせたい場合があります。あるいは、大文字と小文字の両方を必要とするリモートホストを、大文字しか入力できないローカル端末から使っている場合もあります。そのような場合には、MLTNETに大文字と小文字を適切に送信させたいでしょう。リモートモードの動作では、MLTNETは「!」をエスケープ文字として認識し、それに続く文字を、現在使用中の接続の特性を変更するコマンドとして解釈します。MLTNETがリモートモードで認識するコマンドは、次のセクションにまとめてあります。MLTNETにリモートサイトへ「!」を送信させるには、ユーザーは「!!」と入力します。

MLTNET Command Summary

MLTNETのコマンドの概要

Local Mode Commands

ローカルモードのコマンド

MLTNET uses the character "<" to signal the user that it is in local mode ready to accept input. Commands and command parameters may be editted as they are input.The character ^A (CONTROL-A) deletes the last character input. In response to a ^A MLTNET types " deleted. The character ^R (CONTROL-R) causes the input string as collected so far to be retyped (with all editting carried out). MLTNET responds to the character RUBOUT (octal 177) by aborting the current input collecting operation and typeing the ready character "<". The ALTMODE character (octal 175) may be used to invoke command recognition and completion. If insufficient information is availble to recognize an input string as a command MLTNET responds to ALTMODE by ringing the terminal bell. Any prefix which uniquely identifies a command is recognized as that command by MLTNET.

MLTNETは、文字「<」を使って、ローカルモードにあり入力を受け付ける準備ができていることをユーザーに知らせます。コマンドとコマンドのパラメーターは、入力しながら編集できます。文字^A（CONTROL-A）は、最後に入力した文字を削除します。^Aに応答して、MLTNETは「" deleted」と表示します。文字^R（CONTROL-R）を入力すると、それまでに集められた入力文字列が（すべての編集を反映したうえで）再表示されます。MLTNETは、文字RUBOUT（8進数177）に応答して現在の入力収集操作を中止し、準備完了を示す文字「<」を表示します。ALTMODE文字（8進数175）を使うと、コマンドの認識と補完を呼び出せます。入力文字列をコマンドとして認識するのに十分な情報がない場合、MLTNETはALTMODEに応答して端末のベルを鳴らします。コマンドを一意に識別できるプレフィックスであれば、MLTNETはそれをそのコマンドとして認識します。

In the following, <name> and <site> denote command parameters. They are strings terminated by a space or carriage return. <name> is a user chosen string of 14 characters or less; site is either the name of an ARPANET host or the string "LOCAL".

以下では、<name>と<site>はコマンドのパラメーターを表します。これらは、スペースまたはキャリッジリターンで終わる文字列です。<name>はユーザーが選ぶ14文字以下の文字列です。siteは、ARPANETホストの名前か、文字列「LOCAL」のいずれかです。

The commands recognized by MLTNET in local mode are:

MLTNETがローカルモードで認識するコマンドは次のとおりです。

ASSIGN:
syntax:
ASSIGN <name> <site>
effect:
Associates the user chosen string <name> with a connection to the ARPANET site <site>.
TALK:
syntax:
TALK <name>
effect:
Switches from command mode to remote mode directing subsequent console input to the site associated with <name>. If no ARPANET site is currently associated with <name>, the user is asked to spesify a site. The first time the user "talks" to a particular named site MLTNET goes through the ARPANET initial connection protocol with the remote site in order to establish a duplex connection with it.
NAMES:
syntax:
NAMES
effect:
Prints on the console the <name>/<site> associatins currently known to MLTNET.
QUIT:
syntax:
QUIT
effect:
Returns control to the TENEX EXEC breaking all connections with remote hosts. It is good practice to log out of each remote host before using the QUIT command.
NETSTAT:
syntax:
NETSTAT
effect:
Prints on the console the network status as seen from the local TENEX.
RENAME:
syntax:
RENAME <name>1 <name>2
effect:
Associates <name>2 with the ARPANET site previously associated with <name>1.
FLUSH:
syntax:
FLUSH <name>
effect:
Breaks the network connection with the ARPANET site associated with <name> and, in addition, breaks the association between <name> and that site.
HOSTS:
syntax:
HOSTS
effect:
Prints on the console the list of hosts currently known to the MLTNET subsystem.
HELP:
syntax:
HELP
effect:
Prints on the console a breif summary of how to use MLTNET.
ASSIGN:
構文：
ASSIGN <name> <site>
効果：
ユーザーが選んだ文字列<name>を、ARPANETサイト<site>への接続に関連付けます。
TALK:
構文：
TALK <name>
効果：
コマンドモードからリモートモードに切り替え、以降のコンソール入力を<name>に関連付けられたサイトに向けます。<name>に現在関連付けられているARPANETサイトがない場合は、ユーザーにサイトの指定を求めます。ユーザーが名前の付いた特定のサイトと初めて「対話（talk）」するとき、MLTNETはリモートサイトとの間で全二重の接続を確立するために、そのリモートサイトとARPANETの初期接続プロトコルを実行します。
NAMES:
構文：
NAMES
効果：
MLTNETが現在把握している<name>/<site>の関連付けをコンソールに表示します。
QUIT:
構文：
QUIT
効果：
リモートホストとのすべての接続を切断して、TENEXのEXECに制御を戻します。QUITコマンドを使う前に、各リモートホストからログアウトしておくのがよい習慣です。
NETSTAT:
構文：
NETSTAT
効果：
ローカルのTENEXから見たネットワークの状態をコンソールに表示します。
RENAME:
構文：
RENAME <name>1 <name>2
効果：
それまで<name>1に関連付けられていたARPANETサイトに、<name>2を関連付けます。
FLUSH:
構文：
FLUSH <name>
効果：
<name>に関連付けられたARPANETサイトとのネットワーク接続を切断し、さらに<name>とそのサイトとの関連付けも解除します。
HOSTS:
構文：
HOSTS
効果：
MLTNETサブシステムが現在把握しているホストの一覧をコンソールに表示します。
HELP:
構文：
HELP
効果：
MLTNETの使い方の簡単な概要をコンソールに表示します。

Remote Mode Commands

リモートモードのコマンド

In remote mode MLTNET recognizes the escape character "!" as a signal to interpret the following character as a command. Currently MLTNET recognizes the following characters as commands to it:

リモートモードでは、MLTNETはエスケープ文字「!」を、続く文字をコマンドとして解釈する合図として認識します。現在、MLTNETは次の文字を自分へのコマンドとして認識します。

Q:
(quit) Causes MLTNET to switch from remote mode to local mode.
L:
(local echo) Causes MLTNET to echo characters as it transmits them to the remote site. ;L is the inverse of R. The default case.
R:
(remote echo) Causes MLTNET to transmit characters typed to it without echoing them; invers of L.
U:
(upper case) Causes MLTNET to transmit upper case letters as typed; the inverse of S. The default case.
S:
(small letters - lower case): Causes MLTNET to transmit upper case letters typed to it as lower case letters. In this mode of operation "^" acts as a shift key; "^" may be transmitted by typing "!^". S is the inverse of U.
X:
(where X is any character other than Q, L, R, U or S): Causes MLTNET to transmit X.
Q:
（quit）MLTNETをリモートモードからローカルモードに切り替えます。
L:
（local echo）MLTNETに、文字をリモートサイトに送信すると同時にエコーさせます。;LはRの逆です。これがデフォルトです。
R:
（remote echo）MLTNETに、入力された文字をエコーせずに送信させます。Lの逆です。
U:
（upper case）MLTNETに、大文字を入力されたとおりに送信させます。Sの逆です。これがデフォルトです。
S:
（small letters - lower case）：MLTNETに、入力された大文字を小文字として送信させます。この動作モードでは、「^」がシフトキーとして働きます。「^」を送信するには「!^」と入力します。SはUの逆です。
X:
（XはQ、L、R、U、S以外の任意の文字）：MLTNETにXを送信させます。
