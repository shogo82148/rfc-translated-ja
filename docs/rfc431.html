RFC 431

Update on SMFS Login and Logout

RFC 431

SMFSのLoginとLogoutについての更新

Abstract

概要

This document replaces RFC 399, which introduced the Login and Logout commands for UCSB's SMFS, but was incomplete. RFC 399 is restated here, followed by a description of the nature of the response elicted by these commands

この文書は、UCSBのSMFSにLoginコマンドとLogoutコマンドを導入したものの不完全だったRFC 399を置き換えます。ここではRFC 399の内容を改めて述べ、続いてこれらのコマンドが引き起こす応答の性質を説明します。

Two new commands have been added to UCSB's Simple Minded File System (SMFS). They are described below.

UCSBのSimple Minded File System（SMFS）に、2つの新しいコマンドが追加されました。以下でそれらを説明します。

Login (LGI)

Login（LGI）

The Login command is the means whereby the user identifies himself and specifies the account number to which his use of SMFS is to be billed. The user should issue a LGI command directly after completing the ICP and before any command referencing a file. The user name and account number specified remain in effect until another LGI command is issued, a LGO command is issued, or the connection is close.

Loginコマンドは、ユーザーが自分自身を識別し、SMFSの利用料金を請求する勘定番号（account number）を指定するための手段です。ユーザーは、ICPを完了した直後、ファイルを参照するコマンドを発行する前に、LGIコマンドを発行すべきです。指定したユーザー名と勘定番号は、別のLGIコマンドが発行されるか、LGOコマンドが発行されるか、接続が閉じられるまで有効です。

At present, the use of SMFS is not billed, and therefore use of the accounting command is optional. It is requested, however, that users and user processes begin to use this command as soon as possible, since we would like to collect statistics on SMFS utilization before implementing billing. Therefore, at present the user name can be any name that identifies the user, and the account number is completely arbitrary.

現在のところ、SMFSの利用は課金されていないので、この課金用のコマンドの使用は任意です。しかし、課金を実施する前にSMFSの利用状況の統計を集めたいので、ユーザーやユーザープロセスには、できるだけ早くこのコマンドを使い始めていただくようお願いします。したがって、現時点では、ユーザー名はユーザーを識別できる名前なら何でもよく、勘定番号はまったく任意でかまいません。

The format of the LGI command is given below. Note that the lengths of the fixed-length fields are given in bits. The op code for LGI is decimal 13.

LGIコマンドの形式を以下に示します。固定長フィールドの長さはビット単位で示していることに注意してください。LGIのオペコードは10進数の13です。

           8
       <op code><user name><account number>

           8
       <op code><user name><account number>

The <user name> and <account number> fields are further divided as follows:

<user name>フィールドと<account number>フィールドは、さらに次のように分割されます。

          8     8*length
      <length><user name>

          8     8*length
      <length><user name>

Where <length> gives the length in 8-bit characters of the <user name> or <account number> subfield. The maximum length of <user name> is eight characters and of <account number> is four characters. The <user name> and <account number> fields must consist of characters chosen from the same character set as filenames.

ここで、<length>は、<user name>または<account number>サブフィールドの長さを8ビット文字の数で表します。<user name>の最大長は8文字、<account number>の最大長は4文字です。<user name>フィールドと<account number>フィールドは、ファイル名と同じ文字集合から選んだ文字で構成しなければなりません。

Logout (LGO)

Logout（LGO）

The logout command terminates the association between the user and the accounting information specified in the last LGI command issued, if any; it does not cause SMFS to close the connection. The user should then issue another LGI command before attempting any operation referencing a file. It is not necessary to issue a LGO command before issuing another LGI command, or before closing the connection.

Logoutコマンドは、ユーザーと、直前に発行したLGIコマンドで指定した課金情報（あれば）との対応付けを終了します。SMFSが接続を閉じることはありません。その後、ユーザーは、ファイルを参照する操作を試みる前に、もう一度LGIコマンドを発行すべきです。別のLGIコマンドを発行する前や、接続を閉じる前に、LGOコマンドを発行する必要はありません。

Again, at the present time the LGO command is optional, and does not affect the user's ability to reference files.

繰り返しになりますが、現時点ではLGOコマンドは任意であり、ユーザーがファイルを参照できるかどうかには影響しません。

The format of the LGO command is as follows:

LGOコマンドの形式は次のとおりです。

           8
       <op code>

           8
       <op code>

The op code for LGO is decimal 14.

LGOのオペコードは10進数の14です。

Login and logout each elicit, as their only response, an eight-bit completion code. Like the other SMFS commands, the completion code is equal to the command's op code if the command was successful. The following error completion codes, given in decimal, are currently defined:

LoginとLogoutは、どちらも唯一の応答として8ビットの完了コードを返します。ほかのSMFSコマンドと同様に、コマンドが成功した場合、完了コードはそのコマンドのオペコードと等しくなります。現在、次のエラー完了コード（10進数）が定義されています。

47
The length of <user name> is zero.
48
<user name> is too long.
49
<user name> contains invalid characters.
50
The length of <account number> is zero.
51
<account number> is too long.
52
<account number> contains invalid characters.
53
<user name) specifies an invalid user.
54
<account number> specifies an invalid account.
47
<user name>の長さがゼロです。
48
<user name>が長すぎます。
49
<user name>に無効な文字が含まれています。
50
<account number>の長さがゼロです。
51
<account number>が長すぎます。
52
<account number>に無効な文字が含まれています。
53
<user name)が無効なユーザーを指定しています。
54
<account number>が無効な勘定を指定しています。
