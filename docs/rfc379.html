RFC 379

Using TSO at CCN

RFC 379

CCNでのTSOの利用

Abstract

概要

IBM's Time Sharing Option ("TSO") is now available at CCN for use via the Network with Telnet Protocol. TSO is not yet considered "production" by CCN, since there are a number of restrictions and glitches to be removed or documented. However, TSO is now quite stable and is up on a regularly scheduled basis; the system will allow an experienced programmer to work productively at CCN. To use TSO, you will need a valid CCN charge (billing) number, and a user-id. To obtain a charge number (if you do not already have one), or to obtain a TSO user-id, contact Barbara Noble at (213) 825-7438 or (213) 825-7452. At present we are not charging for TSO use (although any batch jobs submitted from TSO will be charged to your account). Barbara can assign on overhead charge number for experimental use of TSO if you do not have a paid account.

IBMのTime Sharing Option（「TSO」）が、CCNでTelnetプロトコルを使ってネットワーク経由で利用できるようになりました。取り除くか文書化すべき制約や不具合がいくつもあるため、CCNはTSOをまだ「本番運用」とはみなしていません。しかし、TSOは現在かなり安定しており、定期的なスケジュールで稼働しています。経験のあるプログラマーであれば、このシステムを使ってCCNで生産的に作業できるでしょう。TSOを使うには、有効なCCNの課金（請求）番号とユーザーIDが必要です。課金番号を（まだ持っていなければ）取得するか、TSOのユーザーIDを取得するには、Barbara Noble（(213) 825-7438または(213) 825-7452）に連絡してください。現在、TSOの利用には課金していません（ただし、TSOから投入したバッチジョブはあなたのアカウントに課金されます）。有料のアカウントを持っていない場合は、TSOを試験的に使うための間接費用の課金番号をBarbaraが割り当てることができます。

Modes of TSO Use

TSOの利用形態

(1) Conversational Remote Job Entry

(1) 会話型リモートジョブエントリー

Using TSO you can prepare an OS job stream using the TSO EDIT command, SUBMIT the job to batch execution, monitor its STATUS, and ship the OUTPUT back to EDIT for examination. This allows those of you with TIP'S to process jobs at CCN without using NETRJS via a friendly TENEX machine. Any batch job can be submitted this way.

TSOを使うと、TSOのEDITコマンドでOSのジョブストリームを準備し、そのジョブをバッチ実行に投入（SUBMIT）し、その状態（STATUS）を監視し、出力（OUTPUT）をEDITに戻して確認できます。これにより、TIPを使っている人は、友好的なTENEXマシンを経由してNETRJSを使わなくても、CCNでジョブを処理できます。どんなバッチジョブでもこの方法で投入できます。

(2) Foreground Execution

(2) フォアグラウンド実行

Many OS/360 programs can be run, with varying degrees of inconvenience, directly from the terminal. There are TSO commands providing the facilities of EXEC and DD cards; the output stream can be directed to the user's terminal. There are some important limitations to foreground operation, however:

多くのOS/360プログラムは、不便さの程度はさまざまですが、端末から直接実行できます。EXECカードやDDカードの機能を提供するTSOコマンドがあり、出力ストリームをユーザーの端末に向けることができます。ただし、フォアグラウンドでの操作には、いくつかの重要な制限があります。

  1. The foreground region size is limited; at present, it is 128K, though this will be expanded.
  2. All datasets referenced must be on resident disk packs; no disks or tapes can be mounted.
  3. Since you are time-sliced and swapped, it can be very slow.
  1. フォアグラウンドの領域サイズは制限されています。現在は128Kですが、これは拡張される予定です。
  2. 参照するデータセットはすべて常駐ディスクパック上になければなりません。ディスクやテープをマウントすることはできません。
  3. タイムスライスされスワップされるので、非常に遅くなることがあります。

There are two important cases of foreground execution:

フォアグラウンド実行には、重要な場合が2つあります。

  1. The TEST command provides DDT-like debugging capability for foreground programs.
  2. The user's own program can interact with his terminal.
  1. TESTコマンドは、フォアグラウンドのプログラムに対してDDTのようなデバッグ機能を提供します。
  2. ユーザー自身のプログラムが、ユーザーの端末と対話できます。

NOTE: It is not yet possible for a program, either in batch or foreground, to open direct Network connections.

注: バッチでもフォアグラウンドでも、プログラムがネットワークの接続を直接開くことはまだできません。

Hours of Operation

運用時間

Monday through Friday, 6 A.M. - Noon PDT (or 9 A.M. - 3 P.M. EDT). These hours will be extended before September 1, 1972.

月曜日から金曜日の午前6時から正午まで（PDT）（EDTでは午前9時から午後3時まで）です。この時間帯は1972年9月1日より前に拡大される予定です。

Telnet Protocol

Telnetプロトコル

The document "USING TSO VIA ARPA NETWORK VIRTUAL TERMINAL", RFC #377 describes the use of a Telnet NVT to access TSO. There are some significant differences from using a real 2741 locally. RFC #377 describes the current server Telnet, complete with an annoying bug. A later version will include the following capabilities not presently available:

文書「USING TSO VIA ARPA NETWORK VIRTUAL TERMINAL」（RFC #377）は、TSOにアクセスするためのTelnet NVTの使い方を説明しています。本物の2741をローカルで使う場合とは、いくつか大きな違いがあります。RFC #377は、厄介なバグも含めて、現在のサーバーTelnetについて説明しています。後の版では、現在は利用できない次の機能が含まれる予定です。

  1. "FULL DUPLEX", i.e., CCN echoing.
  2. Lower case input.
  3. The special character translation included in NETRJS users with Model 33 Teletypes. (see RFC #338).
  4. Optional specification of single CR or single LF as end-of-line indication
  5. Hopefully, the input attention bug described in RFC #377 will be fixed.
  1. 「全二重（FULL DUPLEX）」、つまりCCNによるエコー。
  2. 小文字の入力。
  3. Model 33テレタイプを使うNETRJSのユーザー向けに含まれている特殊文字の変換（RFC #338を参照）。
  4. 行末の指示として、CRだけまたはLFだけを任意に指定できること
  5. うまくいけば、RFC #377で説明している入力アテンションのバグが修正されるでしょう。

Disk Space

ディスク領域

TSO will automatically place datasets created in the foreground (e.g., by EDIT or ALLOC) on the proper resident disk pack. All TSO datasets are cataloged, and can be referenced by name alone (no volume or unit specification is necessary). For most purposes, you can pretend we have one big disk.

TSOは、フォアグラウンドで（たとえばEDITやALLOCによって）作成されたデータセットを、適切な常駐ディスクパックに自動的に配置します。TSOのデータセットはすべてカタログに登録され、名前だけで参照できます（ボリュームやユニットの指定は必要ありません）。ほとんどの目的では、大きなディスクが1つあるとみなしてかまいません。

Dataset Names

データセット名

The standard IBM version of TSO uses the TSO user-id as the highest index of each dataset name. At CCN, the _two_ highest levels are the charge number and the user-id of the person who created the dataset. TSO has been modified accordingly.

IBMの標準版のTSOでは、TSOのユーザーIDを各データセット名の最上位の索引として使います。CCNでは、_上位2つ_のレベルが、課金番号と、そのデータセットを作成した人のユーザーIDです。TSOはそれに合わせて修正されています。

Dataset Access Control

データセットのアクセス制御

In general, under TSO a user can access for reading, writing, or execution any dataset named with the charge number with which he is logged on. In addition, he can rename or scratch any dataset with the logon charge number. There is no provision for public or read-only datasets a present.

一般に、TSOのもとでは、ユーザーはログオンしたときの課金番号が名前に付いたデータセットであれば、どれでも読み取り、書き込み、実行のためにアクセスできます。さらに、ログオンした課金番号の付いたデータセットであれば、名前を変えたり消去（scratch）したりできます。現在のところ、公開のデータセットや読み取り専用のデータセットの仕組みはありません。

Logging On

ログオン

Most Network users will need only the simple form of LOGON:

ほとんどのネットワークユーザーは、単純な形式のLOGONだけを使えば済みます。

                   logon     <user-id>

                   logon     <user-id>

     EXAMPLE:                         NOTES:
     -------                          -----

          user:  logon uid            (Use your user-id)

          TSO:   LOGON UID            (TSO repeats line for reasons of its own)

          TSO:  ENTER PASSWORD        (TSO asks for password)

          user:  xyz

          TSO:  UID LOGON IN PROGRESS AT 11:37:43 ON AUGUST 9, 1984

          TSO:  LOGON PROCEEDING      (It may take a while.  This message will
                                      come every 30 seconds.)

          TSO:  WELCOME TO TSO.  GOOD LUCK

          TSO:  READY

     EXAMPLE:                         NOTES:
     -------                          -----

          user:  logon uid            (Use your user-id)

          TSO:   LOGON UID            (TSO repeats line for reasons of its own)

          TSO:  ENTER PASSWORD        (TSO asks for password)

          user:  xyz

          TSO:  UID LOGON IN PROGRESS AT 11:37:43 ON AUGUST 9, 1984

          TSO:  LOGON PROCEEDING      (It may take a while.  This message will
                                      come every 30 seconds.)

          TSO:  WELCOME TO TSO.  GOOD LUCK

          TSO:  READY

User-id's are created in TSO with a blank password. To add or change your password, use the CHANGE command. If you have TSO access under more than one charge number, LOGON will prompt you for the charge number to be used for the session.

TSOのユーザーIDは、空のパスワードで作成されます。パスワードを追加または変更するには、CHANGEコマンドを使ってください。複数の課金番号でTSOにアクセスできる場合は、そのセッションで使う課金番号をLOGONが尋ねてきます。

Where to Get Help

ヘルプの入手先

  1. To obtain a list of TSO commands enter: "help commands"
  2. To get detailed information on syntax and function of a particular command, enter: "help <command name> <qualifiers>" Type "help help" for details.

  3. The SEND command may be useful for on-line help from PCN (Pete Nielsen) or WDD (Bill Drain), when they are signed on. You can find out if PCN or WDD is on by sending them a trial message.

            EXAMPLE:
        -------

               User:  send 'hello' user(wdd)

               TSO:   USER WDD NOT LOGGED ON

               TSO:   READY

               user:  send 'hello' user(pcn)

               TSO:   READY

               user:  send 'edit is acting funny' user(pcn)

               TSO:   READY

    Here "PCN" was logged on and got your message. You can, therefore, converse with him through SEND. The text in one SEND is limited to 115 characters.

  4. You can also leave a message for wdd to receive when he logs on by typing: send '<message>' user(wdd) logon.
  5. To send a message to the CCN operator, enter simply: send '<message>'
  6. You can call the CCN Telephone Consultant at (213) 825-7452, Monday through Friday during the hours 10-12 A.M. PDT and 1-4 P.M. (except 3-4 P.M. on Thursday). If the consultant does not know the answer, he/she will investigate and call you back.
  7. You can call the general contact for Network user problems, Barbara Noble, at (213) 825-7438. Barbara is also one of the Telephone consultants.
  8. If all else fails, call Bill Drain, the CCN Systems Programmer in charge of TSO installation. His telephone is (213) 825-7474 (if no answer, call my secretary at (213) 825-7518 and leave a message for Bill).

  9. You can also send a message to someone at CCN by submitting the following pseudo-job through RJS at TSO:

                       //<charge number>  JOB 'BIN=9906',MSGLASS=C
                   //*  <message>
                   //*
                   //*
                   //*
                   //*
                   etc.
  1. TSOのコマンドの一覧を得るには、「help commands」と入力してください。
  2. 特定のコマンドの構文と機能に関する詳しい情報を得るには、「help <command name> <qualifiers>」と入力してください。詳しくは「help help」と入力してください。

  3. PCN（Pete Nielsen）またはWDD（Bill Drain）がサインオンしているときは、SENDコマンドを使ってオンラインでヘルプを得られることがあります。PCNやWDDがいるかどうかは、試しにメッセージを送ってみればわかります。

            EXAMPLE:
        -------

               User:  send 'hello' user(wdd)

               TSO:   USER WDD NOT LOGGED ON

               TSO:   READY

               user:  send 'hello' user(pcn)

               TSO:   READY

               user:  send 'edit is acting funny' user(pcn)

               TSO:   READY

    この例では「PCN」がログオンしていて、あなたのメッセージを受け取りました。したがって、SENDを通じて彼と会話できます。1回のSENDで送れるテキストは115文字までです。

  4. send '<message>' user(wdd) logonと入力すると、wddがログオンしたときに受け取るメッセージを残すこともできます。
  5. CCNのオペレーターにメッセージを送るには、単にsend '<message>'と入力してください。
  6. 月曜日から金曜日の午前10時から12時（PDT）と午後1時から4時（木曜日の午後3時から4時を除く）には、CCNの電話相談員（Telephone Consultant）に(213) 825-7452で電話できます。相談員が答えを知らなければ、調査して折り返し電話します。
  7. ネットワークユーザーの問題に関する総合窓口であるBarbara Nobleに、(213) 825-7438で電話できます。Barbaraは電話相談員の1人でもあります。
  8. ほかの手段がすべてうまくいかなければ、TSOの導入を担当しているCCNのシステムプログラマーであるBill Drainに電話してください。彼の電話番号は(213) 825-7474です（応答がなければ、私の秘書に(213) 825-7518で電話して、Bill宛てのメッセージを残してください）。

  9. TSOでRJSを通じて次の疑似ジョブを投入することで、CCNの誰かにメッセージを送ることもできます。

                       //<charge number>  JOB 'BIN=9906',MSGLASS=C
                   //*  <message>
                   //*
                   //*

                   //*
                   etc.
