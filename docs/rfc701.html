RFC 701

August, 1974, survey of New-Protocol Telnet servers

RFC 701

1974年8月の新プロトコルTelnetサーバーの調査

Abstract

概要

THIS IS THE FIRST OF WHAT ARE PLANNED TO BE MONTHLY REPORTS ON THE STATUS OF THE NEW-PROTOCOL TELNET IMPLEMENTAIONS ON THE SERVER HOSTS ON THE ARPA NETWORK. INCLUDED IN THIS REPORT ARE DATA ONLY ON SERVER TELNETS AT THE VARIOUS SITES. ONE WOULD HOPE THAT ANY SITE WITH AN OPERATIONAL NEW-PROTOCOL SERVER TELNET WOULD ALSO BOAST A NEW-PROTOCOL USER TELNET; WE CAN CERTAINLY ASSUME THIS FOR TENEX SITES AT WHICH TENEX 1.32 IS OPERATING. HOWEVER, NO FURTHER CLAIMS ARE MADE FOR THE SERVER DATA CONTAINED IN THIS REPORT.

これは、ARPAネットワーク上のサーバーホストにおける新プロトコル（New-Protocol）TELNETの実装状況について、毎月報告する予定のレポートの第1回です。このレポートに含まれるのは、各サイトのServer TELNETについてのデータだけです。新プロトコルのServer TELNETが稼働しているサイトであれば、新プロトコルのUser TELNETも備えていることが望まれます。TENEX 1.32が稼働しているTENEXのサイトについては、確実にそうだと想定できます。ただし、このレポートに含まれるサーバーのデータについて、それ以上のことは主張しません。

I AM SORRY TO REPORT THAT AT THIS LATE DATE, A MONTH AFTER THE RELEASE OF TENEX 1.32, LESS THAN ONE-THIRD OF THE SERVER SITES HAVE ANY NEW-PROTOCOL SERVER OPERATING, ACCORDING TO MY SURVEYS*, AND ONLY HALF OF THOSE ARE USING CORRECTLY THE LOGGER SOCKET CONVENTIONS, AS I UNDERSTAND THEM. AT THE END OF THIS REPORT IS A COMPLETE TABULATION COMPILED FROM MY SURVEYS; THE FOLLOWING IS A SUMMARY:

残念ながら、TENEX 1.32のリリースから1か月が経ったこの時期になっても、私の調査*によれば、何らかの新プロトコルサーバーを稼働させているサーバーサイトは3分の1未満であり、そのうち私の理解する限りでロガーソケットの慣例を正しく使っているのは半分にすぎないことを報告しなければなりません。このレポートの最後に、私の調査から作成した完全な一覧表があります。概要は次のとおりです：

NOTES:

注記：

*
ALL DATA IN THIS REPORT WERE GATHERED VIA A SURVEYING PROGRAM RUN AT VARIOUS TIMES, PLUS A FEW MANUAL CHECKS TO FILL OUT THE DATA. WHAT IS REPORTED HERE IS THE WAY THE VARIOUS SERVERS WORK AS SEEN BY THE NEW-PROTOCOL USER TELNET AT BBNA, AS OF 15 AUG. 1974. THERE MAY BE DISCREPANCIES BETWEEN THESE RESULTS AND THOSE FROM SURVEYS MADE AT OTHER SITES.
(1)
NUMEROUS ATTEMPTS TO CONNECT TO THESE SITES ALL FAILED DUE TO THE SITES' BEING DOWN TO THE NETWORK.
(2)
THESE ARE THE SITES WHOSE OPERATION IS 100% CORRECT ACCORDING TO ALL PROTOCOLS AND CONVENTIONS, AS I UNDERSTAND THEM.
(3)
WE REALIZE THAT SOME OF THE SERVERS THAT APPEAR HERE AS NEW-PROTOCOL SERVERS ON SOCKET 1 ARE ACTUALLY SERVERS WHICH ATTEMPT TO COMMUNICATE WITH BOTH OLD- AND NEW-PROTOCOL USER TELNETS ACCORDING TO WHAT CONTROL SEQUENCES ARE RECEIVED.
*
このレポートのデータはすべて、さまざまな時刻に実行した調査プログラムで収集し、データを補うためにいくつか手作業で確認したものです。ここに報告しているのは、1974年8月15日時点で、BBNAの新プロトコルのUser TELNETから見た各サーバーの動作です。これらの結果と、他のサイトで行われた調査の結果とは食い違うことがあるかもしれません。
(1)
これらのサイトへの接続を何度も試みましたが、サイトがネットワークに対してダウンしていたため、すべて失敗しました。
(2)
これらは、私の理解する限り、すべてのプロトコルと慣例に照らして100%正しく動作しているサイトです。
(3)
ここでソケット1の新プロトコルサーバーとして挙げているサーバーの一部は、実際には受信した制御シーケンスに応じて、旧プロトコルと新プロトコルの両方のUser TELNETと通信しようとするサーバーであることは承知しています。
