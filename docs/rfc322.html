RFC 322

Well Known Socket Numbers

RFC 322

ウェルノウンソケット番号

Abstract

概要

The Network Measurement Group would like to establish a network standard socket number for a Process Discard service (not all HOSTs need cooperate.) To do this, it is necessary to know which sockets at each HOST have already been allocated to standard network functions.

Network Measurement Groupは、Process Discardサービスのためのネットワーク標準ソケット番号を定めたいと考えています（すべてのホストが協力する必要はありません）。そのためには、各ホストでどのソケットがすでに標準のネットワーク機能に割り当てられているかを知る必要があります。

At all HOSTs which permit login for services, socket 1 is the Network Logger on which ICP may be performed.

サービスへのログインを許可しているすべてのホストでは、ソケット1がNetwork Loggerであり、そこでICPを実行できます。

We would like to catalog other sockets which are supposed to be well-known, so we would appreciate having a note or phone call from each HOST Technical Liaison describing the function and socket numbers of network service programs at each HOST. The catalog will be published and we would recommend that it be maintained at NIC.

私たちは、ウェルノウンであるはずのほかのソケットの一覧を作りたいと考えています。そこで、各ホストの技術連絡担当者（HOST Technical Liaison）から、そのホストのネットワークサービスプログラムの機能とソケット番号を説明するメモか電話をいただけるとありがたいです。この一覧は公開する予定であり、NICで維持管理することを推奨します。
