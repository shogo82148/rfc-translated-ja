RFC 459

Network Questionnaires

RFC 459

ネットワークのアンケート

Abstract

概要

In recent times, a steady stream of questionnaires has been arriving from the network community. Each questionnaire creates an additional distraction from more useful work and raises the general annoyance level somewhat. The arrival of the seven-page NCP questionnaire (RFC 460) has pushed the annoyance level over the top.

最近、ネットワークコミュニティーからアンケートが次から次へと届いています。アンケートが届くたびに、もっと有益な仕事から気がそらされ、全体的ないら立ちが少しずつ高まります。7ページにわたるNCPのアンケート（RFC 460）が届いたことで、いら立ちは限界を超えました。

We are wondering if any of the questionnaire polluters has given any thought to the fact that it takes time to fill out these questionnaires especially if one wants to do a conscientious job and provide reasonable answers to questions which are frequently only partially applicable.

アンケートをまき散らしている人たちのうち、誰か一人でも、こうしたアンケートに記入するには時間がかかるという事実について考えたことがあるのでしょうか。誠実に取り組み、一部しか当てはまらないことの多い質問に対してまっとうな回答をしようとすればなおさらです。

It seems rather presumptuous for RFC 460 to provide a lengthy questionnaire without any explanation as to the motivation for it and then request a response in two weeks. And tantalize us yet with the promise of additional questionnaires in the future.

RFC 460が、その動機について何の説明もなく長いアンケートを出し、そのうえ2週間以内の回答を求めるのは、いささか厚かましいように思えます。しかも、今後さらにアンケートを出すと約束して、私たちをじらすのです。

Sites which have the luxury of people who have nothing better to do than create questionnaires and other meta-work should realize that there are some sites that operate with limited personnel resources, do have something better to do, and will get nothing done if they are continually swamped with all kinds of meta-work.

アンケートやその他のメタワークを作るくらいしかすることのない人を抱えるぜいたくが許されるサイトは、限られた人員で運営しており、ほかにやるべきことがちゃんとあり、あらゆる種類のメタワークに絶えず追われていては何も片づかないサイトもあるということを理解すべきです。

This material has not been reviewed for public release and is intended only for use with the ARPA network. It should not be quoted or cited in any publication not related to the ARPA network.

この資料は一般公開のための審査を受けておらず、ARPAネットワークでの利用のみを意図しています。ARPAネットワークに関係のない出版物で引用したり参照したりしないでください。
