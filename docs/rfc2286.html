RFC 2286

Test Cases for HMAC-RIPEMD160 and HMAC-RIPEMD128

RFC 2286

HMAC-RIPEMD160およびHMAC-RIPEMD128のテストケース

Abstract

概要

This document provides two sets of test cases for HMAC-RIPEMD160 and HMAC-RIPEMD128, respectively. HMAC-RIPEMD160 and HMAC-RIPEMD128 are two constructs of the HMAC [HMAC] message authentication function using the RIPEMD-160 and RIPEMD-128 [RIPE] hash functions. The test cases and results provided in this document are meant to be used as a conformance test for HMAC-RIPEMD160 and HMAC-RIPEMD128 implementations.

この文書は、HMAC-RIPEMD160とHMAC-RIPEMD128のそれぞれについて、2組のテストケースを提供します。HMAC-RIPEMD160とHMAC-RIPEMD128は、RIPEMD-160およびRIPEMD-128 [RIPE]ハッシュ関数を使用した、HMAC [HMAC]メッセージ認証関数の2つの構成です。この文書で提供するテストケースと結果は、HMAC-RIPEMD160とHMAC-RIPEMD128の実装に対する適合性テストとして使用することを意図しています。

1. Introduction

1. はじめに

The general method for constructing a HMAC message authentication function using a particular hash function is described in section 2 of [HMAC].

特定のハッシュ関数を使用してHMACメッセージ認証関数を構成する一般的な方法は、[HMAC]のセクション2で説明されています。

In sections 2 and 3 test cases for HMAC-RIPEMD160 and HMAC-RIPEMD128, respectively are provided. Each case includes the key, the data, and the result. The values of keys and data are either hexadecimal numbers (prefixed by "0x") or ASCII character strings in double quotes. If a value is an ASCII character string, then the HMAC computation for the corresponding test case DOES NOT include the trailing null character ('\0') in the string.

セクション2とセクション3では、それぞれHMAC-RIPEMD160とHMAC-RIPEMD128のテストケースを示します。各ケースには、鍵、データ、結果が含まれます。鍵とデータの値は、16進数（接頭辞「0x」付き）か、二重引用符で囲まれたASCII文字列のいずれかです。値がASCII文字列の場合、対応するテストケースのHMAC計算には、文字列末尾のヌル文字（'\0'）は含まれません（DOES NOT include）。

The C source code of the functions used to generate HMAC-RIPEMD160 and HMAC-RIPEMD128 results is listed in the Appendix. Please Note that the functions provided are implemented in such a way as to be simple and easy to understand as a result they are not optimized in any way. The C source code for computing HMAC-MD5 can be found in [MD5].

HMAC-RIPEMD160とHMAC-RIPEMD128の結果を生成するために使用した関数のCソースコードは、付録に掲載しています。ここで提供する関数は、単純でわかりやすくなるように実装されており、その結果としてまったく最適化されていないことに注意してください。HMAC-MD5を計算するCソースコードは[MD5]にあります。

Appendix

付録

This code which implements HMAC-RIPEMD160 using an existing RIPEMD-160 library. It assumes that the RIPEMD-160 library has similar API's as those of the MD5 code described in RFC 1321. The code for HMAC-MD5, is similar, this HMAC-MD5 code is also listed in RFC 2104. To adapt this example to produce the HMAC-RIPEMD128 then replace each occurance of 'RMD160' with 'RMD128'.

このコードは、既存のRIPEMD-160ライブラリーを使用してHMAC-RIPEMD160を実装するものです。このコードは、RIPEMD-160ライブラリーが、RFC 1321で説明されているMD5のコードと同様のAPIを持つことを前提としています。HMAC-MD5のコードも同様であり、このHMAC-MD5のコードはRFC 2104にも掲載されています。この例を、HMAC-RIPEMD128を生成するように変更するには、「RMD160」をすべて「RMD128」に置き換えてください。

#ifndef RMD160_DIGESTSIZE
#define RMD160_DIGESTSIZE  20
#endif

#ifndef RMD128_DIGESTSIZE
#define RMD128_DIGESTSIZE  16
#endif


/*  HMAC_RMD160 implements HMAC-RIPEMD160 */

void HMAC_RMD160(input, len, key, keylen, digest)
unsigned char *input;                       /* pointer to data stream */
int len;                                     /* length of data stream */
unsigned char *key;                  /* pointer to authentication key */
int keylen;                           /* length of authentication key */
unsigned char *digest;                        /* resulting MAC digest */
{
    RMD160_CTX context;
    unsigned char k_ipad[65];  /* inner padding - key XORd with ipad */
    unsigned char k_opad[65];  /* outer padding - key XORd with opad */
    unsigned char tk[RMD160_DIGESTSIZE];
    int i;

    /* if key is longer than 64 bytes reset it to key=SHA1(key) */
    if (keylen > 64) {
        RMD160_CTX      tctx;

        RMD160Init(&tctx);
        RMD160Update(&tctx, key, keylen);
        RMD160Final(tk, &tctx);

        key = tk;
        keylen = RMD160_DIGESTSIZE;
    }

        /* The HMAC_SHA1 transform looks like:

           RMD160(K XOR opad, RMD160(K XOR ipad, text))

           where K is an n byte key
           ipad is the byte 0x36 repeated 64 times
           opad is the byte 0x5c repeated 64 times
           and text is the data being protected */

        /* start out by storing key in pads */
    memset(k_ipad, 0x36, sizeof(k_ipad));
    memset(k_opad, 0x5c, sizeof(k_opad));

        /* XOR key with ipad and opad values */
    for (i=0; i<keylen; i++) {
        k_ipad[i] ^= key[i];
        k_opad[i] ^= key[i];
    }

        /* perform inner RIPEMD-160 */

    RMD160Init(&context);           /* init context for 1st pass */
    RMD160Update(&context, k_ipad, 64);  /* start with inner pad */
    RMD160Update(&context, input, len); /* then text of datagram */
    RMD160Final(digest, &context);         /* finish up 1st pass */

        /* perform outer RIPEMD-160 */
    RMD160Init(&context);           /* init context for 2nd pass */
    RMD160Update(&context, k_opad, 64);  /* start with outer pad */
    /* then results of 1st hash */
    RMD160Update(&context, digest, RMD160_DIGESTSIZE);
    RMD160Final(digest, &context);         /* finish up 2nd pass */

    memset(k_ipad, 0x00, sizeof(k_ipad));
    memset(k_opad, 0x00, sizeof(k_opad));
}

#ifndef RMD160_DIGESTSIZE
#define RMD160_DIGESTSIZE  20
#endif

#ifndef RMD128_DIGESTSIZE
#define RMD128_DIGESTSIZE  16
#endif


/*  HMAC_RMD160はHMAC-RIPEMD160を実装します */

void HMAC_RMD160(input, len, key, keylen, digest)
unsigned char *input;                       /* データストリームへのポインター */
int len;                                     /* データストリームの長さ */
unsigned char *key;                  /* 認証鍵へのポインター */
int keylen;                           /* 認証鍵の長さ */
unsigned char *digest;                        /* 結果のMACダイジェスト */
{
    RMD160_CTX context;
    unsigned char k_ipad[65];  /* 内側のパディング - 鍵とipadのXOR */
    unsigned char k_opad[65];  /* 外側のパディング - 鍵とopadのXOR */
    unsigned char tk[RMD160_DIGESTSIZE];
    int i;

    /* 鍵が64バイトより長い場合は、key=SHA1(key)に置き換えます */
    if (keylen > 64) {
        RMD160_CTX      tctx;

        RMD160Init(&tctx);
        RMD160Update(&tctx, key, keylen);
        RMD160Final(tk, &tctx);

        key = tk;
        keylen = RMD160_DIGESTSIZE;
    }

        /* HMAC_SHA1の変換は次のようになります。

           RMD160(K XOR opad, RMD160(K XOR ipad, text))

           ここで、Kはnバイトの鍵、
           ipadはバイト0x36を64回繰り返したもの、
           opadはバイト0x5cを64回繰り返したもの、
           textは保護対象のデータです */

        /* まず、鍵をパッドに格納します */
    memset(k_ipad, 0x36, sizeof(k_ipad));
    memset(k_opad, 0x5c, sizeof(k_opad));

        /* 鍵とipadおよびopadの値とのXORをとります */
    for (i=0; i<keylen; i++) {
        k_ipad[i] ^= key[i];
        k_opad[i] ^= key[i];
    }

        /* 内側のRIPEMD-160を実行します */

    RMD160Init(&context);           /* 1回目のパスのためにコンテキストを初期化 */
    RMD160Update(&context, k_ipad, 64);  /* 内側のパッドから開始 */
    RMD160Update(&context, input, len); /* 次にデータグラムのテキスト */
    RMD160Final(digest, &context);         /* 1回目のパスを完了 */

        /* 外側のRIPEMD-160を実行します */
    RMD160Init(&context);           /* 2回目のパスのためにコンテキストを初期化 */
    RMD160Update(&context, k_opad, 64);  /* 外側のパッドから開始 */
    /* 次に1回目のハッシュの結果 */
    RMD160Update(&context, digest, RMD160_DIGESTSIZE);
    RMD160Final(digest, &context);         /* 2回目のパスを完了 */

    memset(k_ipad, 0x00, sizeof(k_ipad));
    memset(k_opad, 0x00, sizeof(k_opad));
}
