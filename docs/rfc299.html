RFC 299

Information Management System

RFC 299

情報管理システム

Abstract

概要

We intend to build an Information Management and Statistical System for the ILLIAC IV. It is intended to support various areas of research whose problems are ILLIAC IV suited and whose data bases are large.

私たちは、ILLIAC IV向けの情報管理・統計システム（Information Management and Statistical System）を構築するつもりです。これは、ILLIAC IVに適した問題を持ち、データベースが大規模であるような、さまざまな研究分野を支援することを目的としています。

This System will include a user language and necessary manipulatory routines for the ILLIAC IV. It will use the datacomputer for Archival storage and provide the interface to the datacomputer for queries not ILLIAC suited.

このシステムには、ILLIAC IV用のユーザー言語と必要な操作ルーチンが含まれます。アーカイブ用のストレージにはdatacomputerを使い、ILLIACに適さない問い合わせのためにdatacomputerへのインターフェイスを提供します。
