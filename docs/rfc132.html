RFC 132

Typographical Error in RFC 107

RFC 132

RFC 107の誤植

Abstract

概要

On page 5 of RFC 107, at the end of the section titled 'V. Flow Control', the partial sentence:

RFC 107の5ページ、「V. Flow Control」という題の節の末尾にある次の文の一部は、

Each of these numbers is interpreted as "the number
of 128ths of the current allocation" to be returned
if it is in the range zero to 128...

Each of these numbers is interpreted as "the number
of 128ths of the current allocation" to be returned
if it is in the range zero to 128...

should read:

次のように読み替えてください。

...if it is the range of zero to 127,...
                                 ---

...if it is the range of zero to 127,...
                                 ---

That is, return al the appropriate allocation if and only if the high-order of the left-most bit of the corresponding fraction is 1.

つまり、対応する分数の上位ビット、すなわち最も左のビットが1である場合に限り、適切な割り当て量を返却します。
