RFC 7354

Update to the Registrant Information for the Digital Video Broadcasting Project (DVB) Uniform Resource Name (URN) Namespace

RFC 7354

Digital Video Broadcasting Project（DVB）のUniform Resource Name（URN）名前空間の登録者情報の更新

Abstract

概要

RFC 5328 registered the Uniform Resource Name (URN) namespace "dvb" for the Digital Video Broadcasting Project. This document updates RFC 5328 with new registrant information.

RFC 5328は、Digital Video Broadcasting Projectのために、Uniform Resource Name（URN）名前空間「dvb」を登録しました。この文書は、新しい登録者情報でRFC 5328を更新します。

1. Introduction

1. はじめに

[RFC5328] registered the Uniform Resource Name (URN) namespace "dvb" for the Digital Video Broadcasting Project. Since the publication of that RFC, the registrant contact information has changed; this document updates the registrant information to make it current. It uses a role-based email address to reduce the need for updates in the future.

[RFC5328]は、Digital Video Broadcasting Projectのために、Uniform Resource Name（URN）名前空間「dvb」を登録しました。そのRFCの発行以降、登録者の連絡先情報が変更されたため、この文書では登録者情報を更新して最新のものにします。将来の更新の必要性を減らすために、役割ベースの電子メールアドレスを使用します。

3. Security Considerations

3. セキュリティーに関する考慮事項

There are no security considerations for this registration update.

この登録の更新には、セキュリティーに関する考慮事項はありません。

4. IANA Considerations

4. IANAに関する考慮事項

In the "Formal URN Namespaces" registry (http://www.iana.org/assignments/urn-namespaces), IANA has added a reference to this RFC, in addition to RFC 5328, for the "dvb" namespace registration. The reference field now contains two RFC numbers.

IANAは、「Formal URN Namespaces」レジストリー（http://www.iana.org/assignments/urn-namespaces）の「dvb」名前空間の登録に、RFC 5328に加えてこのRFCへの参照を追加しました。参照フィールドには、現在2つのRFC番号が含まれています。
