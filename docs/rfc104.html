RFC 104

Link 191

RFC 104

リンク191

Abstract

概要

At the Network meeting at the University of Illinois, it was agreed to reserve a link for use in measurements. The link chosen was the highest unassigned link which was incorrectly calculated to be number 223. The correct number is 191. Therefore, Link 191 will be assigned for measurement use. Use of this link should be cleared with the Liasion Officer at the Network Measurement Center (NMC).

University of Illinoisでのネットワーク会合で、計測に使うリンクを1つ予約することが合意されました。選ばれたのは未割り当てのリンクのうち最も番号の大きいもので、それは誤って223番と計算されていました。正しい番号は191です。したがって、リンク191を計測用に割り当てます。このリンクを使う場合は、Network Measurement Center（NMC）の連絡担当官（Liasion Officer）の了承を得てください。
