Network Host Status

RFC 376

ネットワークホストの状態

Abstract

概要

This RFC reports on the status of most Network Hosts from July 31 to August 4.

このRFCでは、7月31日から8月4日までの、ほとんどのネットワークホストの状態を報告します。

Several Hosts are currently excluded from the daily testing as they are presently intended to be users only. Included here are the Terminal IMPs, which are presently in the Network (AMES, MITRE, RADC, NBS, ETAC, USC, GWC, NOAA, SAAC, ARPA, and BBN*). This category also includes the Network Control Center computer (Network address 5) which is used solely for gathering statistics from the Network. Finally, included among these Hosts are the following:

現在、いくつかのホストは、ユーザーとしてのみ使うことを想定しているため、日々のテストの対象から外れています。これには、現在ネットワークに接続されている端末IMP（AMES、MITRE、RADC、NBS、ETAC、USC、GWC、NOAA、SAAC、ARPA、BBN*）が含まれます。この種類には、ネットワークから統計情報を収集するためだけに使われるネットワークコントロールセンター（Network Control Center）のコンピューター（ネットワークアドレス5）も含まれます。最後に、これらのホストには次のものも含まれます。

ここで、

D =
Dead (Destination Host either dead or inaccessible [due to network partitioning or local IMP failure] from the BBN Terminal IMP.)
F =
Full (Destination Host opened a connection, informed user that all Network ports were in use, and immediately closed the connection.)
H =
1/2 Open (Destination Host opened a connection but then either immediately closed it, or did not respond any further.)
O =
Open (Destination Host opened a connection and was accessible to users.)
R =
Refused (Destination Host returned a CLS to the initial RFC.)
T =
Timed out (Destination Host did not complete the ICP and open a connection within 60 seconds.)
D =
Dead（停止。宛先ホストが停止しているか、BBNの端末IMPから［ネットワークの分断やローカルのIMPの障害のため］アクセスできない）
F =
Full（満杯。宛先ホストはコネクションを開き、すべてのネットワークポートが使用中であることをユーザーに通知して、すぐにコネクションを閉じた）
H =
1/2 Open（半開。宛先ホストはコネクションを開いたが、その後すぐに閉じたか、それ以上応答しなかった）
O =
Open（開。宛先ホストがコネクションを開き、ユーザーがアクセスできた）
R =
Refused（拒否。宛先ホストが最初のRFC（接続要求）に対してCLSを返した）
T =
Timed out（タイムアウト。宛先ホストが60秒以内にICPを完了してコネクションを開かなかった）
