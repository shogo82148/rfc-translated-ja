RFC 145

Initial Connection Protocol Control Commands

RFC 145

初期接続プロトコルの制御コマンド

Abstract

概要

The following is my interpretation of the exchange between NCP's which would be necessary to carry out the Initial Connection Protocol of RFC #123. (This note corrects an error pointed out by Eric Harslem of RAND).

以下は、RFC #123の初期接続プロトコル（Initial Connection Protocol）を実行するために必要となるNCP間のやり取りについての、私の解釈です。（このノートは、RANDのEric Harslemが指摘した誤りを訂正するものです。）

      Server NCP                      User NCP
      __________                      ________

      Listen for Connection L         RTS, U, L, l
                                                  A

      STR, L, U, 32                   ALL, l  , 1, 32
                                            A

      Send 32 bits of data
      in 1 message on link l
                            A

      (value is S)                    Receive 32 bits of data
                                      from link l  (value is S)
                                                 A

      CLS, L, U                       CLS, U, L

      STR, S+1, U+1, B                STR, U+1, S, B
                      s                             u

      RTS, S, U+1, l                  RTS, U, S+1, l
                    B                               C

      wait for connection             wait for connection
      ALL, l , m , b                  ALL, l , m , b
            B   B   B                       C   C   C

      data sent to link l             data sent on link l
                         C                               B

      data received on link           data received on link l
                           B                                 C

      Server NCP                      User NCP
      __________                      ________

      Listen for Connection L         RTS, U, L, l
                                                  A

      STR, L, U, 32                   ALL, l  , 1, 32
                                            A

      Send 32 bits of data
      in 1 message on link l
                            A

      (value is S)                    Receive 32 bits of data
                                      from link l  (value is S)
                                                 A

      CLS, L, U                       CLS, U, L

      STR, S+1, U+1, B                STR, U+1, S, B
                      s                             u

      RTS, S, U+1, l                  RTS, U, S+1, l
                    B                               C

      wait for connection             wait for connection
      ALL, l , m , b                  ALL, l , m , b
            B   B   B                       C   C   C

      data sent to link l             data sent on link l
                         C                               B

      data received on link           data received on link l
                           B                                 C

lA, lB, and lC, are links, mB and mC are messages allocations, bB and bC are bit allocations, and all other symbols are defined in RFC #123.

lA、lB、lCはリンク、mBとmCはメッセージ割り当て、bBとbCはビット割り当てで、その他の記号はすべてRFC #123での定義どおりです。
