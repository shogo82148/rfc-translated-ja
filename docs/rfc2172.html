RFC 2172

MAPOS Version 1 Assigned Numbers

RFC 2172

MAPOSバージョン1の割り当て番号

Abstract

概要

This document describes the protocol parameters used in the Multiple Access Over SONET/SDH (MAPOS) version 1. MAPOS is a link layer protocol and provides multiple access capability over SONET/SDH links.

この文書は、Multiple Access Over SONET/SDH（MAPOS）バージョン1で使用するプロトコルパラメーターについて記述します。MAPOSはリンク層プロトコルであり、SONET/SDHリンク上で多重アクセス機能を提供します。

1. Introduction

1. はじめに

Multiple Access Protocol over SONET/SDH (MAPOS) [1] is a high-speed link-layer protocol that provides multiple access capability over SONET(Synchronous Optical Network)/SDH(Synchronous Digital Hierarchy)[2][3][4][5]. Its frame format is based on the HDLC-like framing [6] for PPP. A component called "Frame Switch" [1] allows multiple nodes to be connected together in a star topology to form a LAN. Using long haul SONET/SDH links, the nodes on such a "SONET-LAN" can span over a wide geographical area. The Internet Protocol (IP) [7] datagrams are transmitted in MAPOS HDLC frames [8].

Multiple Access Protocol over SONET/SDH（MAPOS）[1]は、SONET（Synchronous Optical Network）/SDH（Synchronous Digital Hierarchy）[2][3][4][5]上で多重アクセス機能を提供する高速なリンク層プロトコルです。そのフレーム形式は、PPPのためのHDLC風フレーミング[6]に基づいています。「フレームスイッチ（Frame Switch）」[1]と呼ばれる構成要素によって、複数のノードをスター型トポロジーで相互に接続してLANを形成できます。長距離のSONET/SDHリンクを使うことで、このような「SONET-LAN」上のノードは地理的に広い範囲に広がることができます。インターネットプロトコル（IP）[7]のデータグラムは、MAPOSのHDLCフレームで送信されます[8]。

This document describes the protocol parameters used in MAPOS version 1 [1].

この文書は、MAPOSバージョン1[1]で使用するプロトコルパラメーターについて記述します。

2. Protocol Field Assignments

2. Protocolフィールドの割り当て

The MAPOS Version 1 Data Link Layer [1] contains a 16 bit Protocol field to identify the the encapsulated protocol. The Protocol field is consistent with the ISO 3309 (HDLC) extension mechanism for address fields. All protocol numbers MUST be assigned such that the least significant bit of the most significant octet equals "0", and the least significant bit of the least significant octet equals "1".

MAPOSバージョン1のデータリンク層[1]には、カプセル化されたプロトコルを識別するための16ビットのProtocolフィールドがあります。Protocolフィールドは、アドレスフィールドに関するISO 3309（HDLC）の拡張メカニズムと整合しています。すべてのプロトコル番号は、最上位オクテットの最下位ビットが「0」に等しく、最下位オクテットの最下位ビットが「1」に等しくなるように割り当てなければなりません（MUST）。
