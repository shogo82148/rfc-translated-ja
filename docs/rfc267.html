RFC 267

Network Host Status

RFC 267

ネットワークホストの状況

Abstract

概要

This RFC reports on the status of most Network Hosts from November 8 to November 19. On November 18, however, the BBN prototype Terminal IMP (Network Address 158) was inaccessible due to hardware debugging.

このRFCは、11月8日から11月19日までのほとんどのネットワークホストの状況を報告します。ただし、11月18日には、BBNの試作Terminal IMP（ネットワークアドレス158）がハードウェアのデバッグのためにアクセスできませんでした。

Several Hosts are currently excluded fron the daily testing. These Hosts fall into two categories:

現在、いくつかのホストは毎日の試験の対象から外されています。これらのホストは2つのカテゴリーに分けられます。

1) Hosts which are not expected to be functioning on the Network as servers (available for use from other sites) for at least two weeks. Included here are:

1) 少なくとも2週間は、ネットワーク上でサーバー（他のサイトから利用可能なもの）として機能する見込みのないホスト。ここに含まれるのは次のとおりです。

where

ここで、各記号の意味は次のとおりです。

D =
Dead (Destination Host either dead or inaccessible [due to network partitioning or local IMP failure] from the BBN Terminal IMP.)
R =
Refused (Destination Host returned a CLS to the initial RFC.)
T =
Timed out (Destination Host did not respond in any way to the initial RFC, although not dead.)
H =
1/2 Open (Destination Host opened a connection but then either immediately closed it, or did not respond further.)
O =
Open (Destination Host opened a connection and was accessible to users.)
D =
Dead（宛先ホストがダウンしているか、［ネットワークの分断またはローカルIMPの障害のために］BBN Terminal IMPからアクセスできません。）
R =
Refused（宛先ホストが最初のRFCに対してCLSを返しました。）
T =
Timed out（宛先ホストはダウンしていないものの、最初のRFCに対してまったく応答しませんでした。）
H =
1/2 Open（宛先ホストはコネクションを開きましたが、その後すぐにそれを閉じたか、それ以上応答しませんでした。）
O =
Open（宛先ホストはコネクションを開き、ユーザーがアクセスできました。）

* The UCLA IBM-360/91 currently has Remote Job Service (NETRJS), but has not implemented a full server Telnet System. The BBN Terminal IMP is not equipped to test NETRJS; however, we are assuming that receipt of the UCLA explanatory message indicates that NETRJS is also functioning.

* UCLAのIBM-360/91は現在リモートジョブサービス（Remote Job Service、NETRJS）を提供していますが、完全なサーバーTelnetシステムは実装していません。BBN Terminal IMPにはNETRJSを試験する設備がありませんが、UCLAの説明メッセージを受信できればNETRJSも機能しているものとみなしています。
