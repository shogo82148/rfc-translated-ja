RFC 496

A TNLS QUICK REFERENCE CARD IS AVAILABLE

RFC 496

TNLSクイックリファレンスカードを提供します

Abstract

概要

This RFC announces a new TNLS Quick Reference Card. It documents all of the basic commands required for everyday TNLS usage as well as some special purpose features. It includes TIP settings for connecting to SRI-ARC, basic TENEX/EXECUTIVE commands, and a complete of set of VIEWSPECS codes for TNLS usage.

このRFCでは、新しいTNLSクイックリファレンスカード（TNLS Quick Reference Card）をお知らせします。このカードには、日常的にTNLSを使うのに必要な基本コマンドがすべて記載されており、いくつかの特殊用途の機能も載っています。また、SRI-ARCに接続するためのTIPの設定、TENEX/EXECUTIVEの基本コマンド、TNLSで使うVIEWSPECSコードの完全な一覧も含まれています。

One copy of this card will be sent to your station agent. If you would like to obtain copies for users at your site, please contact Marcia Keeney (MLK) at SRI-ARC indicating the number of copies you require.

このカードは、各サイトのステーションエージェント（station agent）に1部ずつ送ります。サイトのユーザー向けに追加の部数が必要な場合は、必要な部数を添えて、SRI-ARCのMarcia Keeney（MLK）までご連絡ください。
