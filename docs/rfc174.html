RFC 174

UCLA-Computer Science Graphics Overview

RFC 174

UCLAコンピューターサイエンス学科のグラフィックスの概要

I. Hardware

I. ハードウェア

  1. Imlac PDS-1

    We have 2 PDS-1 graphics consoles each with 8K 16 bit words of memory.

    The display screens are mounted with the long axis vertical.

  2. DEC 340

    We have a DEC 340 Display Station with a light pen. Associated with the station are a Rand Tablet and a Lincoln Wand. There is a display processor which drives the DEC 340 which reads its instruction from the XDS Sigma 7 memory via dedicated memory port.

  1. Imlac PDS-1

    当方には、それぞれ16ビットワードで8Kのメモリーを備えたPDS-1グラフィックスコンソールが2台あります。

    ディスプレイ画面は、長辺を縦にして設置されています。

  2. DEC 340

    当方には、ライトペン付きのDEC 340ディスプレイステーションがあります。このステーションには、RandタブレットとLincoln Wandが付属しています。DEC 340を駆動するディスプレイプロセッサーがあり、専用のメモリーポートを介してXDS Sigma 7のメモリーから命令を読み込みます。

II. Software

II. ソフトウェア

  1. Imlacs

    We have not as yet developed any software for the PDS-1. We have used the Imlac provided text and graphics support software to utilize the PDS-1's as alphameric and limited graphics consoles (at 1200 baud).

    These are used only with the SEX timesharing system.

  2. DEC 340

    We have over several years developed a package of Library routines* which interface to FORTRAN programs for use with the DEC 340 and its associated devices. This station is used only with a stand alone system (RAD 75).

    Several programs have been implemented using these facilities among them are:

    1. MOSAIC

      MOSAIC is an experimental computer graphics program which permits a user to manipulate the parameters of a fairly complex polar co-ordinate equation. The object is to explore the space of interesting images which can be produced. Library facilities are provided so that the user can save interesting images. He can also combine the images in many ways to form mosaic-like patterns. An Arriflex 16mm camera can be driven through the use of this program, and we have used the system to generate several films which served as a basis for video-graphics experiments (TV videotape).

    2. FISHEYE

      Using the interactive part of MOSAIC, and a peculiar, exponential mapping function, studies were made in the presentation of CRT images too large to fit in normal form on our 10" scope. The images are mapped in such a way that part of the image is shown at linear scale, the remainder being squeezed up at the outer edges of the screen. Thus, the global image is always visible, but details are apparent mainly in the linear region. This study formed the basis of an M.S. thesis.

    3. MOVIE

      This is a movie script language which allows the user to compose a scenario describing the entrance and exit of images on the CRT. Mosaics can be created. Images can fade-in, fade-out, dissolve, expand, zoom, contract, Dramatis personae (in the form of MOSAIC images) can be defined and their movements described. The program computes the movements of all images for the duration of the film and then calls on the MOSAIC generating routines to make the film. Camera control is automatic.

  1. Imlac

    PDS-1向けのソフトウェアは、まだ何も開発していません。Imlacが提供するテキストおよびグラフィックスのサポートソフトウェアを使って、PDS-1を英数字表示と限定的なグラフィックスのコンソール（1200ボー）として利用しています。

    これらはSEXタイムシェアリングシステムでのみ使用しています。

  2. DEC 340

    当方では数年にわたり、DEC 340とその付属デバイスで使用するための、FORTRANプログラムとのインターフェイスとなるライブラリールーチン*のパッケージを開発してきました。このステーションは、スタンドアロンシステム（RAD 75）でのみ使用しています。

    これらの機能を使っていくつかのプログラムが実装されており、その中には次のものがあります。

    1. MOSAIC

      MOSAICは実験的なコンピューターグラフィックスプログラムで、ユーザーはかなり複雑な極座標方程式のパラメーターを操作できます。その目的は、生成できる興味深い画像の空間を探ることです。ユーザーが興味深い画像を保存できるように、ライブラリー機能が用意されています。また、ユーザーは画像をさまざまな方法で組み合わせて、モザイクのようなパターンを作ることもできます。このプログラムを使ってArriflexの16mmカメラを駆動でき、当方ではこのシステムを使って何本かのフィルムを作成し、それをビデオグラフィックス実験（テレビのビデオテープ）の基礎として使いました。

    2. FISHEYE

      MOSAICの対話的な部分と、独特な指数関数的写像関数を使って、当方の10インチのスコープには通常の形では収まらないほど大きなCRT画像の表示方法を研究しました。画像は、その一部が線形の縮尺で表示され、残りが画面の外縁部に押し縮められるように写像されます。そのため、画像全体が常に見えていながら、細部は主に線形の領域で見て取れます。この研究は修士論文の基礎になりました。

    3. MOVIE

      これは映画の台本言語で、ユーザーはCRT上の画像の登場と退場を記述するシナリオを作成できます。モザイクを作ることができます。画像は、フェードイン、フェードアウト、ディゾルブ、拡大、ズーム、縮小ができ、（MOSAICの画像の形をとる）登場人物を定義してその動きを記述できます。プログラムは、フィルムの全期間にわたってすべての画像の動きを計算し、MOSAICの生成ルーチンを呼び出してフィルムを作成します。カメラの制御は自動です。

*SMOG (sub-program manager for On-Line Graphics).

*SMOG（sub-program manager for On-Line Graphics、オンライングラフィックス用サブプログラムマネージャー）

III. Intentions

III. 今後の予定

  1. Imlacs

    We intend to equip our PDS-1's with the mouse and keyset configuration used at SRI-ARC. We intend to attempt to make use of PDS-1 programs developed at other sites. We intend to develop an assembler for PDS-1 programs. We are thinking about a subroutine Library for PDS-1 graphics for FORTRAN (or other higher level languages).

  2. DEC 340

    We intend eventually to bring the DEC 340 hardware and software facilities into the SEX system.

  1. Imlac

    当方のPDS-1に、SRI-ARCで使われているマウスとキーセットの構成を装備するつもりです。他のサイトで開発されたPDS-1のプログラムの活用も試みるつもりです。PDS-1のプログラム用のアセンブラーを開発するつもりです。FORTRAN（またはその他の高水準言語）向けのPDS-1グラフィックス用サブルーチンライブラリーについても検討しています。

  2. DEC 340

    いずれは、DEC 340のハードウェアとソフトウェアの機能をSEXシステムに取り込むつもりです。
