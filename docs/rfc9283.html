RFC 9283

IAB Charter Update for RFC Editor Model

RFC 9283

RFCエディターモデルに合わせたIAB憲章の更新

Abstract

概要

This document updates the IAB Charter (RFC 2850) to be consistent with version 3 of the RFC Editor Model (RFC 9280).

この文書は、IAB憲章（RFC 2850）を、RFCエディターモデルのバージョン3（RFC 9280）と整合するように更新します。

1. Introduction

1. はじめに

In version 3 of the RFC Editor Model defined by [RFC9280], the RFC Series is governed by its own mechanisms. This requires a modification to the Internet Architecture Board Charter [RFC2850].

[RFC9280]で定義されたRFCエディターモデルのバージョン3では、RFCシリーズは独自の仕組みによって統治されます。このため、インターネットアーキテクチャボード憲章（Internet Architecture Board Charter）[RFC2850]を修正する必要があります。

Also, RFC 2850 states that the RFC Editor appoints a liaison member to the IAB. This is no longer necessary.

また、RFC 2850には、RFCエディターがIABに連絡担当メンバーを任命すると記載されています。これはもはや必要ありません。

2. Changed Text

2. 変更されるテキスト

In Section RFC2850 of [RFC2850], the phrase "the RFC Editor," is deleted.

[RFC2850]のセクションRFC2850から、"the RFC Editor,"という語句を削除します。

In Section RFC2850 of [RFC2850], under the heading "(d) RFC Series and IANA", the following sentence:

[RFC2850]のセクションRFC2850の見出し"(d) RFC Series and IANA"の下にある次の文を:

The IAB must approve the appointment of an organization to act as RFC Editor and the general policy followed by the RFC Editor.

IABは、RFCエディターとして活動する組織の任命と、RFCエディターが従う一般方針を承認しなければなりません。

is replaced by:

次の文に置き換えます:

The RFC Editor function is defined under the authority of the IAB by [RFC9280].

RFCエディター機能は、IABの権限の下で[RFC9280]により定義されます。
