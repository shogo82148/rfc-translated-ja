RFC 8602

Update to the Telephony Routing over IP (TRIP) IANA Registry Rules regarding Postal Addresses

RFC 8602

郵便住所に関するIP上の電話ルーティング（TRIP）のIANAレジストリー規則の更新

Abstract

概要

This memo updates the IANA registry rules for the Telephony Routing over IP (TRIP) protocol, by no longer requiring that postal addresses be included in contact information.

このメモは、連絡先情報に郵便住所を含めることを要求しないようにすることで、IP上の電話ルーティング（Telephony Routing over IP、TRIP）プロトコルのIANAレジストリー規則を更新します。

This memo updates RFC 3219.

このメモはRFC 3219を更新します。

1. Introduction

1. はじめに

This memo updates the IANA registry rules for the Telephony Routing over IP (TRIP) protocol, by no longer requiring that postal addresses be included in contact information. No use for the addresses is identified, and omitting this information provides a privacy benefit.

このメモは、連絡先情報に郵便住所を含めることを要求しないようにすることで、IP上の電話ルーティング（Telephony Routing over IP、TRIP）プロトコルのIANAレジストリー規則を更新します。郵便住所の用途は特に見当たらず、この情報を省略することでプライバシー上の利点が得られます。

This memo updates RFC 3219.

このメモはRFC 3219を更新します。

2. IANA Considerations

2. IANAに関する考慮事項

This memo updates the registration rules [RFC8126] for TRIP Attributes ([RFC3219], Section 13.2) and TRIP IP Telephony Administrative Domain (ITAD) Numbers ([RFC3219], Section 13.5) as follows.

このメモは、TRIP属性（[RFC3219], Section 13.2）およびTRIP IP電話管理ドメイン（IP Telephony Administrative Domain、ITAD）番号（[RFC3219], Section 13.5）の登録規則[RFC8126]を次のように更新します。

The IETF no longer requires IANA to collect postal address information when adding TRIP registry entries. Additionally, IANA has removed previously collected postal addresses from the registries.

IETFは、TRIPレジストリーにエントリーを追加する際に郵便住所の情報を収集することを、もはやIANAに要求しません。さらに、IANAは以前に収集した郵便住所をレジストリーから削除しました。

3. Security Considerations

3. セキュリティーに関する考慮事項

No security impacts of this change have been identified.

この変更によるセキュリティーへの影響は確認されていません。
