RFC 345

INTEREST IN MIXED INTEGER PROGRAMMING (MPSX ON 360/91 AT CCN)

RFC 345

混合整数計画法への関心（CCNの360/91上のMPSX）

Abstract

概要

MPSX is a newer version of the IBM project MPS, used for integer programming. From what I've been told, MPSX outperforms the previous package. In addition, it has available a feature of mixed integer programming.

MPSXは、整数計画法に使われるIBMのプロジェクトMPSの新しいバージョンです。聞いたところによると、MPSXは以前のパッケージよりも性能が優れています。さらに、混合整数計画法の機能も利用できます。

Since MPSX is an IBM product, an installation which uses it is charged a fixed rental fee per month. At the present time, CCN does not have this processor with its system. We are anticipating asking them to install it, with the mixed integer programming option. We are looking for any other users from the Network who may need this software in order to prorate the cost between several installations. The initial estimate of the cost is $130/month, plus $225 for the mixed integer programming feature. A share of this cost would be assigned to each user of the system. I am told by Robert Bell of CCN that they could take care of those details for us.

MPSXはIBMの製品なので、これを使う施設には月ごとに固定のレンタル料金がかかります。現時点では、CCNのシステムにはこのプロセッサーがありません。当方は、混合整数計画法のオプションとあわせてこれを導入するようCCNに依頼するつもりです。費用を複数の施設で按分するために、このソフトウェアを必要とするかもしれないネットワークのほかのユーザーを探しています。費用の当初の見積もりは月額130ドルで、混合整数計画法の機能にはさらに225ドルかかります。この費用は、システムの各ユーザーに分担してもらうことになります。CCNのRobert Bellによれば、そうした細かい手続きはCCN側で引き受けてくれるそうです。

If you have an interest in this, I urge you to contact me within the month. If you have questions about the mixed integer programming feature of the MPSX system itself, you could contact:

関心のある方は、今月中に私までご連絡ください。MPSXシステム自体の混合整数計画法の機能について質問がある場合は、次の連絡先に問い合わせてください。
