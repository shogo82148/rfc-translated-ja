Internet Protocol Handbook: Table of Contents

RFC 774

Internet Protocol Handbook：目次

Abstract

概要

The internet family of protocols is replacing the old ARPANET protocols. To this end an Internet Protocol Handbook will be prepared by the Network Information Center. This Handbook is tentatively planned to be available at the end of 1980. This Internet Protocol Handbook will closely parallel the old ARPANET Protocol Handbook, and will primarily be a collection of existing RFCs and IENs.

インターネットのプロトコル群が、古いARPANETのプロトコルに置き換わりつつあります。そのため、Network Information CenterがInternet Protocol Handbookを作成します。このハンドブックは、1980年末に利用できるようになる予定です（暫定）。このInternet Protocol Handbookは、古いARPANET Protocol Handbookとよく似た構成になり、主に既存のRFCとIENを集めたものになります。

Attached is the current draft table of contents for the Internet Protocol Handbook. Any suggestions for additions should be sent to Jon Postel (Postel@ISIF).

Internet Protocol Handbookの現時点での目次の草案を添付します。追加の提案があれば、Jon Postel（Postel@ISIF）に送ってください。

RFCs and IENs are public access document files and may be copied from the Network Information Center online Library at SRI-KL via FTP using the FTP user name ANONYMOUS and password GUEST. The IENs have pathnames of the form "<NETINFO>IEN-nnn.TXT", and the RFCs have pathnames of the form "<NETINFO>RFCnnn.TXT", where "nnn" is replaced by the document number. [Note the inconsistency: IENs have a hyphen in the pathname, RFCs don't.]

RFCとIENは一般に公開されている文書ファイルで、FTPのユーザー名ANONYMOUSとパスワードGUESTを使い、FTPでSRI-KLにあるNetwork Information Centerのオンラインライブラリーからコピーできます。IENのパス名は「<NETINFO>IEN-nnn.TXT」という形式で、RFCのパス名は「<NETINFO>RFCnnn.TXT」という形式です。ここで、「nnn」は文書番号に置き換えます。[一貫性がないことに注意してください。IENのパス名にはハイフンがありますが、RFCにはありません。]
