RFC 544

Locating On-Line Documentation at SRI-ARC

RFC 544

SRI-ARCのオンライン文書の探し方

Abstract

概要

Where there used to be one, there are now two files to help users locate user documentation and other files available in NLS:

以前は1つだけでしたが、現在は、NLSで利用できるユーザー向け文書やその他のファイルをユーザーが見つけるのに役立つファイルが2つあります。

<NIC>LOCATOR will lead the user to NIC functional documents by means of links. Its branch labeled "ARC SYSTEM DOCUMENTATION" will direct the user to <USERGUIDES>ARCLOCATOR.

<NIC>LOCATORは、リンクによってユーザーをNICの機能文書へ導きます。その「ARC SYSTEM DOCUMENTATION」というラベルの付いたブランチは、ユーザーを<USERGUIDES>ARCLOCATORへ案内します。

        (nic, locator, l:w)

        (nic, locator, l:w)

<USERGUIDES>ARCLOCATOR includes documentation of the SRI-ARC system. Many ARC features are available for Network use, and the documents in <USERGUIDES>ARCLOCATOR should serve to introduce users to these capabilities.

<USERGUIDES>ARCLOCATORには、SRI-ARCシステムの文書が含まれています。ARCの機能の多くはネットワーク経由で利用でき、<USERGUIDES>ARCLOCATOR内の文書は、ユーザーにこれらの機能を紹介する役割を果たすはずです。

        (userguides, arclocator, l:w)

        (userguides, arclocator, l:w)

These files are formatted in a way that allows the documents to be easily accessed by inexperienced NLS users. Both files contain instructions for their use as branch one. To see these instructions:

これらのファイルは、NLSに不慣れなユーザーでも文書に簡単にアクセスできるような形式になっています。どちらのファイルにも、ブランチ1として使い方の説明が含まれています。この説明を見るには、次のようにします。

    L[oad] F[ile] <nic>locator CR

    P[rint] B[ranch] .1 CA wn  CA

    L[oad] F[ile] <nic>locator CR

    P[rint] B[ranch] .1 CA wn  CA

Please send ideas and suggestions for the LOCATOR files to KIRK or NDM at SRI-ARC.

LOCATORファイルについてのアイデアや提案は、SRI-ARCのKIRKまたはNDMまでお送りください。
