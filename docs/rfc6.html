RFC 6

Conversation with Bob Kahn

RFC 6

Bob Kahnとの会話

Abstract

概要

I talked with Bob Kahn at BB&N yesterday. We talked about code conversion in the IMP's, IMP-HOST communication, and HOST software.

昨日、BB&NでBob Kahnと話しました。IMPでのコード変換、IMP-HOST間の通信、HOSTのソフトウェアについて話し合いました。

BB&N is prepared to convert 6, 7, 8, or 9 bit character codes into 8-bit ASCII for transmission and convert again upon assembly at the destination IMP. BB&N plans a one for one conversion scheme with tables unique to the HOST. I suggested that places with 6-bit codes may also want case shifting. Bob said this may result in overflow if too many case shifts are necessary. I suggested that this is rare and we could probably live with an overflow indication instead of a guarantee.

BB&Nは、6、7、8、9ビットの文字コードを送信用に8ビットASCIIに変換し、宛先IMPで組み立てる際に再び変換する用意があります。BB&Nは、HOSTごとに固有の表を使う1対1の変換方式を計画しています。私は、6ビットコードを使うサイトではケースシフト（大文字と小文字の切り替え）も必要になるかもしれないと提案しました。Bobは、ケースシフトが多く必要になりすぎるとオーバーフローが起こるかもしれないと言いました。私は、それはまれなことであり、保証の代わりにオーバーフローの表示があればおそらく十分だろうと提案しました。

With respect to HOST-IMP communication, we now have a five bit link field and a bit to indicate conversion. Also possible is a 2-bit conversion indicator, one for converting before sending and one for converting after. This would allow another handle for checking or controlling the system.

HOST-IMP間の通信については、現在、5ビットのリンクフィールドと、変換を指示する1ビットがあります。2ビットの変換指示子にすることも考えられ、その場合は送信前の変換用と送信後の変換用に1ビットずつ使います。これにより、システムを検査または制御するための手段がもう1つ増えます。

The HOST can send messages or portions of a message to its IMP specifying

HOSTは、メッセージまたはメッセージの一部をIMPに送り、次のことを指定できます。

  1. Tracing
  2. Conversion
  3. Whether message is for destination IMP or HOST
  4. Send RFNM
  5. HOST up or down
  6. Synchronization
  7. Format Error Messages
  8. Master Link Clear
  9. Status Requested
  1. トレース
  2. 変換
  3. メッセージが宛先IMP向けか宛先HOST向けか
  4. RFNMの送信
  5. HOSTの稼働または停止
  6. 同期
  7. フォーマットエラーメッセージ
  8. マスターリンクのクリア
  9. ステータスの要求

The IMP can send to its HOST information on

IMPは、HOSTに次の情報を送ることができます。

  1. Conversion
  2. REFNM Arrived
  3. IMP up or down
  4. Synchornization
  5. Called HOST not Responding
  6. Format Error
  7. Status in IMP
  1. 変換
  2. REFNMの到着
  3. IMPの稼働または停止
  4. 同期
  5. 呼び出されたHOSTが応答しないこと
  6. フォーマットエラー
  7. IMP内のステータス

I also summarized for Bob the contents of Network Notes l, 2, and 3.

また、Bobに、Network Notes l、2、3の内容を要約して伝えました。
