RFC 485

MIX and MIXAL at UCSB

RFC 485

UCSBにおけるMIXとMIXAL

Abstract

概要

The following, in response to David Walden's MIX query (RFC#473) was written by a graduate student at UCSB. Questions regarding "cheap" usage should be directed to Roland F. Bryan (RFB) at UCSB.

以下は、David WaldenのMIXに関する問い合わせ（RFC#473）への回答として、UCSBの大学院生が書いたものです。「安価な」利用に関する質問は、UCSBのRoland F. Bryan（RFB）宛てにお送りください。

Mark Scott Johnson
18 March 1973

Mark Scott Johnson
1973年3月18日

I wrote a MIXAL assembler and a MIX simulator last summer. The assembler is written in SNOBOL4 and, unfortunately, is fairly expensive to run. The assembler has been fairly well debugged and is documented. However, although the MIX simulator is written (in 360 Assembler), it has only been partially debugged. Due to the resumption of school and other commitments, I was unable to give the simulator a thorough debugging. All the simulated instructions except I/O instructions have been tested somewhat and appear to be operating well. Also, card reader input and printer output are operational, but my simulation of disk files and magnetic tape has not been completed. There is presently no documentation for the simulator. Very little documentation is needed, however, since the simulator follows almost to the letter the specifications detailed in _Fundamental_Algorithms_.

私は昨年の夏に、MIXALアセンブラーとMIXシミュレーターを書きました。アセンブラーはSNOBOL4で書かれており、残念ながら実行コストがかなり高くなります。アセンブラーは十分にデバッグされており、ドキュメントもあります。一方、MIXシミュレーターは（360アセンブラーで）書き上げてはいますが、部分的にしかデバッグされていません。学期の再開やその他の用事のため、シミュレーターを徹底的にデバッグすることができませんでした。I/O命令を除くすべてのシミュレートされた命令はある程度テストされており、正しく動作しているようです。また、カードリーダーからの入力とプリンターへの出力は動作しますが、ディスクファイルと磁気テープのシミュレーションはまだ完成していません。現在、シミュレーターのドキュメントはありません。しかし、シミュレーターは『Fundamental Algorithms』に詳述されている仕様にほぼ文字どおり従っているので、ドキュメントはほとんど必要ありません。

If anyone is interested in using the assembler and/or the simulator, I will be happy to supply what documentation exists plus some information on how the programs can be accessed. Also, if anyone is interested in the source code for the programs, I will be happy to send it. I hope to be able to finish the simulator this next quarter. If anyone wants to use the system and if they should find any bugs, I will do my best to maintain and correct the programs.

アセンブラーやシミュレーターの利用に関心のある方がいれば、既存のドキュメントと、プログラムへのアクセス方法に関する情報をお渡しします。また、プログラムのソースコードに関心のある方がいれば、喜んでお送りします。次の学期中にはシミュレーターを完成させたいと考えています。このシステムを使いたい方がバグを見つけた場合は、できる限りプログラムの保守と修正に努めます。
