RFC 456

Meeting Announcement to Discuss a Network Mail System (Revised)

RFC 456

ネットワークメールシステムについて議論する会議の案内（改訂版）

Abstract

概要

This RFC announces a slight change in the meeting time for the Network Mail meeting discussed in RFC #453.

このRFCは、RFC #453で取り上げたネットワークメール（Network Mail）の会議について、開催時刻の小さな変更をお知らせします。

The new meeting time is:

新しい開催日時は次のとおりです。

FRIDAY, FEBRUARY 23, 1973
8:30 AM
SRI-ARC Conference Room

1973年2月23日（金）
午前8時30分
SRI-ARC会議室

If a second day is needed, we will meet on Saturday, February 24th.

2日目が必要な場合は、2月24日（土）にも集まります。

M.D. Kudlick

M.D. Kudlick
