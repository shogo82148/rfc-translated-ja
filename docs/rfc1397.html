RFC 1397

Default Route Advertisement In BGP2 And BGP3 Versions Of The Border Gateway Protocol

RFC 1397

ボーダーゲートウェイプロトコルのBGP2およびBGP3バージョンにおけるデフォルトルートの広告

Abstract

概要

This document specifies the recommendation of the BGP Working Group on default route advertisement support in BGP2 [1] and BGP3 [2] versions of the Border Gateway Protocol.

この文書では、ボーダーゲートウェイプロトコル（Border Gateway Protocol）のBGP2[1]およびBGP3[2]バージョンにおけるデフォルトルートの広告のサポートについて、BGPワーキンググループの推奨事項を規定します。

This recommendation only applies to BGP2 and BGP3 versions of the Border Gateway Protocol since starting with the BGP4 [3] version a default route advertisement capability is built in the protocol.

この推奨事項は、ボーダーゲートウェイプロトコルのBGP2およびBGP3バージョンにのみ適用されます。BGP4[3]バージョン以降では、デフォルトルートを広告する機能がプロトコルに組み込まれているからです。

1. Overview

1. 概要

The purpose of the default route advertisement capability is to advertise the IP address of a border gateway which can be used as the default next hop to destinations that are not listed explicitly in the BGP peer's routing table.

デフォルトルート広告機能の目的は、BGPピアのルーティングテーブルに明示的に載っていない宛先へのデフォルトのネクストホップとして使えるボーダーゲートウェイのIPアドレスを広告することです。

This capability will allow routers, that are unable to maintain a complete routing table (e.g., due to its size) to learn a border gateway that is ready to handle the default traffic. Also, in contrast to static defaults, if there is more than one default gateway, this would make it possible for a BGP speaker to express a preference for one over the other. It also reduces the need to configure default routes in routers.

この機能により、（たとえばサイズのために）完全なルーティングテーブルを維持できないルーターが、デフォルトのトラフィックを処理する準備ができているボーダーゲートウェイを知ることができます。また、静的なデフォルトとは対照的に、デフォルトゲートウェイが複数ある場合に、BGPスピーカーがどちらを優先するかを表明できるようになります。さらに、ルーターにデフォルトルートを設定する必要性も減ります。

2. Default Route Advertisement

2. デフォルトルートの広告

A default route is advertised in an UPDATE message that carries reachability information for network 0.0.0.0. A Network field of such an UPDATE message must contain the IP address 0.0.0.0 as the indication that it carries a default route. The NEXT_HOP path attribute of such a message provides the IP address of a border gateway that can be used as a default next hop to destinations that are not listed in the BGP peer's routing table. The value of the ORIGIN attribute should be 2 (INCOMPLETE). The AS_PATH attribute should be constructed according to the same rules that apply to a conventional network advertisement.

デフォルトルートは、ネットワーク0.0.0.0の到達可能性情報を運ぶUPDATEメッセージで広告されます。そのようなUPDATEメッセージのNetworkフィールドには、デフォルトルートを運んでいることを示すものとして、IPアドレス0.0.0.0が入っていなければなりません。そのようなメッセージのNEXT_HOPパス属性は、BGPピアのルーティングテーブルに載っていない宛先へのデフォルトのネクストホップとして使えるボーダーゲートウェイのIPアドレスを提供します。ORIGIN属性の値は2（INCOMPLETE）であるべきです。AS_PATH属性は、通常のネットワークの広告に適用されるのと同じ規則に従って構成するべきです。

If multiple default routes are advertised by a BGP speaker, the INTER-AS-METRIC path attribute can be included in the corresponding UPDATE messages to express preference levels for entry points to the same AS.

BGPスピーカーが複数のデフォルトルートを広告する場合、同じASへの入口の優先度を表すために、対応するUPDATEメッセージにINTER-AS-METRICパス属性を含めることができます。

The UNREACHABLE path attribute is used to indicate that a previously advertised default route has become unreachable.

UNREACHABLEパス属性は、以前に広告したデフォルトルートが到達不能になったことを示すために使います。

UPDATE messages containing the default route advertisements should be handled according to the rules that apply to all other UPDATE messages. If multiple default route are acquired by a BGP speaker, a route is selected according to the local policies adopted by this BGP speaker.

デフォルトルートの広告を含むUPDATEメッセージは、ほかのすべてのUPDATEメッセージに適用される規則に従って処理するべきです。BGPスピーカーが複数のデフォルトルートを得た場合は、このBGPスピーカーが採用しているローカルポリシーに従ってルートを選択します。
