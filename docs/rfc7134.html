RFC 7134

The Management Policy of the Resource Priority Header (RPH) Registry Changed to "IETF Review"

RFC 7134

リソース優先度ヘッダー（RPH）レジストリーの管理ポリシーの「IETF Review」への変更

Abstract

概要

RFC 4412 defines the "Resource-Priority Namespaces" and "Resource-Priority Priority-values" registries. The management policy of these registries is "Standards Action". This document normatively updates RFC 4412 to change the management policy of these registries to "IETF Review".

RFC 4412は、「Resource-Priority Namespaces」レジストリーと「Resource-Priority Priority-values」レジストリーを定義しています。これらのレジストリーの管理ポリシーは「Standards Action」です。この文書は、これらのレジストリーの管理ポリシーを「IETF Review」に変更するため、RFC 4412を規範的に更新します。

1. Introduction

1. はじめに

[RFC4412] defines the "Resource-Priority Namespaces" and "Resource-Priority Priority-values" registries. The management policy of these registries is "Standards Action" [RFC5226]. Experience suggests that a document that only defines a new namespace with its priorities, and does not create new protocol semantics, should not be a Standards-Track document. Therefore, this document updates [RFC4412] to change the management policy of the registries to "IETF Review".

[RFC4412]は、「Resource-Priority Namespaces」レジストリーと「Resource-Priority Priority-values」レジストリーを定義しています。これらのレジストリーの管理ポリシーは「Standards Action」[RFC5226]です。経験から、新しい名前空間とその優先度を定義するだけで、新しいプロトコルのセマンティクスを作り出さない文書は、標準化過程の文書であるべきではないと考えられます。そのため、この文書は、これらのレジストリーの管理ポリシーを「IETF Review」に変更するため、[RFC4412]を更新します。

2. Security Considerations

2. セキュリティーに関する考慮事項

This document does not introduce any security considerations beyond those discussed in [RFC4412].

この文書は、[RFC4412]で議論されているもの以外に、セキュリティーに関する考慮事項をもたらしません。

3. IANA Considerations

3. IANAに関する考慮事項

IANA has changed the management policy of the "Resource-Priority Namespaces" and "Resource-Priority Priority-values" registries to "IETF Review" [RFC5226].

IANAは、「Resource-Priority Namespaces」レジストリーと「Resource-Priority Priority-values」レジストリーの管理ポリシーを「IETF Review」[RFC5226]に変更しました。
