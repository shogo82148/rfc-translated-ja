RFC 1960

A String Representation of LDAP Search Filters

RFC 1960

LDAP検索フィルターの文字列表現

Status of This Memo

このメモのステータス

This document specifies an Internet standards track protocol for the Internet community, and requests discussion and suggestions for improvements. Please refer to the current edition of the "Internet Official Protocol Standards" (STD 1) for the standardization state and status of this protocol. Distribution of this memo is unlimited.

この文書は、インターネットコミュニティーのためのインターネット標準化過程（Internet Standards Track）のプロトコルを規定し、改善のための議論と提案を求めるものです。このプロトコルの標準化の状態とステータスについては、「Internet Official Protocol Standards」（STD 1）の最新版を参照してください。このメモの配布は無制限です。

1. Abstract

1. 概要

The Lightweight Directory Access Protocol (LDAP) [1] defines a network representation of a search filter transmitted to an LDAP server. Some applications may find it useful to have a common way of representing these search filters in a human-readable form. This document defines a human-readable string format for representing LDAP search filters.

Lightweight Directory Access Protocol（LDAP）[1]は、LDAPサーバーに送信される検索フィルターのネットワーク表現を定義しています。アプリケーションによっては、これらの検索フィルターを人間が読める形式で表す共通の方法があると便利な場合があります。この文書は、LDAP検索フィルターを表すための、人間が読める文字列形式を定義します。

2. LDAP Search Filter Definition

2. LDAP検索フィルターの定義

An LDAP search filter is defined in [1] as follows:

LDAP検索フィルターは、[1]で次のように定義されています。

  Filter ::= CHOICE {
          and                [0] SET OF Filter,
          or                 [1] SET OF Filter,
          not                [2] Filter,
          equalityMatch      [3] AttributeValueAssertion,
          substrings         [4] SubstringFilter,
          greaterOrEqual     [5] AttributeValueAssertion,
          lessOrEqual        [6] AttributeValueAssertion,
          present            [7] AttributeType,
          approxMatch        [8] AttributeValueAssertion
  }

  SubstringFilter ::= SEQUENCE {
          type    AttributeType,
          SEQUENCE OF CHOICE {
                  initial        [0] LDAPString,
                  any            [1] LDAPString,
                  final          [2] LDAPString
          }
  }

  AttributeValueAssertion ::= SEQUENCE {
          attributeType   AttributeType,
          attributeValue  AttributeValue
  }

  AttributeType ::= LDAPString

  AttributeValue ::= OCTET STRING

  LDAPString ::= OCTET STRING

  Filter ::= CHOICE {
          and                [0] SET OF Filter,
          or                 [1] SET OF Filter,
          not                [2] Filter,
          equalityMatch      [3] AttributeValueAssertion,
          substrings         [4] SubstringFilter,
          greaterOrEqual     [5] AttributeValueAssertion,
          lessOrEqual        [6] AttributeValueAssertion,
          present            [7] AttributeType,
          approxMatch        [8] AttributeValueAssertion
  }

  SubstringFilter ::= SEQUENCE {
          type    AttributeType,
          SEQUENCE OF CHOICE {
                  initial        [0] LDAPString,
                  any            [1] LDAPString,
                  final          [2] LDAPString
          }
  }

  AttributeValueAssertion ::= SEQUENCE {
          attributeType   AttributeType,
          attributeValue  AttributeValue
  }

  AttributeType ::= LDAPString

  AttributeValue ::= OCTET STRING

  LDAPString ::= OCTET STRING

where the LDAPString above is limited to the IA5 character set. The AttributeType is a string representation of the attribute type name and is defined in [1]. The AttributeValue OCTET STRING has the form defined in [2]. The Filter is encoded for transmission over a network using the Basic Encoding Rules defined in [3], with simplifications described in [1].

ここで、上記のLDAPStringはIA5文字セットに限られます。AttributeTypeは属性型の名前を文字列で表したもので、[1]で定義されています。AttributeValueのOCTET STRINGは、[2]で定義された形式を持ちます。Filterは、ネットワーク上で送信するために、[3]で定義されたBasic Encoding Rulesを使い、[1]で説明されている簡略化を加えてエンコードされます。

3. String Search Filter Definition

3. 文字列による検索フィルターの定義

The string representation of an LDAP search filter is defined by the following grammar. It uses a prefix format.

LDAP検索フィルターの文字列表現は、次の文法で定義されます。これは前置形式を使います。

  <filter> ::= '(' <filtercomp> ')'
  <filtercomp> ::= <and> | <or> | <not> | <item>
  <and> ::= '&' <filterlist>
  <or> ::= '|' <filterlist>
  <not> ::= '!' <filter>
  <filterlist> ::= <filter> | <filter> <filterlist>
  <item> ::= <simple> | <present> | <substring>
  <simple> ::= <attr> <filtertype> <value>
  <filtertype> ::= <equal> | <approx> | <greater> | <less>
  <equal> ::= '='
  <approx> ::= '~='
  <greater> ::= '>='
  <less> ::= '<='
  <present> ::= <attr> '=*'
  <substring> ::= <attr> '=' <initial> <any> <final>
  <initial> ::= NULL | <value>
  <any> ::= '*' <starval>
  <starval> ::= NULL | <value> '*' <starval>
  <final> ::= NULL | <value>

  <filter> ::= '(' <filtercomp> ')'
  <filtercomp> ::= <and> | <or> | <not> | <item>
  <and> ::= '&' <filterlist>
  <or> ::= '|' <filterlist>
  <not> ::= '!' <filter>
  <filterlist> ::= <filter> | <filter> <filterlist>
  <item> ::= <simple> | <present> | <substring>
  <simple> ::= <attr> <filtertype> <value>
  <filtertype> ::= <equal> | <approx> | <greater> | <less>
  <equal> ::= '='
  <approx> ::= '~='
  <greater> ::= '>='
  <less> ::= '<='
  <present> ::= <attr> '=*'
  <substring> ::= <attr> '=' <initial> <any> <final>
  <initial> ::= NULL | <value>
  <any> ::= '*' <starval>
  <starval> ::= NULL | <value> '*' <starval>
  <final> ::= NULL | <value>

<attr> is a string representing an AttributeType, and has the format defined in [1]. <value> is a string representing an AttributeValue, or part of one, and has the form defined in [2]. If a <value> must contain one of the characters '*' or '(' or ')', these characters should be escaped by preceding them with the backslash '\' character.

<attr>はAttributeTypeを表す文字列で、[1]で定義された形式を持ちます。<value>はAttributeValueまたはその一部を表す文字列で、[2]で定義された形式を持ちます。<value>に'*'、'('、')'のいずれかの文字を含める必要がある場合は、これらの文字の前にバックスラッシュ文字'\'を置いてエスケープすべきです。

Note that although both the <substring> and <present> productions can produce the 'attr=*' construct, this construct is used only to denote a presence filter.

'attr=*'という構成は<substring>と<present>の両方の生成規則から生成できますが、この構成は存在フィルター（presence filter）を表すためだけに使われることに注意してください。

4. Examples

4. 例

This section gives a few examples of search filters written using this notation.

このセクションでは、この表記法を使って書いた検索フィルターの例をいくつか示します。

  (cn=Babs Jensen)
  (!(cn=Tim Howes))
  (&(objectClass=Person)(|(sn=Jensen)(cn=Babs J*)))
  (o=univ*of*mich*)

  (cn=Babs Jensen)
  (!(cn=Tim Howes))
  (&(objectClass=Person)(|(sn=Jensen)(cn=Babs J*)))
  (o=univ*of*mich*)
