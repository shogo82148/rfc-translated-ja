RFC 429

Character Generator Process

RFC 429

文字生成プロセス

Abstract

概要

I hereby propose that there be a standard process implemented on whatever hosts desire which generates character data with out any regard to input. In some sense the process is the converse of the discard process [RFC 348]. Many hosts have an existing terminal testing program [e.g. TTYTST] which would suit this function adequately.

私はここに、希望するホストに実装する標準プロセスとして、入力にまったく関係なく文字データを生成するプロセスを提案します。ある意味で、このプロセスは破棄（discard）プロセス[RFC 348]の逆です。多くのホストには既存の端末テストプログラム[例：TTYTST]があり、この機能を十分に果たせるでしょう。

This Character Generator process would listen for a request for connection and execute the Initial Connection Protocol (ICP) as specified in NIC 7104 the "Current Network Protocols" notebook. Upon completion of the ICP the Character Generator process would begin to send characters into the network as buffer space is made available .

この文字生成（Character Generator）プロセスは、接続要求を待ち受け、「Current Network Protocols」ノートブックのNIC 7104で規定されている初期接続プロトコル（Initial Connection Protocol; ICP）を実行します。ICPが完了すると、文字生成プロセスは、バッファー空間が利用可能になるにつれて、ネットワークに文字を送り始めます。

The Character Generator process is terminated by closing the connections.

文字生成プロセスは、接続を閉じることで終了します。
