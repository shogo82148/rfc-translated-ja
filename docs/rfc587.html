RFC 587

Announcing New Telnet Options

RFC 587

新しいTelnetオプションのお知らせ

Abstract

概要

This is to announce that two new TELNET options have been specified.

2つの新しいTELNETオプションが規定されたことをお知らせします。

  • Negotiate About Output Line Width (NAOL) NIC#20196
  • Negotiate About Output Page Size (NAOP) NIC#20197
  • 出力行幅のネゴシエーション（Negotiate About Output Line Width; NAOL）、NIC#20196
  • 出力ページサイズのネゴシエーション（Negotiate About Output Page Size; NAOP）、NIC#20197

These were prepared by Dave Walden (BBN-NET) and put on-line by Anita Coley (UCLA-NMC) and Dave Crocker (UCLA-NMC).

これらは、Dave Walden（BBN-NET）が作成し、Anita Coley（UCLA-NMC）とDave Crocker（UCLA-NMC）がオンラインにしました。
