RFC 118

Recommendations for facility documentation

RFC 118

ファシリティーの文書化に関する推奨事項

INFORMATION REQUIRED FOR EACH SERVICE AVAILABLE TO THE NETWORK

ネットワークに提供する各サービスに必要な情報

There are two classes of information which a site needs to provide for each service or process it makes available over the Network:

サイトは、ネットワーク経由で利用できるようにする各サービスやプロセスについて、2種類の情報を提供する必要があります。

  1. information required by system programmers in order to establish a connection to the facility
  2. information required by a user to gain access to and use the facility
  1. ファシリティーへのコネクションを確立するためにシステムプログラマーが必要とする情報
  2. ユーザーがファシリティーにアクセスして利用するために必要とする情報

The above two basic kinds of information which need to be in each facility description will comprise a "functional document" (see RFC 115, NIC (5822,) for a description of functional documents and recommended procedures for updating them).

各ファシリティーの説明に含める必要がある上記の2種類の基本的な情報によって、「機能文書（functional document）」が構成されます（機能文書の説明と、その更新のための推奨手順については、RFC 115、NIC (5822,)を参照してください）。

The information required by user site system programmers may be a detailed document or a reference to a document containing a protocol common to several facilities or some combination of the above. All information required such as connection socket numbers, message formats, and character set information must be included. Two examples of system programmer type information are RFC 74, NIC (5417,) and RFC 105, NIC (5775,) prepared by James White of UCSB.

ユーザーサイトのシステムプログラマーが必要とする情報は、詳細な文書であっても、複数のファシリティーに共通するプロトコルを記載した文書への参照であっても、それらを組み合わせたものであってもかまいません。コネクションのソケット番号、メッセージの形式、文字セットの情報など、必要な情報はすべて含めなければなりません。システムプログラマー向けの情報の例として、UCSBのJames Whiteが作成したRFC 74、NIC (5417,)とRFC 105、NIC (5775,)の2つがあります。

The information required by user site users is of three types:

ユーザーサイトのユーザーが必要とする情報には、3つの種類があります。

  1. information unique to Network users of the facility
  2. information in common between Network users and server site users of the facility
  3. information unique to particular Network user site.
  1. ファシリティーのネットワークユーザーに固有の情報
  2. ファシリティーのネットワークユーザーとサーバーサイトのユーザーに共通する情報
  3. 特定のネットワークユーザーサイトに固有の情報。

The information of type c) would be prepared by the user site from the information provided by the server site. An example might be keying conventions required in order to send certain codes to the server site.

c)の種類の情報は、サーバーサイトから提供された情報をもとに、ユーザーサイトが用意することになるでしょう。たとえば、特定のコードをサーバーサイトに送るために必要なキー入力の規則などが考えられます。

Future documentation will probably be written with information types a) and b) above integrated in one document, but initially server sites will probably have user manuals or documentation for their local users and will need to write a short document giving any additional information required for Network users. This information will vary, but might include a different login or control card sequence, varying echo or syntax for user sites operating with character at a time, line at a time, server site or user site echoing and so forth. Some features available to server site users may not be available to Network user site users or certain features may behave differently.

将来の文書は、おそらく上記のa)とb)の種類の情報を1つの文書にまとめて書かれるようになるでしょう。しかし当初は、サーバーサイトはおそらくローカルユーザー向けのユーザーマニュアルや文書を持っているので、ネットワークユーザーに必要な追加情報を記載した短い文書を書く必要があるでしょう。この情報はさまざまですが、異なるログインやコントロールカードの手順や、ユーザーサイトの動作形態（1文字ずつ、1行ずつ、サーバーサイトでのエコー、ユーザーサイトでのエコーなど）に応じて異なるエコーや構文などが含まれるかもしれません。サーバーサイトのユーザーが利用できる機能の一部が、ネットワークユーザーサイトのユーザーには利用できなかったり、特定の機能の動作が異なったりすることもあるでしょう。

In addition to the above types of information, there should be instructions to the user on how to obtain help or answers to questions about using the facility.

上記の種類の情報に加えて、ファシリティーの利用に関するヘルプや質問への回答を得る方法を、ユーザーに説明しておくべきです。

Information about how to obtain administrative access (charge numbers, etc.) to a site should be contained in the document, ARPA Network Current Guides to Network Facilities, NIC (5148,). This information is being collected by BBN. This document will in turn contain references to the functional documents containing detailed descriptions of available Network facilities and how to use them.

サイトへの管理上のアクセス（課金番号など）を得る方法に関する情報は、文書「ARPA Network Current Guides to Network Facilities」、NIC (5148,)に含めるべきです。この情報はBBNが収集しています。この文書には、利用可能なネットワークファシリティーとその使い方を詳しく説明した機能文書への参照も含まれることになります。

Even if there are no special conventions or information unique to a Network user as opposed to a server site user, this fact should be explicitly stated in order to avoid confusion or uncertainty.

サーバーサイトのユーザーとは異なる、ネットワークユーザーに固有の特別な規則や情報がない場合でも、混乱や不確かさを避けるために、そのことを明記すべきです。

NETWORK INFORMATION CENTER POLICY ON DISTRIBUTION AND UPDATING OF DOCUMENTATION

文書の配布と更新に関するネットワークインフォメーションセンターの方針

The Network Information Center will distribute and maintain one copy of each functional document describing a facility in each Network Station NIC Collection. For this purpose we would appreciate it if 100 copies of each manual and set of manual updates, when they occur, could be sent to the NIC. Users at sites desiring their own copies of user documentation can obtain them either directly from the server site or by copying the master in their local NIC Collection. In order that users may know where to obtain additional copies of the documentation, an address and a price, if any, should be included in the information about each facility.

ネットワークインフォメーションセンター（Network Information Center）は、ファシリティーを説明する各機能文書を1部ずつ、各ネットワークステーションのNICコレクションに配布し、維持します。そのため、各マニュアルと、更新があった場合はマニュアルの更新一式を、100部ずつNICに送っていただけるとありがたく思います。ユーザー文書を自分用に入手したいサイトのユーザーは、サーバーサイトから直接入手するか、ローカルのNICコレクションにある原本を複製することで入手できます。ユーザーが文書の追加のコピーをどこで入手できるかがわかるように、各ファシリティーに関する情報には、連絡先の住所と、もしあれば価格を記載すべきです。
