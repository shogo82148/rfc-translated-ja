RFC 597

Host Status

RFC 597

ホストの状況

Abstract

概要

Attached are the latest network maps -- geographic and logical -- and a list of Hosts connected to the ARPANET.

最新のネットワーク地図（地理的な地図と論理的な地図）と、ARPANETに接続されているホストの一覧を添付します。

The geographic map shows all IMPs and TIPs currently installed in the subnetwork.

地理的な地図は、現在サブネットワークに設置されているすべてのIMPとTIPを示しています。

The logical map diagrams the current (as of Dec. 10, 1973) status of all computers on the net, with the exception of MIT-MULTICS which is shown in the advanced state of being attached to IMP #44 rather than IMP #5. (My apologies for not reprinting the map.) Hosts with interfaces to the subnet are shown with intersected ovals; the small "v" represents a Very Distant Host (VDH) interface to the IMP; IMPs are the solid black circles and TIPs the circles with "T" enclosed. The two jagged lines represent satellite links.

論理的な地図は、ネット上のすべてのコンピューターの現在（1973年12月10日時点）の状況を図示しています。ただし、MIT-MULTICSは例外で、IMP #5ではなくIMP #44に接続されるという、先の段階の状態で示されています（地図を刷り直さなかったことをお詫びします）。サブネットへのインターフェイスを持つホストは、交差する楕円で示しています。小さな「v」は、IMPへのVery Distant Host（VDH）インターフェイスを表します。IMPは黒く塗りつぶした円で、TIPは「T」を囲んだ円で示しています。2本のギザギザの線は衛星リンクを表します。

Note: The names listed on this map are unofficial IMP names, NOT official Host names.

注: この地図に記載されている名前は非公式のIMP名であり、公式のホスト名ではありません。

The list of Hosts includes current sites as well as those projected to come onto the net within the next two months. At the end is an incomplete list of installations to be connected further in the future. Dates for connection have been included only for the next few months to prevent gross inaccuracy.

ホストの一覧には、現在のサイトに加えて、今後2か月以内にネットに参加する予定のサイトも含まれています。末尾には、さらに先に接続される予定の設備の不完全な一覧があります。大きな不正確さを避けるため、接続日は今後数か月分のみ記載しています。

The Host's network address is given in octal and decimal.

ホストのネットワークアドレスは、8進数と10進数で示しています。

Interfaces from the subnet to the particular computer are listed in parentheses and may be ignored.

サブネットから個々のコンピューターへのインターフェイスは括弧内に記載しており、無視してかまいません。

A site is considered a Server or User of the network based on self-proclamation. Limited Server implies the site performs service functions but for a restricted group of users dedicated Servers implies the type of service is restricted, not the user group. In all cases normal site access restrictions are observed. Included in the status column is any special operating system available for that Host, that is not supplied by the computer manufacturer.

サイトがネットワークのサーバーかユーザーかは、自己申告に基づいて判断しています。限定サーバー（Limited Server）は、そのサイトがサービス機能を実行するものの、利用者が限られたグループに制限されていることを意味します。専用サーバー（dedicated Server）は、利用者のグループではなく、サービスの種類が制限されていることを意味します。いずれの場合も、通常のサイトアクセス制限が守られます。状況の欄には、そのホストで利用できる特別なオペレーティングシステムのうち、コンピューターの製造元が提供していないものも記載しています。

This RFC contains official Host names as of December, 1973. Naming conventions and an official Hostname list, which will be maintained at the NIC by Jake Feinler (FEINLER@NIC), will be published in the ARPANEWS. A version of this list will be available online at the NIC, the location to be announced with the official Hostname list. (Other sites are encouraged to make copies of this list available on their own systems.) In addition, a printed version will be issued periodically as part of the Resource Notebook

このRFCには、1973年12月時点の公式のホスト名が含まれています。命名規則と公式のホスト名一覧はNICでJake Feinler（FEINLER@NIC）が管理し、ARPANEWSで公開する予定です。この一覧の版はNICでオンラインで利用できるようになる予定で、その場所は公式のホスト名一覧とともに告知します（他のサイトも、自身のシステム上でこの一覧のコピーを利用できるようにすることが推奨されます）。さらに、印刷版がResource Notebookの一部として定期的に発行される予定です。
