RFC 255

Status of network hosts

RFC 255

ネットワークホストの状況

Abstract

概要

This RFC reports on the status of most Network Hosts from October 12 to October 22. (Monday, October 11 was Columbus Day.) During these two weeks, the general status of these Hosts remained as it had been previously.

このRFCでは、10月12日から10月22日までの、ほとんどのネットワークホストの状況を報告します（10月11日の月曜日はコロンブス・デーでした）。この2週間、これらのホストの全般的な状況は以前と変わりませんでした。

where

ここで、各記号の意味は次のとおりです。

D =
Dead (Destination Host either dead or inaccessible [due to network partitioning or local IMP failure] from the BBN Terminal IMP.)
R =
Refused (Destination Host returned a CLS to the initial RFC.)
T =
Timed out (Destination Host did not respond in any way to the initial RFC, although not dead.)
H =
1/2 Open (Destination Host opened a connection but then either immediately closed it, or did not respond any further.)
O =
Opened (Destination Host opened a connection and was accessible to user.)
*
The UCLA IMB-360/91 currently has Remote Job Service (NETRJS), but has not implemented a full server Telnet System. The BBN Terminal IMP is not equipped to test NETRJS however, we are assuming that receipt of the UCLA explanatory message indicates that NETRJS is also functioning.
#
These sites advertise that they may not have their system available at these times.
D =
Dead（停止）。宛先ホストが停止しているか、BBN Terminal IMPから（ネットワークの分断またはローカルIMPの障害により）アクセスできない状態です。
R =
Refused（拒否）。宛先ホストが、最初のRFC（接続要求）に対してCLSを返しました。
T =
Timed out（タイムアウト）。宛先ホストは停止していないものの、最初のRFCに対してまったく応答しませんでした。
H =
1/2 Open（半開）。宛先ホストはコネクションを開いたものの、その後すぐに閉じたか、それ以上応答しませんでした。
O =
Opened（オープン）。宛先ホストがコネクションを開き、ユーザーからアクセスできました。
*
UCLAのIMB-360/91には現在リモートジョブサービス（Remote Job Service、NETRJS）がありますが、完全なサーバーTelnetシステムは実装されていません。BBN Terminal IMPにはNETRJSを試験する設備がありませんが、UCLAから説明メッセージを受信したことは、NETRJSも機能していることを示すものとみなしています。
#
これらのサイトは、この時間帯にはシステムを利用できない可能性があると告知しています。
