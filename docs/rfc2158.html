1. Introduction

1. はじめに

This document contains the body parts defined in RFC 1495 for carrying image formats that were originally defined in MIME through an X.400 system.

この文書には、もともとMIMEで定義された画像形式をX.400システムで運ぶために、RFC 1495で定義されたボディーパートを収録しています。

It also documents the OIDs assigned to these data formats as FTAM body parts, which allow the MIME types to be converted to FTAM body parts; this will probably be more useful than the new body parts defined here.

また、これらのデータ形式にFTAMボディーパートとして割り当てられたOIDも記載します。これにより、MIMEタイプをFTAMボディーパートに変換できます。おそらく、こちらのほうがここで定義する新しいボディーパートよりも有用でしょう。

2. Newly defined X.400 body parts

2. 新たに定義するX.400ボディーパート

2.1. The JPEG body part

2.1. JPEGボディーパート

The following Extended Body Part is defined for JPEG data streams. It has no parameters.

JPEGデータストリーム用に、次の拡張ボディーパート（Extended Body Part）を定義します。パラメーターはありません。

jpeg-body-part EXTENDED-BODY-PART-TYPE
  DATA            OCTET STRING
  ::= mime-jpeg-body

jpeg-body-part EXTENDED-BODY-PART-TYPE
  DATA            OCTET STRING
  ::= mime-jpeg-body

mime-jpeg-body OBJECT IDENTIFIER ::=
        { mixer-bp-data 3 }

mime-jpeg-body OBJECT IDENTIFIER ::=
        { mixer-bp-data 3 }

The content is as defined in [MIME].

内容は[MIME]で定義されているとおりです。

2.2. The GIF body part

2.2. GIFボディーパート

The following Extended Body Part is defined for GIF data streams. It has no parameters.

GIFデータストリーム用に、次の拡張ボディーパートを定義します。パラメーターはありません。

gif-body-part EXTENDED-BODY-PART-TYPE
  DATA            OCTET STRING
  ::= mime-gif-body

gif-body-part EXTENDED-BODY-PART-TYPE
  DATA            OCTET STRING
  ::= mime-gif-body

mime-gif-body OBJECT IDENTIFIER ::=
        { mixer-bp-data 4 }

mime-gif-body OBJECT IDENTIFIER ::=
        { mixer-bp-data 4 }

The content is as defined in [MIME].

内容は[MIME]で定義されているとおりです。

3.2. image/jpeg - FTAM EMA JPEG

3.2. image/jpeg - FTAM EMA JPEG

X.400 Body Part:
FTAM EMA JPEG
MIME Content-Type:
image/jpeg
Conversion:
None
X.400ボディーパート：
FTAM EMA JPEG
MIME Content-Type：
image/jpeg
変換：
なし

The OID assigned to JPEG by EMA in [MAWG] is

[MAWG]でEMAがJPEGに割り当てたOIDは次のとおりです。

{ ema objects(2) messaging (2) attachments(1) jpeg-image(6) }

{ ema objects(2) messaging (2) attachments(1) jpeg-image(6) }

while EMA's OID is

一方、EMAのOIDは次のとおりです。

{ joint-iso-ccitt(2) country(16) us(840) organization(1)
ema(113694) }

{ joint-iso-ccitt(2) country(16) us(840) organization(1)
ema(113694) }

making the total OID, numeric only

したがって、OID全体を数値だけで表すと次のようになります。

{ 2 16 840 1 113694 2 2 1 6 }

{ 2 16 840 1 113694 2 2 1 6 }
