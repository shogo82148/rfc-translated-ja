RFC 628

Status of RFC Numbers and a Note on Pre-assigned Journal Numbers

RFC 628

RFC番号の状況と、事前に割り当てられたジャーナル番号に関する注意

Abstract

概要

This is to announce that RFC numbers can now be obtained on-line through NLS at OFFICE-1; they can no longer be obtained on-line at SRI-ARC. You may still call the NIC to get an RFC number, if you do not wish to use the on-line facilities.

RFC番号はOFFICE-1のNLSを通じてオンラインで取得できるようになり、SRI-ARCではオンラインで取得できなくなったことをお知らせします。オンライン機能を使いたくない場合は、これまでどおりNICに電話してRFC番号を取得することもできます。

Also, please note that pre-assigned journal numbers (excepting RFC numbers) can be used through NLS only on the system (OFFICE-1 or SRI-ARC) from which they were taken.

また、事前に割り当てられたジャーナル番号（RFC番号を除く）は、それを取得したシステム（OFFICE-1またはSRI-ARC）上でのみ、NLSを通じて使えることに注意してください。
