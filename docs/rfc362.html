RFC 362

Network Host Status

RFC 362

ネットワークホストの状況

Abstract

概要

This RFC reports on the status of most Network Hosts from June 5 to June 16. During this period the MIT Math Lab PDP-10 (Network address 198) became a server.

このRFCは、6月5日から6月16日までの、ほとんどのネットワークホストの状況を報告するものです。この期間に、MIT Math LabのPDP-10（ネットワークアドレス198）がサーバーになりました。

No testing was done on June 6 due to an attempt to install the new IMP system. No testing was done on June 9 as the prototype Terminal IMP was being used for software debugging.

6月6日は、新しいIMPシステムの導入を試みたため、テストを行いませんでした。6月9日は、プロトタイプのTerminal IMPをソフトウェアのデバッグに使用していたため、テストを行いませんでした。

On June 16 the ARPA Terminal IMP (Network 156) was installed in Arlington, Virginia.

6月16日に、ARPAのTerminal IMP（ネットワーク156）がバージニア州アーリントンに設置されました。

Several Hosts are currently excluded from the daily testing. These Hosts fall into two categories:

現在、いくつかのホストは毎日のテストから除外しています。これらのホストは2つのカテゴリーに分かれます。

1) Hosts which are not expected to be functioning on the Network as servers (available for use from other sites) on a regular basis for at least two weeks. The only Host in this category is the PDP-10 at Case (Network address 13).

1) 少なくとも2週間は、ネットワーク上でサーバー（他のサイトから利用可能なもの）として定常的に稼働する見込みのないホスト。このカテゴリーに属するホストは、CaseのPDP-10（ネットワークアドレス13）だけです。

2) Hosts which are currently intended to be users only. Included here are the Terminal IMPs, which are presently in the Network (AMES, MITRE, NBS, ETAC, USC, GWC, NOAA, RADC, SAAC, BELVOIR, ARPA, and BBN*). This category also includes the Network Control Center computer (Network address 5) which is used solely for gathering statistics from the Network. Finally, included among these Hosts are the following:

2) 現在はユーザーとしてのみ使用する予定のホスト。現在ネットワーク上にあるTerminal IMP（AMES、MITRE、NBS、ETAC、USC、GWC、NOAA、RADC、SAAC、BELVOIR、ARPA、BBN*）がここに含まれます。このカテゴリーには、ネットワークの統計情報の収集にのみ使用するネットワークコントロールセンター（Network Control Center）のコンピューター（ネットワークアドレス5）も含まれます。最後に、これらのホストには次のものも含まれます。

where

記号の意味は次のとおりです。

D =
Dead (Destination Host either dead or inaccessible [due to network partitioning or local IMP failure] from the BBN Terminal IMP.)
F =
Full (Destination Host opened a connection, informed user that all Network ports were in use, and immediately closed the connection.)
H =
1/2 Open (Destination Host opened a connection but then either immediately closed it, or did not respond any further.)
O =
Open (Destination Host opened a connection and was accessible to users.)
R =
Refused (Destination Host returned a CLS to the initial RFC.)
T =
Timed out (Destination Host did not complete the ICP and open a connection within 60 seconds.)
D =
Dead（宛先ホストが停止しているか、BBNのTerminal IMPから［ネットワークの分断またはローカルのIMPの障害により］アクセスできない。）
F =
Full（宛先ホストがコネクションを開き、すべてのネットワークポートが使用中であることをユーザーに通知して、すぐにコネクションを閉じた。）
H =
1/2 Open（宛先ホストがコネクションを開いたが、その後すぐにそれを閉じたか、それ以上応答しなかった。）
O =
Open（宛先ホストがコネクションを開き、ユーザーがアクセスできた。）
R =
Refused（宛先ホストが最初のRFCに対してCLSを返した。）
T =
Timed out（宛先ホストが60秒以内にICPを完了してコネクションを開かなかった。）
