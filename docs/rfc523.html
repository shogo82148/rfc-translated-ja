RFC 523

SURVEY is in Operation Again

RFC 523

SURVEYの運用再開

Abstract

概要

The purpose of this message is to inform the network community that the survey program at MIT-DMCG computer system is in operation now. We are surveying hosts every 20 minutes instead of the earlier 15 minutes. It appears that some sites had problems with incomplete ICP's when survey first came up. The problem has definitely been fixed now. Please let me know (tel 617-253-1428 or 253-1449) if any site is being inconvenienced by the survey program. Upon written request I will be willing to not survey a particular server site. Upon oral or written request, I will add sites who wish to be surveyed but are not surveyed.

このメッセージの目的は、MIT-DMCGのコンピューターシステムのSURVEYプログラムが現在稼働していることを、ネットワークコミュニティーにお知らせすることです。以前は15分ごとでしたが、現在は20分ごとにホストを調査しています。SURVEYが最初に稼働したとき、一部のサイトでICPが完了しないという問題があったようです。この問題は現在では確実に修正されています。SURVEYプログラムによって迷惑を被っているサイトがあれば、私までお知らせください（電話617-253-1428または253-1449）。書面で依頼があれば、特定のサーバーサイトを調査対象から外します。調査を希望しているのに調査されていないサイトは、口頭または書面で依頼があれば追加します。

The sites currently being surveyed are (host number in decimal): 1,2,3,4,6,7,8,9,10,11,13,14,15,16,23,31,32,35,65,66,69,70,74,78,86,133, 134,138,198. We issue an RFC to socket1 and now go though the complete ICP, ie establish telnet connections and then close them. The time for response is now the time to establish the telnet connections, so if your response time shows a larger number don't be alarmed (I think the new numbers are more meaningful and reflect the situation more accurately.)

現在調査しているサイトは次のとおりです（ホスト番号は10進数）：1,2,3,4,6,7,8,9,10,11,13,14,15,16,23,31,32,35,65,66,69,70,74,78,86,133,134,138,198。当方はソケット1にRFC（接続要求）を発行し、現在はICPを最後まで実行します。つまり、telnetのコネクションを確立してから、それを閉じます。そのため、応答時間はtelnetのコネクションを確立するまでの時間になります。応答時間が以前より大きな値を示していても驚かないでください（新しい値のほうが意味があり、状況をより正確に反映していると私は考えています）。

We are also providing a NETSTATUS service on socket 15. (decimal). So if you ICP to host 70 socket 15., you will get the following output:

当方では、ソケット15.（10進数）でNETSTATUSサービスも提供しています。ホスト70のソケット15.に対してICPを行うと、次のような出力が得られます。

        mm,dd.yyyy,hh,mm
        nnn,c,ttt
        nnn,c,ttt
        .......
        -1

        mm,dd.yyyy,hh,mm
        nnn,c,ttt
        nnn,c,ttt
        .......
        -1

Where first item is month, day, year, hour, minute and then is a list of host numbers, code, response time in tenths of second. The list ends with a minus 1, and we close the connections right after sending data (The service is designed so that both human users and programs can use the data ). You can of course log into dmcg and use our NETWRK subsystem which has commands for displaying the survey data in many formats (Ref. RFC 308, NIC 9259). We are also recording this data on the DATACOMPUTER (CCA). Your comments and suggestions will be appreciated.

最初の項目は月、日、年、時、分で、その後にホスト番号、コード、応答時間（0.1秒単位）の一覧が続きます。一覧はマイナス1で終わり、データを送信した直後に当方がコネクションを閉じます（このサービスは、人間の利用者とプログラムの両方がデータを利用できるように設計されています）。もちろん、dmcgにログインして、当方のNETWRKサブシステムを使うこともできます。このサブシステムには、SURVEYのデータをさまざまな形式で表示するコマンドがあります（RFC 308、NIC 9259を参照）。当方では、このデータをDATACOMPUTER（CCA）にも記録しています。コメントや提案をいただければ幸いです。

Thank You

ありがとうございます。

Abhay Bhushan
AKB@DMCG (NIC ident AKB)
