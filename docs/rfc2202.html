RFC 2202

Test Cases for HMAC-MD5 and HMAC-SHA-1

RFC 2202

HMAC-MD5とHMAC-SHA-1のテストケース

Abstract

概要

This document provides two sets of test cases for HMAC-MD5 and HMAC-SHA-1, respectively. HMAC-MD5 and HMAC-SHA-1 are two constructs of the HMAC [HMAC] message authentication function using the MD5 [MD5] hash function and the SHA-1 [SHA] hash function. Both constructs are used by IPSEC [OG] [CG] and other protocols to authenticate messages. The test cases and results provided in this document are meant to be used as a conformance test for HMAC-MD5 and HMAC-SHA-1 implementations.

この文書は、HMAC-MD5とHMAC-SHA-1のそれぞれについて、2組のテストケースを提供します。HMAC-MD5とHMAC-SHA-1は、MD5 [MD5]ハッシュ関数とSHA-1 [SHA]ハッシュ関数を使って、HMAC [HMAC]メッセージ認証関数を構成した2種類の構成です。 どちらの構成も、IPSEC [OG] [CG]やその他のプロトコルで、メッセージの認証に使われています。 この文書で提供するテストケースと結果は、HMAC-MD5およびHMAC-SHA-1の実装に対する適合性テストとして使われることを意図しています。

Status of This Memo

このメモのステータス

このメモは、インターネットコミュニティーに情報を提供するものです。 このメモは、いかなる種類のインターネット標準も規定しません。 このメモの配布に制限はありません。

1. Introduction

1. はじめに

The general method for constructing a HMAC message authentication function using a particular hash function is described in section 2 of [HMAC]. We will not repeat the description here. Section 5 of [HMAC] also discusses truncating the output of HMAC; the rule is that we should keep the more significant bits (the bits in the left, assuming a network byte order (big-endian)).

特定のハッシュ関数を使ってHMACメッセージ認証関数を構成する一般的な方法は、[HMAC]のセクション2で説明されています。ここでは、その説明を繰り返しません。 また、[HMAC]のセクション5では、HMACの出力の切り詰めについても議論されています。 その規則は、上位のビット（ネットワークバイトオーダー（ビッグエンディアン）を前提とすると、左側のビット）を残すべきである、というものです。

In sections 2 and 3 we provide test cases for HMAC-MD5 and HMAC-SHA-1, respectively. Each case includes the key, the data, and the result. The values of keys and data are either hexadecimal numbers (prefixed by "0x") or ASCII character strings in double quotes. If a value is an ASCII character string, then the HMAC computation for the corresponding test case DOES NOT include the trailing null character ('\0') in the string.

セクション2とセクション3では、それぞれHMAC-MD5とHMAC-SHA-1のテストケースを提供します。各ケースには、鍵、データ、結果が含まれます。鍵とデータの値は、16進数（接頭辞「0x」付き）か、二重引用符で囲んだASCII文字列のどちらかです。 値がASCII文字列の場合、対応するテストケースのHMAC計算には、文字列末尾のヌル文字（'\0'）は含まれません。

The C source code of the functions used to generate HMAC-SHA-1 results is listed in the Appendix. Note that these functions are meant to be simple and easy to understand; they are not optimized in any way. The C source code for computing HMAC-MD5 can be found in [MD5]; or you can do a simple modification to HMAC-SHA-1 code to get HMAC-MD5 code, as explained in the Appendix.

HMAC-SHA-1の結果の生成に使った関数のCソースコードは、付録に掲載しています。 これらの関数は、単純で理解しやすいことを目的としており、いかなる最適化もされていないことに注意してください。 HMAC-MD5を計算するCソースコードは[MD5]にあります。 あるいは、付録で説明するように、HMAC-SHA-1のコードに簡単な修正を加えることで、HMAC-MD5のコードを得ることもできます。

The test cases in this document are cross-verified by three independent implementations, one from NIST and two from IBM Research. One IBM implementation uses optimized code that is very different from the code in the Appendix. An implemenation that concurs with the results provided in this document should be interoperable with other similar implemenations. We do not claim that such an implementation is absolutely correct with respect to the HMAC definition in [HMAC].

この文書のテストケースは、3つの独立した実装（NISTの実装が1つ、IBM Researchの実装が2つ）によって相互検証されています。 IBMの実装の1つは、付録のコードとは大きく異なる最適化されたコードを使っています。 この文書で提供する結果と一致する実装は、同様の他の実装と相互運用可能であるはずです。 ただし、そのような実装が、[HMAC]のHMACの定義に関して絶対的に正しいと主張するものではありません。

Appendix A. Appendix

付録A. 付録

This appendix contains the C reference code which implements HMAC-SHA-1 using an existing SHA-1 library. It assumes that the SHA-1 library has similar API's as those of the MD5 code described in RFC 1321. The code for HMAC-MD5 is similar, just replace the strings "SHA" and "sha" with "MD5" and "md5". HMAC-MD5 code is also listed in RFC 2104.

この付録には、既存のSHA-1ライブラリーを使ってHMAC-SHA-1を実装するCのリファレンスコードを掲載しています。 SHA-1ライブラリーは、RFC 1321で説明されているMD5のコードと同様のAPIを持つものと仮定しています。 HMAC-MD5のコードも同様で、文字列「SHA」と「sha」を「MD5」と「md5」に置き換えるだけです。 HMAC-MD5のコードは、RFC 2104にも掲載されています。

#ifndef SHA_DIGESTSIZE
#define SHA_DIGESTSIZE  20
#endif

#ifndef SHA_BLOCKSIZE
#define SHA_BLOCKSIZE   64
#endif

#ifndef MD5_DIGESTSIZE
#define MD5_DIGESTSIZE  16
#endif

#ifndef MD5_BLOCKSIZE
#define MD5_BLOCKSIZE   64
#endif

/* Function to print the digest */
void
pr_sha(FILE* fp, char* s, int t)
{
        int     i ;

        fprintf(fp, "0x") ;
        for (i = 0 ; i < t ; i++)
                fprintf(fp, "%02x", s[i]) ;
        fprintf(fp, "0) ;
}

void truncate
(
 char*   d1,   /* data to be truncated */
 char*   d2,   /* truncated data */
 int     len   /* length in bytes to keep */
)
{
        int     i ;
        for (i = 0 ; i < len ; i++) d2[i] = d1[i];
}

/* Function to compute the digest */
void
hmac_sha
(
 char*    k,     /* secret key */
 int      lk,    /* length of the key in bytes */
 char*    d,     /* data */
 int      ld,    /* length of data in bytes */
 char*    out,   /* output buffer, at least "t" bytes */
 int      t
)
{
        SHA_CTX ictx, octx ;
        char    isha[SHA_DIGESTSIZE], osha[SHA_DIGESTSIZE] ;
        char    key[SHA_DIGESTSIZE] ;
        char    buf[SHA_BLOCKSIZE] ;
        int     i ;

        if (lk > SHA_BLOCKSIZE) {

                SHA_CTX         tctx ;

                SHAInit(&tctx) ;
                SHAUpdate(&tctx, k, lk) ;
                SHAFinal(key, &tctx) ;

                k = key ;
                lk = SHA_DIGESTSIZE ;
        }

        /**** Inner Digest ****/

        SHAInit(&ictx) ;

        /* Pad the key for inner digest */
        for (i = 0 ; i < lk ; ++i) buf[i] = k[i] ^ 0x36 ;
        for (i = lk ; i < SHA_BLOCKSIZE ; ++i) buf[i] = 0x36 ;

        SHAUpdate(&ictx, buf, SHA_BLOCKSIZE) ;
        SHAUpdate(&ictx, d, ld) ;

        SHAFinal(isha, &ictx) ;

        /**** Outter Digest ****/

        SHAInit(&octx) ;

        /* Pad the key for outter digest */

        for (i = 0 ; i < lk ; ++i) buf[i] = k[i] ^ 0x5C ;
        for (i = lk ; i < SHA_BLOCKSIZE ; ++i) buf[i] = 0x5C ;

        SHAUpdate(&octx, buf, SHA_BLOCKSIZE) ;
        SHAUpdate(&octx, isha, SHA_DIGESTSIZE) ;

        SHAFinal(osha, &octx) ;

        /* truncate and print the results */
        t = t > SHA_DIGESTSIZE ? SHA_DIGESTSIZE : t ;
        truncate(osha, out, t) ;
        pr_sha(stdout, out, t) ;

}

#endif

#define MD5_DIGESTSIZE  16
#endif

#ifndef MD5_BLOCKSIZE
#define MD5_BLOCKSIZE   64
#endif

(
 char*   d1,   /* 切り詰めるデータ */
 char*   d2,   /* 切り詰めたデータ */
 int     len   /* 残すバイト数 */
)
{
        int     i ;
        for (i = 0 ; i < len ; i++) d2[i] = d1[i];
}

/* ダイジェストを計算する関数 */
void
hmac_sha
(
 char*    k,     /* 秘密鍵 */
 int      lk,    /* 鍵の長さ（バイト） */
 char*    d,     /* データ */
 int      ld,    /* データの長さ（バイト） */
 char*    out,   /* 出力バッファー（少なくとも「t」バイト） */
 int      t
)
{
        SHA_CTX ictx, octx ;
        char    isha[SHA_DIGESTSIZE], osha[SHA_DIGESTSIZE] ;
        char    key[SHA_DIGESTSIZE] ;
        char    buf[SHA_BLOCKSIZE] ;
        int     i ;

        if (lk > SHA_BLOCKSIZE) {

                SHA_CTX         tctx ;

                SHAInit(&tctx) ;
                SHAUpdate(&tctx, k, lk) ;
                SHAFinal(key, &tctx) ;

                k = key ;
                lk = SHA_DIGESTSIZE ;
        }

        /**** Inner Digest ****/

        SHAInit(&ictx) ;

        /* 内側のダイジェスト用に鍵をパディングする */
        for (i = 0 ; i < lk ; ++i) buf[i] = k[i] ^ 0x36 ;
        for (i = lk ; i < SHA_BLOCKSIZE ; ++i) buf[i] = 0x36 ;

        SHAUpdate(&ictx, buf, SHA_BLOCKSIZE) ;
        SHAUpdate(&ictx, d, ld) ;

        SHAFinal(isha, &ictx) ;

        /**** Outter Digest ****/

        SHAInit(&octx) ;

        /* 外側のダイジェスト用に鍵をパディングする */

        for (i = 0 ; i < lk ; ++i) buf[i] = k[i] ^ 0x5C ;
        for (i = lk ; i < SHA_BLOCKSIZE ; ++i) buf[i] = 0x5C ;

        SHAUpdate(&octx, buf, SHA_BLOCKSIZE) ;
        SHAUpdate(&octx, isha, SHA_DIGESTSIZE) ;

        SHAFinal(osha, &octx) ;

        /* 結果を切り詰めて表示する */
        t = t > SHA_DIGESTSIZE ? SHA_DIGESTSIZE : t ;
        truncate(osha, out, t) ;
        pr_sha(stdout, out, t) ;

}
